Checklist dọn dẹp resource

Các resource tính phí theo giờ cần xoá ngay: ALB bluegreen-lab-alb, các task Fargate (tối đa 4 task), Public IPv4 của task, EC2 Jenkins server. ECR, CloudWatch Logs tính phí theo dung lượng.

  1. Terraform stack: xoá VPC, ALB, Target Group, 2 ECS Cluster/Service, IAM Role, log group:

    cd sourcecode/section_11_deployment_strategy/terraform_bluegreen_stack
terraform destroy

  2. Task definition còn sót: các revision do Jenkins đăng ký không do Terraform quản lý – deregister nếu muốn danh sách sạch (không tính phí):

    aws ecs list-task-definitions --family-prefix bluegreen-lab-nodejs-task --region ap-southeast-1 --query 'taskDefinitionArns[]' --output text | tr '\t' '\n' | xargs -I {} aws ecs deregister-task-definition --task-definition {} --region ap-southeast-1 --query 'taskDefinition.taskDefinitionArn'

  3. ECR: xoá các image v2.0.0, v2.1.0, v2.2.0 hoặc xoá cả repository nếu không dùng ở các section sau:

    aws ecr batch-delete-image --repository-name nodejs-random-color --image-ids imageTag=v2.0.0 imageTag=v2.1.0 imageTag=v2.2.0 --region ap-southeast-1

  4. IAM: gỡ policy ElasticLoadBalancingFullAccess khỏi Role jenkins-server-role nếu không cần nữa (least privilege).

  5. Jenkins server: stop instance jenkins-server nếu còn dùng ở các section sau; nếu không, terminate instance và xoá Security Group, key pair, IAM Role (xem Section 10 – Tổng kết).

  6. Kiểm tra lại trên Console (region Singapore): EC2 → Load Balancers, Target Groups, Elastic IPs, NAT Gateways, Volumes không dùng; ECS → Clusters. Không còn resource có tiền tố bluegreen-lab.

  7. RDS (nếu tự thử chương 4): xoá Blue/Green deployment, instance Green và instance -old1.

Best practice

  • Một artifact cho mọi môi trường: build một lần theo tag, cùng image đi qua Test → Production; không build lại khi rollback.
  • Guardrail trong pipeline: chặn deploy lên môi trường LIVE, kiểm tra health trước khi chuyển traffic, manual approval cho production.
  • Tương thích ngược: API versioning và mô hình expand – contract cho database để 2 version luôn chạy song song được.
  • Health check & monitoring đúng nghĩa: endpoint health kiểm tra cả dependency; alarm trên 5xx/latency theo Target Group; auto rollback khi alarm.
  • Hạ tầng là code: Terraform quản lý hạ tầng, pipeline quản lý trạng thái deploy – dùng ignore_changes để 2 bên không ghi đè nhau.
  • Kiểm soát chi phí: giới hạn thời gian giữ môi trường cũ, scale về 0 hoặc warm standby 1 task.

10. CI/CD sử dụng Jenkins / Lab 6: Build Docker image & push lên Amazon ECR

Mục tiêu

  • Cài Docker Engine (kèm Buildx, Compose plugin) trên Jenkins server, cho phép user jenkins sử dụng Docker.
  • Tạo (hoặc dùng lại) ECR repository nodejs-random-color.
  • Tạo Pipeline job: checkout code → docker build → đăng nhập ECR → tag & push image với tag ver-<BUILD_NUMBER>.
  • Không hard-code AWS Account ID: lấy động bằng aws sts get-caller-identity.

Các bước thực hành

  1. Bước 1: Cài Docker Engine trên Jenkins server

    SSH vào Jenkins server, cài Docker từ repository chính thức theo hướng dẫn của Docker:

    sudo apt update
sudo apt install -y ca-certificates curl
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.asc] https://download.docker.com/linux/ubuntu $(. /etc/os-release && echo "${UBUNTU_CODENAME:-$VERSION_CODENAME}") stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
sudo apt update
sudo apt install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
  2. Bước 2: Cho phép user jenkins dùng Docker

    Thêm user jenkins (và ubuntu) vào group docker, sau đó restart Jenkins để process Jenkins nhận group mới:

    sudo usermod -aG docker jenkins
sudo usermod -aG docker ubuntu
sudo systemctl restart jenkins
sudo -u jenkins docker version
docker compose version
    User thuộc group docker có quyền tương đương root trên máy (có thể mount mọi thư mục vào container). Chấp nhận được cho lab; production nên build trên agent riêng / container tạm thời, hoặc dùng công cụ build không cần daemon (Kaniko, Buildah).
  3. Bước 3: Tạo ECR repository

    Nếu đã có repository nodejs-random-color từ Section 9 thì dùng lại. Nếu chưa, vào ECR → Private registry → Create repository:

    • Repository name: nodejs-random-color
    • Image tag mutability: Mutable; Encryption: mặc định (AES-256)
  4. Bước 4: Cập nhật Dockerfile trong repository

    Dockerfile gốc của repository dùng node:14 (đã hết hỗ trợ) từ Docker Hub. Trên máy local, mở repository nodejs-random-color, thay toàn bộ nội dung file Dockerfile bằng nội dung lab6_docker_ecr/Dockerfile:

    # Dùng base image Node.js 22 từ Amazon ECR Public Gallery (mirror Docker Official Image)
# để tránh lỗi rate limit khi Jenkins pull image ẩn danh từ Docker Hub
FROM public.ecr.aws/docker/library/node:22-alpine

WORKDIR /app

COPY package*.json ./
RUN npm install --omit=dev

COPY . .

EXPOSE 3000

CMD [ "npm", "start" ]
    cd ~/jenkins-labs/nodejs-random-color
git add Dockerfile
git commit -m "build: use node 22 alpine base image from ECR Public"
git push origin master

    💡 Nếu đã clone repository ở Section 9 (thư mục ~/codepipeline-labs/nodejs-random-color), bạn có thể dùng luôn thư mục đó – thay đường dẫn cd trong các lệnh của section này cho phù hợp.

  5. Bước 5: Tạo Pipeline job

    Tạo New Item → Pipeline tên lab06-docker-ecr, Definition Pipeline script, dán nội dung lab6_docker_ecr/Jenkinsfile và sửa GIT_REPO:

    pipeline {
    agent any

    environment {
        // Thay <your-github-username> bằng GitHub username của bạn
        GIT_REPO   = 'https://github.com/<your-github-username>/nodejs-random-color.git'
        AWS_REGION = 'ap-southeast-1'
        ECR_REPO   = 'nodejs-random-color'
        IMAGE_TAG  = "ver-${BUILD_NUMBER}"
    }

    stages {
        stage('Checkout') {
            steps {
                git branch: 'master', url: "${GIT_REPO}"
            }
        }

        stage('Build image') {
            steps {
                sh 'docker build -t ${ECR_REPO}:${IMAGE_TAG} .'
            }
        }

        stage('Push image to ECR') {
            steps {
                // Lấy Account ID từ IAM Role của Jenkins server -> không hard-code Account ID
                sh '''
                    ACCOUNT_ID=$(aws sts get-caller-identity --query Account --output text)
                    ECR_REGISTRY=${ACCOUNT_ID}.dkr.ecr.${AWS_REGION}.amazonaws.com
                    aws ecr get-login-password --region ${AWS_REGION} | docker login --username AWS --password-stdin ${ECR_REGISTRY}
                    docker tag ${ECR_REPO}:${IMAGE_TAG} ${ECR_REGISTRY}/${ECR_REPO}:${IMAGE_TAG}
                    docker push ${ECR_REGISTRY}/${ECR_REPO}:${IMAGE_TAG}
                    echo "Pushed image: ${ECR_REGISTRY}/${ECR_REPO}:${IMAGE_TAG}"
                '''
            }
        }
    }

    post {
        always {
            // Xoá image không còn dùng để tránh đầy ổ đĩa Jenkins server
            sh 'docker image prune -f'
        }
    }
}

    💡 Các lệnh login, tag, push nằm chung một khối sh '''...''' vì biến shell ACCOUNT_ID, ECR_REGISTRY chỉ tồn tại trong process của khối đó (chương Jenkins Pipeline – Thông tin bổ sung).

Troubleshoot

permission denied while trying to connect to the Docker daemon socket at unix:///var/run/docker.sock
Nguyên nhân: User jenkins chưa thuộc group docker, hoặc chưa restart Jenkins sau khi thêm group.
Giải pháp: 
groups jenkins
sudo usermod -aG docker jenkins
sudo systemctl restart jenkins
denied: User: arn:aws:sts::...:assumed-role/jenkins-server-role/... is not authorized to perform: ecr:InitiateLayerUpload
Nguyên nhân: IAM Role thiếu quyền push ECR.
Giải pháp: Gắn thêm AmazonEC2ContainerRegistryPowerUser vào jenkins-server-role.
name unknown: The repository with name 'nodejs-random-color' does not exist in the registry
Nguyên nhân: Chưa tạo ECR repository hoặc tạo ở region khác.
Giải pháp: Tạo repository ở ap-southeast-1 (Bước 3).
toomanyrequests: You have reached your pull rate limit
Nguyên nhân: Dockerfile vẫn pull base image từ Docker Hub ẩn danh.
Giải pháp: Dùng base image từ ECR Public như Bước 4.
no space left on device
Nguyên nhân: Image và build cache tích tụ sau nhiều lần build.
Giải pháp: 
df -h /
sudo docker system df
sudo docker system prune -af

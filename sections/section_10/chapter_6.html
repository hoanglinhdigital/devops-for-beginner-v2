10. CI/CD sử dụng Jenkins / Lab 4: Build Java project (Maven) & upload artifact lên S3

Mục tiêu

  • Khai báo JDK và Maven trong Manage Jenkins → Tools.
  • Phần 1 – Freestyle: checkout repository Java mẫu từ GitHub, build bằng Maven, kiểm tra file .jar trong workspace.
  • Phần 2: thêm bước upload artifact lên S3 bucket bằng AWS CLI (quyền từ IAM Role).
  • Phần 3 – Declarative Pipeline: làm lại toàn bộ bằng Jenkinsfile với các stage Checkout → Build → Test → Upload.

Các bước thực hành

  1. Bước 1: Khai báo JDK cho Jenkins

    Tìm đường dẫn JAVA_HOME trên Jenkins server:

    java -XshowSettings:properties -version 2>&1 | grep 'java.home'
    java.home = /usr/lib/jvm/java-21-openjdk-amd64

    Vào Manage Jenkins → Tools → JDK installations → Add JDK:

    • Name: JDK21
    • Install automatically: không tick; JAVA_HOME: /usr/lib/jvm/java-21-openjdk-amd64
  2. Bước 2: Khai báo Maven cho Jenkins

    Cùng trang Tools, mục Maven installations → Add Maven:

    • Name: M3
    • Install automatically: tick → Install from Apache, chọn version 3.9.x mới nhất

    Save. Maven sẽ được Jenkins tự tải về /var/lib/jenkins/tools/ ở lần build đầu tiên.

    💡 Tên JDK21 và M3 sẽ được tham chiếu trong job/Jenkinsfile. Cách này cho phép nhiều project dùng nhiều version Maven/JDK khác nhau trên cùng một server.

  3. Bước 3: Tạo S3 bucket chứa artifact

    Vào S3 → Create bucket:

    • Bucket name: jenkins-artifact-<your-suffix> (tên bucket là duy nhất toàn cầu, ví dụ jenkins-artifact-linh2026)
    • Region: ap-southeast-1; Block all public access: giữ bật; các thông số khác mặc định
  4. Bước 4 (Phần 1): Tạo job Freestyle build Java

    Tạo New Item → Freestyle project tên lab04-java-freestyle:

    • Source Code Management: Git; Repository URL: https://github.com/<your-github-username>/simple-java-maven-app.git; Credentials: - none -; Branch Specifier: */master
    • Build Steps → Invoke top-level Maven targets: Maven Version M3; Goals: clean package

    Build Now và xem Console Output: Jenkins clone repository, tải Maven, tải dependency, chạy unit test và kết thúc bằng:

    [INFO] Building jar: /var/lib/jenkins/workspace/lab04-java-freestyle/target/my-app-1.0-SNAPSHOT.jar
[INFO] BUILD SUCCESS
...
Finished: SUCCESS

    Vào Workspace → target để thấy file my-app-1.0-SNAPSHOT.jar – đây chính là artifact của quá trình build.

  5. Bước 5 (Phần 2): Thêm bước upload artifact lên S3

    Vào Configure, thêm build step Execute shell phía sau bước Maven (thay <your-suffix>):

    ls -la "${WORKSPACE}/target/"
aws s3 cp "${WORKSPACE}/target/my-app-1.0-SNAPSHOT.jar" "s3://jenkins-artifact-<your-suffix>/lab04-java-freestyle/${BUILD_NUMBER}/"

    Save → Build Now. Mỗi build upload artifact vào một thư mục theo BUILD_NUMBER – giữ được lịch sử các version để rollback.

  6. Bước 6 (Phần 3): Tạo Declarative Pipeline

    Tạo New Item → Pipeline tên lab04-java-pipeline. Mục Pipeline: Definition Pipeline script, dán nội dung lab4_build_java/Jenkinsfile và sửa 2 dòng GIT_REPO, S3_BUCKET:

    pipeline {
    agent any

    // Tên tool phải trùng với tên đã khai báo ở Manage Jenkins -> Tools
    tools {
        jdk 'JDK21'
        maven 'M3'
    }

    environment {
        // Thay <your-github-username> và <your-suffix> bằng giá trị của bạn
        GIT_REPO  = 'https://github.com/<your-github-username>/simple-java-maven-app.git'
        S3_BUCKET = 'jenkins-artifact-<your-suffix>'
    }

    stages {
        stage('Checkout') {
            steps {
                git branch: 'master', url: "${GIT_REPO}"
            }
        }

        stage('Build') {
            steps {
                sh 'mvn -B -DskipTests clean package'
            }
        }

        stage('Test') {
            steps {
                sh 'mvn -B test'
            }
            post {
                always {
                    // Hiển thị kết quả unit test trên giao diện Jenkins
                    junit allowEmptyResults: true, testResults: 'target/surefire-reports/*.xml'
                }
            }
        }

        stage('Upload artifact to S3') {
            steps {
                sh 'aws s3 cp "${WORKSPACE}/target/my-app-1.0-SNAPSHOT.jar" "s3://${S3_BUCKET}/lab04-java-pipeline/${BUILD_NUMBER}/"'
            }
        }
    }

    post {
        success {
            // Lưu artifact ngay trên Jenkins để tải về từ trang build
            archiveArtifacts artifacts: 'target/*.jar', fingerprint: true
        }
    }
}
  7. Bước 7: Build pipeline & quan sát các stage

    Build Now. Trang job hiển thị từng stage (Checkout, Build, Test, Upload artifact to S3) cùng thời gian chạy; click vào một stage để xem log riêng của stage đó. Trang build có thêm mục Tests (kết quả unit test) và Build Artifacts (file .jar tải về được).

    💡 So sánh với Phần 1: cùng kết quả nhưng toàn bộ cấu hình nằm trong một đoạn code – có thể copy sang project khác, đưa vào Git (Lab 8) và review như source code.

Troubleshoot

Tool type "maven" does not have an install of "M3" configured
Nguyên nhân: Tên Maven trong Jenkinsfile khác với tên khai báo ở Tools.
Giải pháp: Kiểm tra lại Bước 2, tên phân biệt hoa/thường.
upload failed ... An error occurred (AccessDenied) when calling the PutObject operation
Nguyên nhân: IAM Role của Jenkins server thiếu quyền S3 hoặc sai tên bucket.
Giải pháp: Kiểm tra role jenkins-server-role có AmazonS3FullAccess; chạy thử sudo -u jenkins aws s3 ls trên server.
The user-provided path .../target/my-app-1.0-SNAPSHOT.jar does not exist
Nguyên nhân: Bước Maven bị lỗi hoặc tên artifact khác (đã sửa artifactId/version trong pom.xml).
Giải pháp: Xem log bước Maven, dùng ls -la target/ để biết đúng tên file.
Jenkins không khởi động lại được sau khi cài thêm Java khác
Nguyên nhân & giải pháp: Xem Troubleshoot của Lab 1 – chọn lại Java 21 bằng sudo update-alternatives --config java. Muốn build bằng JDK khác, hãy cài thêm và khai báo ở Tools, không đổi Java mặc định của hệ thống.

Dọn dẹp resource

Giữ lại bucket jenkins-artifact-<your-suffix> cho Lab 5. Dung lượng file .jar rất nhỏ nên chi phí S3 không đáng kể; bucket sẽ được xoá ở chương tổng kết. Nhớ Stop Jenkins server nếu nghỉ học.

10. CI/CD sử dụng Jenkins / Lab 5: Build Node.js (Vue + Webpack) & upload lên S3

Mục tiêu

  • Cài Node.js 22 LTS trên Jenkins server.
  • Phần 1: tạo Pipeline job checkout project Vue 3 + Webpack 5, build bằng npm install + npm run build, kiểm tra thư mục dist.
  • Phần 2: upload toàn bộ file tĩnh (html, css, js) trong dist lên S3 bằng aws s3 sync.
  • Phần 3 (tuỳ chọn): bật S3 Static website hosting để xem website do Jenkins build ra.

Các bước thực hành

  1. Bước 1: Cài Node.js 22 trên Jenkins server

    SSH vào Jenkins server và cài Node.js từ repository của NodeSource:

    curl -fsSL https://deb.nodesource.com/setup_22.x -o nodesource_setup.sh
sudo -E bash nodesource_setup.sh
sudo apt install -y nodejs
rm nodesource_setup.sh
node --version
npm --version

    💡 Node.js cài vào /usr/bin/node nên mọi job thấy ngay, không cần khai báo ở Tools. Muốn mỗi project dùng một version Node khác nhau, có thể dùng plugin NodeJS (khai báo ở Tools như Maven) hoặc build trong Docker container (Lab 6).

  2. Bước 2 (Phần 1 + 2): Tạo Pipeline job

    Tạo New Item → Pipeline tên lab05-vue-webpack, Definition Pipeline script, dán nội dung lab5_build_nodejs/Jenkinsfile và sửa GIT_REPO, S3_BUCKET:

    pipeline {
    agent any

    environment {
        // Thay <your-github-username> và <your-suffix> bằng giá trị của bạn
        GIT_REPO  = 'https://github.com/<your-github-username>/simple-vue-webpack.git'
        S3_BUCKET = 'jenkins-artifact-<your-suffix>'
    }

    stages {
        stage('Checkout') {
            steps {
                git branch: 'master', url: "${GIT_REPO}"
            }
        }

        stage('Clear old build') {
            steps {
                sh 'rm -rf "${WORKSPACE}/dist"'
            }
        }

        stage('Install dependencies') {
            steps {
                sh 'node --version'
                sh 'npm install'
            }
        }

        stage('Build') {
            steps {
                sh 'npm run build'
                sh 'ls -la dist'
            }
        }

        stage('Upload artifact to S3') {
            steps {
                // sync + --delete: đồng bộ đúng nội dung dist, xoá file cũ không còn dùng
                sh 'aws s3 sync "${WORKSPACE}/dist/" "s3://${S3_BUCKET}/lab05-vue/" --delete'
            }
        }
    }
}

    💡 Stage Clear old build xoá thư mục dist của lần build trước (workspace được giữ lại giữa các build – Lab 2) để chắc chắn file upload lên S3 là file vừa build.

  3. Bước 3: Build & kiểm tra artifact

    Build Now. Lần build đầu tốn 1–2 phút cho npm install. Log stage Build có dạng:

    + npm run build
> vue@1.0.0 build
> webpack --mode production
...
webpack 5.x.x compiled successfully in 5123 ms
+ ls -la dist
-rw-r--r-- 1 jenkins jenkins   ... index.html
-rw-r--r-- 1 jenkins jenkins   ... main.js
...

    Kiểm tra file trên S3:

    aws s3 ls s3://jenkins-artifact-<your-suffix>/lab05-vue/ --recursive
  4. Bước 4 (Phần 3 – tuỳ chọn): Tạo bucket static website

    Tạo bucket mới để public website (không public bucket artifact):

    • Bucket name: jenkins-web-<your-suffix>, region ap-southeast-1
    • Block all public access: bỏ tick (xác nhận cảnh báo)
    • Tab Properties → Static website hosting: Enable, Index document index.html
    • Tab Permissions → Bucket policy: dán nội dung lab5_build_nodejs/bucket-policy.json (thay <your-suffix>)
    {
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "PublicReadForStaticWebsite",
      "Effect": "Allow",
      "Principal": "*",
      "Action": "s3:GetObject",
      "Resource": "arn:aws:s3:::jenkins-web-<your-suffix>/*"
    }
  ]
}
  5. Bước 5 (Phần 3 – tuỳ chọn): Deploy website bằng Jenkins

    Vào Configure của job, sửa dòng aws s3 sync để upload vào gốc bucket website, Save và build lại:

    sh 'aws s3 sync "${WORKSPACE}/dist/" "s3://jenkins-web-<your-suffix>/" --delete'

    Truy cập Bucket website endpoint (tab Properties), dạng http://jenkins-web-<your-suffix>.s3-website-ap-southeast-1.amazonaws.com – thấy trang Vue do Jenkins build. Thử sửa nội dung trong src/, push lên GitHub, build lại và refresh trình duyệt.

    💡 Trong thực tế website tĩnh nên đặt sau CloudFront với Origin Access Control (Section 4) và job deploy thêm bước aws cloudfront create-invalidation để xoá cache.

Kiểm tra kết quả

✅ Lab thành công khi

  • Job lab05-vue-webpack chạy SUCCESS cả 5 stage.
  • S3 có các file index.html, *.js, *.css trong prefix lab05-vue/.
  • (Tuỳ chọn) Website endpoint của bucket jenkins-web-<your-suffix> hiển thị ứng dụng Vue.

Troubleshoot

npm: not found / node: not found
Nguyên nhân: Chưa cài Node.js trên Jenkins server (hoặc cài nhầm trên máy local).
Giải pháp: SSH vào Jenkins server làm lại Bước 1, kiểm tra bằng sudo -u jenkins node --version.
npm install rất lâu rồi build bị Killed
Nguyên nhân: Server thiếu RAM.
Giải pháp: Dùng tối thiểu t3.medium (Lab 1 – Troubleshoot).
Website endpoint trả về 403 Forbidden
Nguyên nhân: Chưa tắt Block public access, chưa có bucket policy, hoặc sai tên bucket trong Resource.
Giải pháp: Kiểm tra lại Bước 4; nhớ có /* ở cuối ARN.
Website endpoint trả về 404 Not Found – NoSuchKey: index.html
Nguyên nhân: File được upload vào prefix con (ví dụ lab05-vue/) thay vì gốc bucket.
Giải pháp: Kiểm tra lại đường dẫn đích của lệnh aws s3 sync ở Bước 5.

Dọn dẹp resource

Bucket website public chỉ nên tồn tại trong lúc thực hành. Xoá bucket jenkins-web-<your-suffix> sau khi kiểm tra xong; giữ lại bucket artifact cho các lab sau.
aws s3 rb s3://jenkins-web-<your-suffix> --force

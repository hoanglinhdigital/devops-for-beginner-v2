10. CI/CD sử dụng Jenkins / Lab 8: Pipeline from SCM & private repository (SSH key)

Mục tiêu

  • Chuyển repository nodejs-random-color sang chế độ Private và cấp quyền checkout cho Jenkins bằng SSH key (GitHub Deploy key – chỉ đọc, chỉ cho 1 repository).
  • Lưu private key vào Jenkins credential loại SSH Username with private key, cấu hình Git Host Key Verification.
  • Đưa Jenkinsfile vào repository và tạo job Pipeline script from SCM – pipeline được quản lý cùng source code.

Yêu cầu trước khi bắt đầu

  • Hoàn thành Lab 6 (Docker trên Jenkins, ECR repository). Repository nodejs-random-color đã clone về máy local.
  • Biết tạo SSH key và dùng SSH với GitHub (Section 7 – Lab 2).
  • Source code: sourcecode/section_10_cicd_with_jenkins/lab8_pipeline_from_scm/.

Các bước thực hành

  1. Bước 1: Tạo SSH key pair riêng cho Jenkins

    Trên máy local (Git Bash / Terminal), tạo key không có passphrase (Jenkins cần dùng key tự động):

    ssh-keygen -t ed25519 -C "jenkins-deploy-key" -f ~/.ssh/jenkins_github -N ""
ls -la ~/.ssh/jenkins_github*

    💡 Không dùng lại SSH key cá nhân của bạn: key cho Jenkins nên tách riêng để có thể thu hồi độc lập và chỉ cấp đúng quyền cần thiết.

  2. Bước 2: Thêm Deploy key vào repository & chuyển repository sang Private 
    cat ~/.ssh/jenkins_github.pub

    Trên GitHub, mở repository nodejs-random-color của bạn → Settings → Deploy keys → Add deploy key:

    • Title: jenkins-server; Key: dán nội dung file .pub; Allow write access: không tick

    Sau đó vào Settings → General → Danger Zone → Change repository visibility → Make private.

    💡 Từ lúc này job lab06-docker-ecr (checkout bằng URL HTTPS, không có credential) sẽ lỗi khi build – đúng như mong đợi với repository Private. Các lab sau đều checkout bằng URL SSH + credential github-ssh-key.

  3. Bước 3: Cấu hình Git Host Key Verification

    Lần đầu SSH tới github.com, Jenkins cần tin tưởng host key của GitHub. Vào Manage Jenkins → Security → Git Host Key Verification Configuration:

    • Host Key Verification Strategy: Accept first connection

    💡 Accept first connection lưu host key ở lần kết nối đầu vào /var/lib/jenkins/.ssh/known_hosts. Chặt chẽ hơn là Manually provided keys – dán sẵn host key chính thức của GitHub.

  4. Bước 4: Tạo credential SSH trên Jenkins 
    cat ~/.ssh/jenkins_github

    Vào Manage Jenkins → Credentials → System → Global credentials → Add Credentials:

    • Kind: SSH Username with private key
    • ID: github-ssh-key; Description: GitHub deploy key – nodejs-random-color
    • Username: git
    • Private Key: Enter directly → Add → dán toàn bộ nội dung private key (gồm cả dòng -----BEGIN OPENSSH PRIVATE KEY----- và -----END OPENSSH PRIVATE KEY-----); Passphrase để trống
  5. Bước 5: Đưa Jenkinsfile vào repository

    Copy file lab8_pipeline_from_scm/Jenkinsfile vào thư mục gốc repository nodejs-random-color trên máy local. Pipeline này giống Lab 6 nhưng không có stage Checkout:

    pipeline {
    agent any

    environment {
        AWS_REGION = 'ap-southeast-1'
        ECR_REPO   = 'nodejs-random-color'
        IMAGE_TAG  = "ver-${BUILD_NUMBER}"
    }

    stages {
        stage('Show commit') {
            steps {
                sh 'git log -1 --oneline'
            }
        }

        stage('Build image') {
            steps {
                sh 'docker build -t ${ECR_REPO}:${IMAGE_TAG} .'
            }
        }

        stage('Push image to ECR') {
            steps {
                sh '''
                    ACCOUNT_ID=$(aws sts get-caller-identity --query Account --output text)
                    ECR_REGISTRY=${ACCOUNT_ID}.dkr.ecr.${AWS_REGION}.amazonaws.com
                    aws ecr get-login-password --region ${AWS_REGION} | docker login --username AWS --password-stdin ${ECR_REGISTRY}
                    docker tag ${ECR_REPO}:${IMAGE_TAG} ${ECR_REGISTRY}/${ECR_REPO}:${IMAGE_TAG}
                    docker push ${ECR_REGISTRY}/${ECR_REPO}:${IMAGE_TAG}
                '''
            }
        }
    }

    post {
        always {
            sh 'docker image prune -f'
        }
    }
}
    cd ~/jenkins-labs/nodejs-random-color
git add Jenkinsfile
git commit -m "ci: add Jenkinsfile for pipeline from SCM"
git push origin master
  6. Bước 6: Tạo job Pipeline script from SCM

    Tạo New Item → Pipeline tên lab08-pipeline-from-scm, mục Pipeline:

    • Definition: Pipeline script from SCM; SCM: Git
    • Repository URL: git@github.com:<your-github-username>/nodejs-random-color.git (URL dạng SSH)
    • Credentials: git (GitHub deploy key – nodejs-random-color)
    • Branch Specifier: */master; Script Path: Jenkinsfile

    💡 Nếu credential đúng, ô Repository URL không còn báo lỗi đỏ Failed to connect to repository. Lỗi này xuất hiện nếu bạn dùng URL HTTPS cho repository Private mà không có credential.

Troubleshoot

No ED25519 host key is known for github.com and you have requested strict checking. Host key verification failed.
Nguyên nhân: Chưa cấu hình Git Host Key Verification.
Giải pháp: Làm lại Bước 3, chọn Accept first connection.
git@github.com: Permission denied (publickey) / Repository not found
Nguyên nhân: Sai private key, Deploy key thêm nhầm repository, hoặc job chưa chọn credential.
Giải pháp: Kiểm tra cặp key (jenkins_github ↔ jenkins_github.pub), Deploy key nằm đúng repository, Username credential là git.
Unable to find Jenkinsfile from git ...
Nguyên nhân: Chưa push Jenkinsfile, sai tên file (phân biệt hoa/thường) hoặc sai branch.
Giải pháp: Kiểm tra file trên GitHub ở nhánh master, Script Path đúng Jenkinsfile.
Load key "...": invalid format
Nguyên nhân: Private key dán thiếu dòng BEGIN/END hoặc thiếu ký tự xuống dòng cuối.
Giải pháp: Copy lại toàn bộ output của cat ~/.ssh/jenkins_github, cập nhật credential.

Checklist dọn dẹp resource

Các resource tính phí theo giờ cần xoá ngay: EC2 Jenkins server (t3.medium), Public IPv4 / Elastic IP, ALB, task Fargate. Các resource lưu trữ (EBS, S3, ECR, CloudWatch Logs) tính phí theo dung lượng.

  1. ECS stack: chạy terraform destroy nếu chưa xoá (Lab 7 → Lab 10):

    cd sourcecode/section_10_cicd_with_jenkins/terraform_ecs_stack
terraform destroy

  2. Task definition còn sót: các revision do Jenkins đăng ký không do Terraform quản lý – deregister nếu muốn danh sách sạch (không tính phí):

    aws ecs list-task-definitions --family-prefix jenkins-lab-nodejs-task --region ap-southeast-1 --query 'taskDefinitionArns[]' --output text | tr '\t' '\n' | xargs -I {} aws ecs deregister-task-definition --task-definition {} --region ap-southeast-1 --query 'taskDefinition.taskDefinitionArn'

  3. ECR: xoá bớt image hoặc xoá repository nodejs-random-color (nếu không còn dùng cho các section sau):

    aws ecr delete-repository --repository-name nodejs-random-color --force --region ap-southeast-1

  4. S3: làm rỗng và xoá bucket artifact (và bucket website nếu còn):

    aws s3 rb s3://jenkins-artifact-<your-suffix> --force
aws s3 rb s3://jenkins-web-<your-suffix> --force

  5. Jenkins server: nếu còn học tiếp các section sau, chỉ cần Stop instance. Nếu không dùng nữa: terminate instance jenkins-server (EBS root volume tự xoá), release Elastic IP (nếu có), xoá Security Group jenkins-sg, key pair jenkins-key, IAM Role jenkins-server-role.

  6. Kiểm tra lại trên Console (region Singapore): EC2 instances, Load Balancers, Target Groups, Elastic IPs, NAT Gateways, ECS clusters – không còn resource của lab.

  7. CloudWatch Logs: xoá log group /ecs/jenkins-lab-nodejs nếu còn (Terraform đã xoá khi destroy).

  8. GitHub & Slack: xoá webhook (Lab 9) và Deploy key jenkins-server (Lab 8) trên repository; xoá Slack App (Lab 12). Có thể chuyển repository về Public nếu muốn.

  9. Máy local: xoá key ~/.ssh/jenkins_github, ~/.ssh/jenkins_github.pub nếu không dùng nữa.

Best practice khi vận hành Jenkins thật

  • Tách agent khỏi controller: đặt số executor của built-in node = 0, build trên agent EC2 / Docker / Kubernetes (plugin EC2, Kubernetes) – controller chỉ điều phối.
  • Bảo mật: Jenkins sau ALB + HTTPS hoặc VPN, không public port 8080; bật phân quyền (Matrix / Role-based), cập nhật core & plugin định kỳ, gỡ plugin không dùng.
  • Least privilege: IAM Role chỉ đủ quyền cho đúng bucket, repository, cluster; secret lưu trong Jenkins Credentials hoặc AWS Secrets Manager.
  • Backup JENKINS_HOME: snapshot EBS định kỳ (AWS Backup hoặc Data Lifecycle Manager), hoặc cấu hình bằng code (Jenkins Configuration as Code – JCasC) để dựng lại server nhanh.
  • Pipeline as Code: mọi job dùng Jenkinsfile trong repository, Multibranch Pipeline cho nhiều nhánh, Shared Library cho đoạn code dùng chung.
  • Giữ server gọn: Discard old builds, dọn Docker image/cache định kỳ, theo dõi dung lượng đĩa.

Chủ đề nên tìm hiểu thêm

  • Multibranch Pipeline & GitHub Branch Source: tự build mọi nhánh/PR, báo trạng thái build ngược lại GitHub.
  • Docker agent (agent { docker { image 'node:22' } }): mỗi build chạy trong container sạch, không cần cài tool lên server.
  • Tích hợp chất lượng code: SonarQube, quét lỗ hổng image bằng ECR scanning / Trivy, lưu artifact trên Nexus / CodeArtifact.
  • Kết hợp Jenkins với CodeDeploy để có Blue/Green, Canary (Section 9) thay vì rolling update.
  • So sánh với công cụ CI/CD tiếp theo của khoá học: GitHub Actions – cùng khái niệm CI/CD, khác công cụ.

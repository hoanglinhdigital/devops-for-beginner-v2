7. Thao tác cơ bản với Git / Lab 8: Sử dụng AWS CodeCommit

Mục tiêu

  • Tạo Git repository trên AWS CodeCommit – dịch vụ Git managed của AWS.
  • Tạo IAM User với quyền CodeCommit và upload SSH public key cho IAM User.
  • Cấu hình ~/.ssh/config, clone repository, tạo branch, commit và push.
  • Tạo, review và merge Pull Request trên CodeCommit Console.

Khác với GitHub (key gắn với tài khoản GitHub), CodeCommit xác thực qua IAM: SSH public key được gắn với IAM User, quyền thao tác repository do IAM Policy quyết định.

Yêu cầu trước khi bắt đầu

  • Tài khoản AWS, đăng nhập Console bằng IAM User có quyền quản trị (không dùng root user cho thao tác hằng ngày).
  • Đã hoàn thành Lab 2 (biết cách sinh SSH key) và Lab 4 (hiểu Pull Request).
  • Source code: sourcecode/section_7_git_basic_operation/lab8_codecommit/ (commands.sh, ssh_config).
Lưu ý về CodeCommit: từ 07/2024 AWS tạm ngừng cho phép tài khoản mới tạo repository CodeCommit; đến 11/2025 AWS thông báo CodeCommit hoạt động trở lại đầy đủ và mở cho khách hàng mới. Nếu tài khoản của bạn vẫn không tạo được repository, hãy đọc qua lab để nắm cách làm – các section sau có phương án dùng GitHub thay thế.

Các bước thực hành

  1. Bước 1: Tạo repository trên CodeCommit

    Trên AWS Console, mở dịch vụ CodeCommit, tạo repository với thông số:

    • Region: Asia Pacific (Singapore) ap-southeast-1
    • Repository name: demo-codecommit
    • Description: Lab 8 - Section 7
  2. Bước 2: Tạo IAM User cho CodeCommit

    Trên IAM Console, tạo user với thông số:

    • User name: codecommit-lab-user
    • Console access: không cần
    • Permissions: Attach policies directly → AWSCodeCommitPowerUser

    💡 Root user không dùng được SSH key cho CodeCommit. AWSCodeCommitPowerUser cho phép thao tác mọi repository nhưng không được xoá repository – phù hợp nguyên tắc least privilege cho developer.

  3. Bước 3: Sinh SSH key RSA trên PC Local

    IAM chỉ chấp nhận SSH public key dạng ssh-rsa (tối thiểu 2048 bit), không hỗ trợ ed25519 như GitHub. Sinh một key riêng cho CodeCommit (Enter để bỏ qua passphrase):

    ssh-keygen -t rsa -b 4096 -C "codecommit-lab-user" -f ~/.ssh/codecommit_rsa
cat ~/.ssh/codecommit_rsa.pub
clip < ~/.ssh/codecommit_rsa.pub
  4. Bước 4: Upload public key cho IAM User

    Trên IAM Console, mở user codecommit-lab-user → tab Security credentials → mục SSH public keys for AWS CodeCommit → upload với nội dung file codecommit_rsa.pub.

    Sau khi upload, ghi lại SSH key ID (dạng APKAxxxxxxxxxxxxxxxx) – đây sẽ là “username” khi kết nối SSH tới CodeCommit.

  5. Bước 5: Cấu hình ~/.ssh/config 
    code ~/.ssh/config

    Thêm nội dung trong file ssh_config của source code vào cuối file (thay <SSH_KEY_ID>), lưu lại:

    Host git-codecommit.*.amazonaws.com
    User <SSH_KEY_ID>
    IdentityFile ~/.ssh/codecommit_rsa
  6. Bước 6: Kiểm tra kết nối

    Lần đầu gõ yes để chấp nhận fingerprint:

    ssh git-codecommit.ap-southeast-1.amazonaws.com
You have successfully authenticated over SSH. You can use Git to interact with AWS CodeCommit. Interactive shells are not supported.Connection to git-codecommit.ap-southeast-1.amazonaws.com closed by remote host.
  7. Bước 7: Clone repository

    Lấy URL ở mục Clone URL → Clone SSH trên trang repository:

    cd ~/git-labs
git clone ssh://git-codecommit.ap-southeast-1.amazonaws.com/v1/repos/demo-codecommit
cd demo-codecommit

    Git báo warning: You appear to have cloned an empty repository – bình thường vì repository chưa có commit nào.

  8. Bước 8: Commit đầu tiên trên main & tạo nhánh feature 
    echo "# demo-codecommit" > README.md
git add README.md
git commit -m "chore: init repository"
git branch -M main
git push -u origin main
    git checkout -b feature/F001
echo "<h1>Hello from CodeCommit</h1>" > index.html
git add index.html
git commit -m "feat(F001): add index page"
git push -u origin feature/F001

    Trên CodeCommit Console, mục Branches giờ có main và feature/F001.

  9. Bước 9: Tạo, review & merge Pull Request trên Console

    Trong repository demo-codecommit, tạo Pull Request với thông số:

    • Destination: main · Source: feature/F001
    • Title: F001 - Add index page

    Ở tab Changes xem diff và thử thêm comment. Merge PR với tuỳ chọn Fast forward merge và đánh dấu xoá source branch sau khi merge. CodeCommit hỗ trợ 3 kiểu merge: Fast forward, Squash and merge, 3-way merge – tương ứng các khái niệm ở chương trước.

    💡 Muốn bắt buộc review như Ruleset của GitHub: dùng Approval rule templates (số người approve tối thiểu) và IAM Policy Deny codecommit:GitPush vào branch main.

  10. Bước 10: Cập nhật main ở local 
    git checkout main
git pull origin main
git log --oneline --graph -5

Kiểm tra kết quả

✅ Lab thành công khi

  • ssh git-codecommit.ap-southeast-1.amazonaws.com trả về You have successfully authenticated over SSH.
  • Repository demo-codecommit trên Console có file README.md và index.html trên branch main.
  • Mục Pull requests (lọc Closed) có PR F001 - Add index page ở trạng thái Merged.

Troubleshoot

Permission denied (publickey).
Nguyên nhân: Sai SSH key ID trong ~/.ssh/config (nhầm với Access Key ID AKIA...), sai đường dẫn IdentityFile, hoặc public key chưa ở trạng thái Active.
Giải pháp: Kiểm tra lại SSH key ID dạng APKA... trên IAM; chạy ssh -v git-codecommit.ap-southeast-1.amazonaws.com để xem key nào được dùng.
Unable to negotiate with ... no matching host key type found. Their offer: ssh-rsa
Nguyên nhân: OpenSSH bản mới tắt mặc định thuật toán ssh-rsa (SHA-1).
Giải pháp: Thêm 2 dòng vào block Host git-codecommit.*.amazonaws.com trong ~/.ssh/config: HostkeyAlgorithms +ssh-rsa và PubkeyAcceptedAlgorithms +ssh-rsa.
Upload SSH key lên IAM báo lỗi định dạng key không hợp lệ
Nguyên nhân: Upload key ed25519 hoặc dán nhầm private key.
Giải pháp: Sinh key RSA như bước 3 và chỉ dán nội dung file .pub (bắt đầu bằng ssh-rsa).
fatal: unable to access ... The requested URL returned error: 403 khi dùng URL HTTPS
Nguyên nhân: Clone bằng URL HTTPS nhưng chưa có HTTPS Git credentials cho IAM User.
Giải pháp: Dùng URL SSH như lab, hoặc tạo HTTPS Git credentials tại tab Security credentials của IAM User, hoặc dùng công cụ git-remote-codecommit với AWS CLI profile.

Dọn dẹp resource

CodeCommit miễn phí cho 5 active user đầu tiên mỗi tháng (kèm 50 GB lưu trữ, 10.000 Git request), nên lab gần như không phát sinh chi phí. Tuy vậy, hãy dọn dẹp để tránh để lại IAM User và SSH key không dùng tới – đây là rủi ro bảo mật.
  1. Xoá resource trên AWS
    • CodeCommit: xoá repository demo-codecommit (Settings → Delete repository).
    • IAM: xoá SSH public key của codecommit-lab-user, sau đó xoá user.
  2. Xoá file ở PC Local 
    rm -rf ~/git-labs/demo-codecommit
rm ~/.ssh/codecommit_rsa ~/.ssh/codecommit_rsa.pub

    Xoá block Host git-codecommit.*.amazonaws.com trong ~/.ssh/config.

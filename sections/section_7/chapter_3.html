7. Thao tác cơ bản với Git / Lab 1: Cài đặt Git, SourceTree & clone repository đầu tiên

Mục tiêu

  • Cài đặt Git (kèm Git Bash trên Windows) và cấu hình thông tin người dùng.
  • Cài đặt SourceTree – công cụ giao diện đồ hoạ để xem branch, lịch sử commit.
  • Clone một public repository trên GitHub về máy local.
  • Mở repository bằng VS Code và xem các branch bằng SourceTree.

Yêu cầu trước khi bắt đầu

  • PC Windows / Mac / Linux có kết nối Internet, quyền cài đặt phần mềm.
  • Đã cài VS Code (đã chuẩn bị theo checklist ở Section 1).
  • Tài khoản GitHub (đăng ký miễn phí tại github.com/signup) – dùng từ Lab 2, nên tạo trước.
  • Source code: sourcecode/section_7_git_basic_operation/lab1_install_git/commands.sh.

Các bước thực hành

  1. Bước 1: Cài đặt Git
    Hệ điều hànhCách cài đặt
    WindowsTải Git for Windows tại git-scm.com/downloads, cài với các tuỳ chọn mặc định. Bộ cài kèm sẵn Git Bash – terminal giống Linux.
    Macbrew install git (hoặc xcode-select --install)
    Ubuntu / Debiansudo apt install -y git
    Amazon Linux 2023sudo dnf install -y git

    Mở Git Bash trên Windows bằng một trong hai cách: click chuột phải vào thư mục → Open Git Bash here, hoặc tìm “Git Bash” trong Start menu. Kiểm tra phiên bản:

    git --version
git version 2.51.0.windows.1
  2. Bước 2: Cấu hình thông tin người dùng (chỉ làm 1 lần)

    Tên và email sẽ được ghi vào mỗi commit. Dùng email trùng với email tài khoản GitHub để commit hiển thị đúng avatar:

    git config --global user.name "Your Name"
git config --global user.email "your_email@example.com"
git config --global init.defaultBranch main
git config --global pull.rebase false
git config --global core.autocrlf true
git config --global core.editor "code --wait"
git config --global --list
    Cấu hìnhÝ nghĩa
    init.defaultBranch mainRepo tạo bằng git init dùng branch mặc định main (giống GitHub)
    pull.rebase falsegit pull dùng merge (mặc định dễ hiểu cho người mới), tránh cảnh báo “divergent branches”
    core.autocrlf trueWindows: tự chuyển ký tự xuống dòng CRLF ↔ LF. Trên Mac/Linux dùng core.autocrlf input
    core.editor "code --wait"Dùng VS Code để soạn commit message thay vì Vim
  3. Bước 3: Cài đặt SourceTree

    Tải tại sourcetreeapp.com (Windows/Mac). Khi cài đặt có thể bỏ qua bước đăng nhập Bitbucket; ở bước chọn Git, chọn dùng System Git đã cài ở bước 1.

    💡 SourceTree không bắt buộc. Có thể thay bằng tab Source Control có sẵn trong VS Code, extension Git Graph/GitLens, hoặc GitHub Desktop.

  4. Bước 4: Tạo thư mục làm việc

    Tất cả repository của section này sẽ đặt trong thư mục ~/git-labs (trên Windows là C:\Users\<tên-user>\git-labs):

    mkdir -p ~/git-labs
cd ~/git-labs
pwd
  5. Bước 5: Clone một public repository trên GitHub

    Repository octocat/Hello-World là repo mẫu của GitHub, có nhiều branch để quan sát:

    git clone https://github.com/octocat/Hello-World.git
cd Hello-World
ls -la
git status
git log --oneline
git branch
git branch -a

    Quan sát:

    • ls -la có thư mục ẩn .git – đây chính là local repository.
    • git branch chỉ hiện branch local (master), còn git branch -a hiện thêm các branch trên remote dạng remotes/origin/....
    • Repo này tạo từ trước 2020 nên branch chính vẫn là master.
  6. Bước 6: Mở repository bằng VS Code 
    code .

    Trong VS Code: góc dưới bên trái hiển thị branch hiện tại; tab Source Control hiển thị các file thay đổi. Thử sửa file README rồi quay lại Git Bash chạy git status và git diff để thấy Git đã phát hiện thay đổi. Sau đó bỏ thay đổi bằng:

    git restore README
git status
  7. Bước 7: Xem branch & lịch sử bằng SourceTree

    Mở SourceTree, thêm repository có sẵn với thông số:

    • Loại: Add / Open local repository
    • Đường dẫn: thư mục ~/git-labs/Hello-World

    Quan sát danh sách Branches và Remotes → origin ở cột bên trái, biểu đồ commit ở tab History. Double-click vào một branch remote (ví dụ origin/test) để checkout thành branch local.

Kiểm tra kết quả

✅ Lab thành công khi

  • git --version hiển thị phiên bản Git.
  • git config --global --list có user.name và user.email của bạn.
  • Thư mục ~/git-labs/Hello-World tồn tại, git branch -a liệt kê được các branch remote.

Troubleshoot

bash: git: command not found / 'git' is not recognized as an internal or external command
Nguyên nhân: Chưa cài Git hoặc chưa mở lại terminal sau khi cài nên biến PATH chưa cập nhật.
Giải pháp: Đóng và mở lại terminal/VS Code. Trên Windows nên dùng Git Bash.
bash: code: command not found
Nguyên nhân: Lệnh code chưa được thêm vào PATH.
Giải pháp: Windows: cài lại VS Code với tuỳ chọn Add to PATH. Mac: trong VS Code mở Command Palette → Shell Command: Install 'code' command in PATH.
fatal: unable to access 'https://github.com/...': SSL certificate problem
Nguyên nhân: Mạng công ty dùng proxy/firewall kiểm tra SSL.
Giải pháp: Thử mạng khác (4G, mạng nhà) hoặc liên hệ IT để lấy cấu hình proxy. Không tắt kiểm tra SSL (http.sslVerify false) vì không an toàn.

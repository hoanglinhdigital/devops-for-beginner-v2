  • Tạo repository demo-git trên GitHub – repository dùng xuyên suốt các lab của section.
  • Sinh cặp SSH key trên PC Local và thêm public key vào tài khoản GitHub.
  • Hiểu khi nào cần ssh-agent.
  • Clone repository bằng SSH, không cần nhập username/password.

Các bước thực hành

  1. Bước 1: Tạo repository trên GitHub

    Trên GitHub, tạo repository mới (nút New repository) với các thông số:

    • Repository name: demo-git
    • Visibility: Public
    • Add README: bật (để repository có sẵn branch main và commit đầu tiên)
    • .gitignore: None · License: None
    Vì sao chọn Public? Với tài khoản GitHub Free, tính năng bảo vệ branch (Lab 4) chỉ áp dụng cho public repository. Repository này chỉ chứa code demo, không chứa thông tin nhạy cảm. Nếu dùng GitHub Pro/Team, có thể chọn Private.
  2. Bước 2: Sinh SSH key trên PC Local

    Mở Git Bash (Windows) hoặc Terminal (Mac/Linux). Kiểm tra key đã có chưa, sau đó sinh key mới (thay email bằng email GitHub của bạn):

    ls -la ~/.ssh
ssh-keygen -t ed25519 -C "your_email@example.com"
    • Enter file in which to save the key: nhấn Enter để dùng vị trí mặc định ~/.ssh/id_ed25519 (Windows: C:\Users\<tên-user>\.ssh\id_ed25519).
    • Enter passphrase: nhấn Enter 2 lần để bỏ qua, hoặc đặt passphrase để bảo vệ key (xem bước 3).
    ls -l ~/.ssh/id_ed25519 ~/.ssh/id_ed25519.pub

    💡 Nếu đã có sẵn file id_ed25519 (đã tạo trước đây), không cần tạo lại – trả lời n khi được hỏi Overwrite? để tránh mất key đang dùng.

  3. Bước 3 (chỉ khi đặt passphrase): Thêm private key vào ssh-agent

    ssh-agent giữ private key đã mở khoá trong bộ nhớ để không phải gõ passphrase mỗi lần push/pull. Nếu không đặt passphrase, bỏ qua bước này – SSH tự dùng key mặc định ~/.ssh/id_ed25519.

    eval "$(ssh-agent -s)"
ssh-add ~/.ssh/id_ed25519
ssh-add -l

    Nếu muốn ssh-agent tự khởi động cùng Windows, mở PowerShell (Run as administrator) và chạy:

    Get-Service -Name ssh-agent | Set-Service -StartupType Manual
Start-Service ssh-agent
ssh-add "$env:USERPROFILE\.ssh\id_ed25519"
ssh-add -L
  4. Bước 4: Thêm public key vào tài khoản GitHub

    Hiển thị (hoặc copy thẳng vào clipboard trên Windows) nội dung public key:

    cat ~/.ssh/id_ed25519.pub
ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAA... your_email@example.com
clip < ~/.ssh/id_ed25519.pub

    Trên GitHub, vào Settings → SSH and GPG keys → New SSH key (menu từ avatar góc phải) với các thông số:

    • Title: tên dễ nhận biết, ví dụ laptop-ca-nhan
    • Key type: Authentication Key
    • Key: dán toàn bộ nội dung file id_ed25519.pub (1 dòng, bắt đầu bằng ssh-ed25519)
    Chỉ dán public key (file .pub). Không bao giờ chia sẻ nội dung file id_ed25519 (private key) cho bất kỳ ai hay website nào.
  5. Bước 5: Kiểm tra kết nối SSH tới GitHub

    Lần đầu kết nối, gõ yes để chấp nhận fingerprint của GitHub:

    ssh -T git@github.com
Hi your-username! You've successfully authenticated, but GitHub does not provide shell access.
  6. Bước 6: Clone repository bằng SSH

    Trên trang repository demo-git, chọn Code → SSH để lấy URL. Clone về thư mục ~/git-labs (thay <GITHUB_USERNAME>):

    cd ~/git-labs
git clone git@github.com:<GITHUB_USERNAME>/demo-git.git
cd demo-git
git remote -v
origin  git@github.com:<GITHUB_USERNAME>/demo-git.git (fetch)
origin  git@github.com:<GITHUB_USERNAME>/demo-git.git (push)
git branch -a
* main
  remotes/origin/HEAD -> origin/main
  remotes/origin/main

Troubleshoot

git@github.com: Permission denied (publickey).
Nguyên nhân: Chưa thêm public key lên GitHub, dán thiếu ký tự, hoặc private key không nằm ở vị trí mặc định / có passphrase nhưng chưa ssh-add.
Giải pháp: Kiểm tra lại key trên GitHub Settings; chạy ssh -vT git@github.com để xem SSH đang thử key nào; nếu key đặt tên khác thì thêm vào ~/.ssh/config: Host github.com / IdentityFile ~/.ssh/<tên-key>.
ssh: connect to host github.com port 22: Connection timed out
Nguyên nhân: Mạng công ty/trường chặn cổng 22.
Giải pháp: Dùng SSH qua cổng 443: thêm vào ~/.ssh/config block Host github.com với Hostname ssh.github.com và Port 443, sau đó thử lại ssh -T git@github.com.
unable to start ssh-agent service, error :1058 (PowerShell)
Nguyên nhân: Service ssh-agent của Windows đang bị Disabled.
Giải pháp: Chạy PowerShell bằng quyền Administrator và chạy lại Get-Service -Name ssh-agent | Set-Service -StartupType Manual trước Start-Service ssh-agent.

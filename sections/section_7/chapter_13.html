Best practice khi sử dụng Git

  • Sử dụng branch: tạo branch riêng mỗi khi phát triển feature hoặc fix bug. Developer làm việc không ảnh hưởng lẫn nhau và dễ review thay đổi.
  • Commit thường xuyên, nhỏ gọn (atomic): mỗi commit chứa một thay đổi logic nhỏ – dễ theo dõi tiến độ, cô lập thay đổi và revert khi cần.
  • Commit message rõ ràng, dễ hiểu: mô tả “làm gì, vì sao”, gắn mã ticket, theo quy ước chung (ví dụ Conventional Commits feat:, fix:, docs:).
  • Pull before push: luôn pull code mới nhất từ remote trước khi bắt đầu thay đổi và trước khi push – giảm conflict, đảm bảo làm việc trên codebase mới nhất.
  • Review code qua Pull Request: phát hiện bug sớm, cải thiện chất lượng code và chia sẻ kiến thức giữa các thành viên. Bảo vệ main/develop để mọi thay đổi đều đi qua PR.
  • Resolve conflict cẩn thận: dành thời gian hiểu rõ code của cả hai phía (trao đổi với người viết) trước khi chọn; chạy thử/test lại sau khi resolve.
  • Dùng Git tag & Release: đánh tag cho các milestone quan trọng giúp theo dõi release, quản lý phiên bản ổn định và đơn giản hoá deploy/rollback.
  • Backup & dùng remote repository tin cậy: push thường xuyên, dùng GitHub/GitLab/CodeCommit và cân nhắc backup định kỳ repository quan trọng để tránh mất dữ liệu.
  • Không commit secret: dùng .gitignore cho .env, *.pem, terraform.tfvars; bật Secret scanning / Push protection của GitHub. Lỡ push secret → rotate ngay, không chỉ xoá file.
  • Hạn chế lệnh viết lại lịch sử trên branch chung: dùng revert thay vì reset --hard + push --force trên develop/main.

Dọn dẹp resource

Repository GitHub không phát sinh chi phí – có thể giữ lại để tham khảo trong tương lai hoặc xoá nếu không có nhu cầu. Resource AWS (CodeCommit, IAM User) nên được xoá.
  1. GitHub (tuỳ chọn)
    • Xoá repository demo-git: Settings → General → Danger Zone → Delete this repository.
    • Giữ lại SSH key trên GitHub nếu vẫn dùng máy này; xoá key tại Settings → SSH and GPG keys nếu là máy dùng chung/máy công ty.
  2. AWS (nếu đã làm Lab 8 và chưa dọn)
    • CodeCommit: xoá repository demo-codecommit ở region ap-southeast-1.
    • IAM: xoá SSH public key của codecommit-lab-user và xoá user.
  3. PC Local

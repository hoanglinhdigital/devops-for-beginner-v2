Các bước thực hành

  1. Bước 1: Tạo ECR repository

    Vào Amazon ECR → Private registry → Repositories, tạo repository với các thông số:

    • Repository name: nodejs-random-color
    • Image tag mutability: Mutable (cho phép ghi đè tag latest)
    • Encryption: AES-256 (mặc định)
  2. Bước 2: Cập nhật Dockerfile & thêm buildspec.yml vào repository

    Trong repository nodejs-random-color: copy đè file Dockerfile và tạo file buildspec.yml ở thư mục gốc, nội dung lấy từ thư mục lab4_codebuild_docker.

    Dockerfile – nâng cấp từ node:14 lên Node.js 20 và lấy base image từ ECR Public để tránh lỗi rate limit của Docker Hub:

    # Dùng base image Node.js 20 từ Amazon ECR Public Gallery (mirror Docker Official Image)
# để tránh lỗi rate limit khi CodeBuild pull image ẩn danh từ Docker Hub
FROM public.ecr.aws/docker/library/node:20-alpine

WORKDIR /app

COPY package*.json ./
RUN npm install --omit=dev

COPY . .

EXPOSE 3000

CMD [ "npm", "start" ]

    buildspec.yml:

    version: 0.2

# Biến IMAGE_REPO_NAME khai báo ngay trong file; AWS_DEFAULT_REGION do CodeBuild cung cấp sẵn
env:
  variables:
    IMAGE_REPO_NAME: nodejs-random-color

phases:
  pre_build:
    commands:
      - echo Logging in to Amazon ECR...
      - AWS_ACCOUNT_ID=$(aws sts get-caller-identity --query Account --output text)
      - ECR_REGISTRY=$AWS_ACCOUNT_ID.dkr.ecr.$AWS_DEFAULT_REGION.amazonaws.com
      - REPOSITORY_URI=$ECR_REGISTRY/$IMAGE_REPO_NAME
      - aws ecr get-login-password --region $AWS_DEFAULT_REGION | docker login --username AWS --password-stdin $ECR_REGISTRY
      - COMMIT_HASH=$(echo $CODEBUILD_RESOLVED_SOURCE_VERSION | cut -c 1-7)
      - echo Image will be tagged with $COMMIT_HASH
  build:
    commands:
      - echo Build started on `date`
      - docker build -t $REPOSITORY_URI:latest .
      - docker tag $REPOSITORY_URI:latest $REPOSITORY_URI:$COMMIT_HASH
  post_build:
    commands:
      - echo Pushing the Docker image...
      - docker push $REPOSITORY_URI:latest
      - docker push $REPOSITORY_URI:$COMMIT_HASH
      - echo Build completed on `date`

    💡 Account ID được lấy động bằng aws sts get-caller-identity – không hard-code Account ID trong source code. Tag theo commit SHA (7 ký tự đầu) giúp truy ngược image về đúng commit.

    cd ~/codepipeline-labs/nodejs-random-color
git add Dockerfile buildspec.yml
git commit -m "ci: build docker image with CodeBuild"
git push origin master
  3. Bước 3: Tạo CodeBuild project
    • Project name: nodejs-docker-build
    • Source: GitHub (connection github-connection), Repository <your-github-username>/nodejs-random-color, Source version master
    • Environment: Managed image, Amazon Linux, Standard, aws/codebuild/amazonlinux-x86_64-standard:5.0, 3 GB / 2 vCPUs
    • Privileged: bật (Enable this flag if you want to build Docker images...)
    • Service role: New service role, tên codebuild-nodejs-docker-build-service-role
    • Buildspec: Use a buildspec file; Artifacts: No artifacts
    • Logs: CloudWatch logs, Group name /codebuild/nodejs-docker-build
  4. Bước 4: Cấp quyền push image cho service role

    Vào IAM → Roles → codebuild-nodejs-docker-build-service-role, gắn managed policy:

    • AmazonEC2ContainerRegistryPowerUser – cho phép login, pull, push image lên ECR (không có quyền xoá repository).
  5. Bước 5: Chạy build & kiểm tra image trên ECR

    Start build, theo dõi log: Login Succeeded → các bước docker build → docker push. Sau khi build thành công:

    aws ecr describe-images --repository-name nodejs-random-color --region ap-southeast-1 --query "imageDetails[].imageTags"

    Repository có 1 image mang 2 tag: latest và commit SHA (ví dụ a1b2c3d). Copy Image URI tag latest – dùng cho Terraform ở Lab 6.

  6. Bước 6 (tuỳ chọn): Chạy thử image trên máy local

    Thay 123456789012 bằng Account ID của bạn, sau đó truy cập http://localhost:3000:

    export ECR_REGISTRY=123456789012.dkr.ecr.ap-southeast-1.amazonaws.com
aws ecr get-login-password --region ap-southeast-1 | docker login --username AWS --password-stdin ${ECR_REGISTRY}
docker run -d --rm --name random-color -p 3000:3000 ${ECR_REGISTRY}/nodejs-random-color:latest
docker stop random-color

Kiểm tra kết quả

✅ Lab thành công khi

  • Build của nodejs-docker-build ở trạng thái Succeeded.
  • ECR repository nodejs-random-color có image với tag latest và tag commit SHA.
  • Mỗi lần push code mới và chạy build lại, xuất hiện thêm 1 tag commit SHA mới.

Troubleshoot

Cannot connect to the Docker daemon at unix:///var/run/docker.sock. Is the docker daemon running?
Nguyên nhân: Chưa bật Privileged mode.
Giải pháp: Edit project → Environment → bật Privileged, chạy lại build.
An error occurred (AccessDeniedException) when calling the GetAuthorizationToken operation / denied: User ... is not authorized to perform: ecr:InitiateLayerUpload
Nguyên nhân: Service role chưa có quyền ECR.
Giải pháp: Gắn policy AmazonEC2ContainerRegistryPowerUser như Bước 4.
name unknown: The repository with name 'nodejs-random-color' does not exist
Nguyên nhân: Chưa tạo ECR repository, tạo khác region, hoặc khác tên với biến IMAGE_REPO_NAME.
Giải pháp: Kiểm tra lại Bước 1.
toomanyrequests: You have reached your pull rate limit
Nguyên nhân: Dockerfile vẫn dùng base image từ Docker Hub (FROM node:14) – CodeBuild pull ẩn danh, dùng chung IP với nhiều khách hàng khác.
Giải pháp: Dùng base image public.ecr.aws/docker/library/node:20-alpine như Bước 2. Nếu bắt buộc dùng Docker Hub: lưu username/token vào Secrets Manager, khai báo trong buildspec bằng env.secrets-manager và chạy docker login ở phase pre_build (service role cần quyền secretsmanager:GetSecretValue).

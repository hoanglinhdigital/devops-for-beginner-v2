9. CI/CD với AWS CodePipeline / Lab 3: CodeBuild – Build Node.js (Webpack), upload file tĩnh lên S3

Mục tiêu

  • Build project Vue + Webpack bằng CodeBuild: npm install → npm run build.
  • Truyền tên bucket qua Environment variables của CodeBuild project thay vì hard-code trong buildspec.
  • Upload file tĩnh trong thư mục dist/ lên S3 bằng lệnh aws s3 cp và cấp quyền tối thiểu (least privilege) cho service role.

Yêu cầu trước khi bắt đầu

  • Hoàn thành Lab 1 (repository simple-vue-webpack, connection, S3 bucket) và Lab 2 (đã quen màn hình tạo CodeBuild project).
  • Source code: sourcecode/section_9_code_pipeline/lab3_codebuild_nodejs/ (buildspec.yml, s3-upload-policy.json).

Các bước thực hành

  1. Bước 1: Thêm buildspec.yml vào repository

    Tạo file buildspec.yml tại thư mục gốc repository simple-vue-webpack, copy nội dung từ lab3_codebuild_nodejs/buildspec.yml:

    version: 0.2

# Biến S3_BUCKET được khai báo trong phần Environment variables của CodeBuild project
phases:
  install:
    runtime-versions:
      nodejs: 20
    commands:
      - echo Installing NPM dependencies...
      - npm install
  build:
    commands:
      - echo Build started on `date`
      - npm run build
  post_build:
    commands:
      - echo Build completed on `date`
      - echo Uploading static files to s3://$S3_BUCKET/nodejs_artifacts/
      - aws s3 cp --recursive ./dist s3://$S3_BUCKET/nodejs_artifacts/

cache:
  paths:
    - 'node_modules/**/*'
    cd ~/codepipeline-labs/simple-vue-webpack
git add buildspec.yml
git commit -m "ci: add buildspec for CodeBuild"
git push origin master
  2. Bước 2: Tạo CodeBuild project

    Tạo build project với các thông số (những mục không nêu để giống Lab 2):

    • Project name: nodejs-webpack-build
    • Source: GitHub (connection github-connection), Repository <your-github-username>/simple-vue-webpack, Source version master
    • Environment: Managed image, Amazon Linux, Standard, aws/codebuild/amazonlinux-x86_64-standard:5.0, 3 GB / 2 vCPUs
    • Service role: New service role, tên codebuild-nodejs-webpack-build-service-role
    • Environment variables: Name S3_BUCKET, Value codebuild-artifact-<your-suffix>, Type Plaintext
    • Buildspec: Use a buildspec file
    • Artifacts: No artifacts (file được upload bằng lệnh aws s3 cp trong buildspec)
    • Logs: CloudWatch logs, Group name /codebuild/nodejs-webpack-build
  3. Bước 3: Cấp quyền upload S3 cho service role

    Vì chọn No artifacts, service role do CodeBuild tạo không có quyền ghi vào bucket. Vào IAM → Roles → codebuild-nodejs-webpack-build-service-role, tạo inline policy tên s3-upload-static-files với nội dung JSON từ file s3-upload-policy.json (thay <your-suffix>):

    {
    "Version": "2012-10-17",
    "Statement": [
        {
            "Sid": "AllowUploadStaticFiles",
            "Effect": "Allow",
            "Action": [
                "s3:PutObject",
                "s3:GetObject",
                "s3:ListBucket"
            ],
            "Resource": [
                "arn:aws:s3:::codebuild-artifact-<your-suffix>",
                "arn:aws:s3:::codebuild-artifact-<your-suffix>/*"
            ]
        }
    ]
}

    💡 Đây là cách cấp quyền theo nguyên tắc least privilege: chỉ đúng action, đúng bucket cần dùng, thay vì gắn AmazonS3FullAccess.

  4. Bước 4: Chạy build

    Start build project nodejs-webpack-build. Trong Build logs, quan sát output của webpack (danh sách file được sinh ra) và các dòng upload: dist/... to s3://... ở phase POST_BUILD.

  5. Bước 5: Kiểm tra file tĩnh trên S3 
    aws s3 ls s3://codebuild-artifact-<your-suffix>/nodejs_artifacts/ --recursive

    (Tuỳ chọn) Tải về và mở index.html bằng browser để xem ứng dụng Vue:

    aws s3 sync s3://codebuild-artifact-<your-suffix>/nodejs_artifacts/ ./vue-dist
ls ./vue-dist

    💡 Trong thực tế, thư mục này thường là một S3 bucket bật static website hoặc làm origin cho CloudFront (Section 4 – Chapter 6).

Kiểm tra kết quả

✅ Lab thành công khi

  • Build của nodejs-webpack-build ở trạng thái Succeeded.
  • S3 có các file index.html, file JS/CSS trong prefix nodejs_artifacts/.

Troubleshoot

upload failed: ... An error occurred (AccessDenied) when calling the PutObject operation
Nguyên nhân: Service role chưa có quyền ghi vào bucket, hoặc ARN trong inline policy sai tên bucket.
Giải pháp: Kiểm tra lại Bước 3, tên bucket trong policy phải trùng với biến S3_BUCKET.
Parameter validation failed: Invalid bucket name ""
Nguyên nhân: Chưa khai báo biến môi trường S3_BUCKET trong CodeBuild project.
Giải pháp: Edit project → Environment → Additional configuration → Environment variables, thêm S3_BUCKET.
npm ERR! code ERESOLVE hoặc lỗi build webpack
Nguyên nhân: Phiên bản Node.js không tương thích với dependency.
Giải pháp: Kiểm tra nodejs: 20 trong runtime-versions; chạy thử npm install && npm run build trên máy local để tái hiện lỗi.

Dọn dẹp resource

Có thể xoá prefix nodejs_artifacts/ trên S3 nếu không cần. Giữ lại CodeBuild project để tham khảo – không phát sinh chi phí khi không build.
aws s3 rm s3://codebuild-artifact-<your-suffix>/nodejs_artifacts/ --recursive

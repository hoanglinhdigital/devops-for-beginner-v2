9. CI/CD với AWS CodePipeline / AWS CodeBuild & file buildspec.yml

Giới thiệu

AWS CodeBuild là dịch vụ build & test được AWS quản lý: nó lấy source code, biên dịch, chạy test và tạo ra các software package sẵn sàng để deploy. Mỗi lần build, CodeBuild khởi tạo một container sạch từ build image (Amazon Linux, Ubuntu, Windows...), thực thi các lệnh khai báo trong file buildspec.yml, rồi đẩy kết quả (artifact) lên S3 và log lên CloudWatch Logs. Bạn không cần duy trì build server – chỉ trả tiền cho số phút build thực tế.

Đặc điểm chính

  • Tự động hoá: build được kích hoạt thủ công, theo webhook (push, pull request) hoặc như một stage trong CodePipeline.
  • Có thể mở rộng: chạy nhiều build song song, không phải xếp hàng chờ build agent như Jenkins tự host.
  • Môi trường build linh hoạt: dùng managed image có sẵn runtime (Java, Node.js, Python, Go, .NET, Docker...) hoặc custom image của bạn trên ECR.
  • Bảo mật: mỗi build chạy trong container cô lập, quyền truy cập AWS qua service role; có thể chạy trong VPC để truy cập resource private (RDS, ElastiCache).
  • Tích hợp: CodePipeline, S3, ECR, Secrets Manager, Parameter Store, CloudWatch Logs; đọc source từ GitHub, Bitbucket, GitLab, CodeCommit, S3.
  • Hiệu quả chi phí: trả tiền theo phút build, không tốn chi phí khi không build.

Cấu trúc file buildspec.yml

version: 0.2                  # bắt buộc, phiên bản cú pháp buildspec

env:                          # (tuỳ chọn) biến môi trường
  variables:
    IMAGE_REPO_NAME: my-app   # biến thường
  parameter-store:
    DB_HOST: /myapp/db-host   # lấy từ SSM Parameter Store
  secrets-manager:
    DOCKERHUB_TOKEN: dockerhub-credentials:token   # secret-id:json-key

phases:
  install:                    # cài runtime, công cụ cần thiết
    runtime-versions:
      nodejs: 20
    commands:
      - npm install
  pre_build:                  # chuẩn bị: login registry, chạy lint, unit test...
    commands:
      - echo Logging in...
  build:                      # lệnh build chính
    commands:
      - npm run build
  post_build:                 # sau build: push image, upload file, ghi file output
    commands:
      - echo Build completed on `date`

artifacts:                    # file nào được đóng gói thành output artifact
  files:
    - dist/**/*
  discard-paths: no

cache:                        # cache thư mục giữa các lần build để build nhanh hơn
  paths:
    - 'node_modules/**/*'
  • Các phase chạy tuần tự: install → pre_build → build → post_build. Nếu một lệnh trả về exit code khác 0, phase đó thất bại và build dừng (riêng post_build vẫn chạy sau khi build lỗi).
  • Mỗi lệnh chạy trong cùng một shell của phase, nên biến gán ở lệnh trước dùng được ở lệnh sau (với buildspec version 0.2).
  • Biến môi trường có sẵn: AWS_DEFAULT_REGION, CODEBUILD_BUILD_NUMBER, CODEBUILD_RESOLVED_SOURCE_VERSION (commit SHA), CODEBUILD_SRC_DIR...
  • Không ghi password vào buildspec: dùng parameter-store hoặc secrets-manager, service role cần quyền đọc tương ứng.

Use Cases

Build & đóng gói ứng dụng

Build file .jar từ project Maven, file tĩnh từ project Webpack/React, đẩy artifact lên S3 để deploy (Lab 2, Lab 3).

Build Docker image

Build image từ Dockerfile, đánh tag theo commit SHA và push lên ECR – đầu vào cho deploy ECS/EKS (Lab 4).

Chạy test & kiểm tra chất lượng

Chạy unit test, integration test, lint, quét bảo mật cho mỗi Pull Request; xuất test report để xem trực tiếp trên Console.

Thông tin bổ sung

  • Privileged mode: bắt buộc bật khi build Docker image (cần quyền chạy Docker daemon trong container build).
  • Timeout: mặc định 60 phút, có thể cấu hình từ 5 phút đến 36 giờ. Build quá lâu thường do không dùng cache.
  • Cache: Local cache (nhanh, nằm trên build host, có thể mất) hoặc S3 cache (bền hơn). Cache ~/.m2, node_modules giúp giảm đáng kể thời gian build.
  • Compute type: chọn loại nhỏ nhất đủ dùng (ví dụ 3 GB / 2 vCPU) để tiết kiệm; có thêm lựa chọn Lambda compute cho build ngắn, khởi động gần như tức thì.
  • Docker Hub rate limit: CodeBuild pull image ẩn danh từ Docker Hub dễ bị lỗi toomanyrequests. Dùng base image từ Amazon ECR Public Gallery (public.ecr.aws/docker/library/...) hoặc đăng nhập Docker Hub bằng token lưu trong Secrets Manager.
  • Danh sách runtime hỗ trợ: tra cứu tại tài liệu “Available runtimes” của CodeBuild – mỗi build image hỗ trợ một tập phiên bản Java/Node.js/Python khác nhau.

9. CI/CD với AWS CodePipeline / Giới thiệu AWS Developer Tools

Mục tiêu của section

  • Hiểu vai trò của các dịch vụ CodeCommit, CodeBuild, CodeDeploy, CodePipeline trong một luồng CI/CD trên AWS.
  • Sử dụng CodeBuild để build các loại project phổ biến: Java (Maven), Node.js (Webpack), Docker image.
  • Kết hợp các dịch vụ trong CodePipeline để deploy tự động lên Elastic Beanstalk và Amazon ECS.
  • Tìm hiểu & thực hành các chiến lược deployment: Rolling update, Blue/Green, Canary với CodeDeploy.
  • Thêm bước Manual approval và notification vào pipeline – mô phỏng quy trình release thực tế.

Giới thiệu

Ở Section 3 bạn đã biết CI/CD là một chuỗi các bước tự động: lấy source code → build → test → deploy. Có nhiều công cụ để hiện thực hoá chuỗi này (Jenkins, GitHub Actions, GitLab CI...). Trên AWS, nhóm dịch vụ AWS Developer Tools cung cấp sẵn từng mảnh ghép dưới dạng managed service – bạn không cần cài đặt, vá lỗi hay scale server CI/CD, chỉ cần cấu hình và trả tiền theo mức sử dụng. Bốn dịch vụ cốt lõi là CodeCommit (lưu source code), CodeBuild (build & test), CodeDeploy (deploy) và CodePipeline (điều phối toàn bộ luồng).

Các dịch vụ chính

AWS CodeCommit

Dịch vụ Git repository được AWS quản lý: lưu trữ source code, cấu hình, tài liệu trong kho Git riêng tư; mã hoá dữ liệu at-rest & in-transit; phân quyền bằng IAM; tích hợp trực tiếp với CodeBuild, CodePipeline.

AWS CodeBuild

Dịch vụ build & test: biên dịch source code, chạy unit test, tạo ra artifact (file .jar, file tĩnh, Docker image) dựa trên file cấu hình buildspec.yml. Mỗi lần build chạy trong một container sạch, tự scale, trả tiền theo phút build.

AWS CodeDeploy

Dịch vụ deploy tự động lên EC2 / On-premises, AWS Lambda, Amazon ECS. Hỗ trợ các chiến lược In-place, Blue/Green, Canary, Linear; tự động rollback khi deploy lỗi hoặc khi CloudWatch Alarm kích hoạt.

AWS CodePipeline

Dịch vụ điều phối (orchestration) luồng CI/CD: định nghĩa các stage (Source → Build → Approval → Deploy), tự động chạy mỗi khi có commit mới, truyền artifact giữa các stage và tích hợp được cả công cụ bên thứ ba (GitHub, Jenkins...).

Đặc điểm chung

  • Fully managed: không có server CI/CD để cài đặt, vá lỗi, backup – khác với việc tự dựng Jenkins trên EC2.
  • Pay-as-you-go: CodeBuild tính theo phút build, CodePipeline V2 tính theo phút chạy action, CodeDeploy miễn phí khi deploy lên EC2/Lambda/ECS.
  • Bảo mật với IAM: mỗi dịch vụ chạy bằng một service role, không cần lưu access key trong pipeline.
  • Tích hợp sâu với AWS: S3 (artifact), ECR (image), Elastic Beanstalk, ECS, Lambda, CloudWatch Logs, SNS, Secrets Manager.
  • Kết hợp linh hoạt: có thể dùng riêng lẻ (chỉ CodeBuild) hoặc ghép với GitHub, Bitbucket, GitLab qua AWS CodeConnections.
  • Hỗ trợ chiến lược deployment nâng cao: Blue/Green, Canary, Linear kèm tự động rollback – khó tự làm nếu chỉ dùng script.

Use Cases

Startup chạy 100% trên AWS

Team nhỏ, không có người chuyên vận hành Jenkins: dùng GitHub + CodePipeline + CodeBuild để mỗi lần merge vào main là tự động build Docker image và deploy lên ECS Fargate.

Release an toàn cho hệ thống production

Doanh nghiệp cần deploy không downtime, có bước phê duyệt của Team Lead: CodePipeline với stage Manual approval + CodeDeploy Blue/Green, rollback tự động khi lỗi.

Kết hợp với công cụ sẵn có

Team đã dùng GitHub Actions cho CI nhưng muốn deploy canary cho Lambda/ECS: gọi CodeDeploy từ workflow, tận dụng traffic shifting và rollback theo CloudWatch Alarm.

Thông tin bổ sung

Về CodeCommit: từ 07/2024 AWS ngừng cho phép tài khoản mới tạo repository CodeCommit; đến 11/2025 AWS thông báo CodeCommit hoạt động trở lại đầy đủ (xem Section 7 – Lab 8). Để mọi học viên đều làm được, các lab trong section này dùng GitHub làm source và kết nối với AWS qua AWS CodeConnections (tên cũ: CodeStar Connections). Nếu bạn muốn dùng CodeCommit, chỉ cần chọn Source provider là CodeCommit – các bước còn lại không đổi.
  • Chi phí tham khảo (region Singapore): CodeBuild tính theo phút build tuỳ loại compute (instance nhỏ nhất vài cent/10 phút); CodePipeline V2 tính theo phút chạy action (có quota miễn phí hằng tháng); CodeDeploy miễn phí khi deploy lên EC2, Lambda, ECS. Luôn kiểm tra trang Pricing chính thức trước khi dùng.
  • Chi phí lớn nhất thường nằm ở resource đích (ALB, ECS task, EC2 của Elastic Beanstalk), không phải ở bản thân pipeline. Hãy dọn dẹp sau mỗi lab.
  • Region: tất cả lab dùng ap-southeast-1 (Singapore). Pipeline, CodeBuild project, S3 artifact bucket, ECR nên cùng region.
  • Chứng chỉ: các dịch vụ này xuất hiện nhiều trong đề thi AWS Developer Associate (DVA) và DevOps Engineer Professional (DOP) – đặc biệt là cấu trúc buildspec.yml, appspec.yml và các deployment configuration.

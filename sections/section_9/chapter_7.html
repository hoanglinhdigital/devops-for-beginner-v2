9. CI/CD với AWS CodePipeline / AWS CodePipeline & AWS CodeDeploy

Giới thiệu

AWS CodePipeline là dịch vụ điều phối luồng CI/CD: bạn định nghĩa một chuỗi bước gọi là pipeline, và mỗi khi có thay đổi code, pipeline tự động chạy qua các bước build, test, phê duyệt và deploy. AWS CodeDeploy là dịch vụ chuyên thực hiện bước deploy lên EC2/On-premises, AWS Lambda và Amazon ECS, hỗ trợ các chiến lược triển khai giảm downtime như Blue/Green, Canary và tự động rollback. Hai dịch vụ này kết hợp với CodeBuild tạo thành một luồng CI/CD hoàn chỉnh trên AWS.

AWS CodePipeline

Đặc điểm chính

  • Tự động hoá end-to-end: trigger khi push code (webhook qua CodeConnections), khi có image mới trên ECR, file mới trên S3 hoặc theo lịch (EventBridge).
  • Mô hình Stage – Action: mỗi stage chứa một hoặc nhiều action chạy tuần tự hoặc song song (Source, Build, Test, Approval, Deploy, Invoke Lambda...).
  • Artifact store: output của action này (source code, file build) được lưu trên S3 và làm input cho action kế tiếp.
  • Tích hợp rộng: GitHub, GitLab, Bitbucket, CodeCommit, ECR, S3, CodeBuild, Jenkins, CodeDeploy, ECS, Elastic Beanstalk, CloudFormation, Lambda...
  • Pipeline type V2: hỗ trợ trigger theo branch/tag/file path, biến pipeline, execution mode Queued / Superseded / Parallel, rollback stage.
  • Quan sát & kiểm soát: lịch sử execution, Release change thủ công, Stop execution, Manual approval, notification qua SNS / Chatbot.

AWS CodeDeploy

Đặc điểm chính

  • Triển khai tự động lên 3 loại compute platform: EC2/On-premises, AWS Lambda, Amazon ECS.
  • Giảm downtime: hỗ trợ In-place (rolling), Blue/Green, Canary, Linear – chuyển traffic dần dần thông qua Load Balancer hoặc Lambda alias.
  • Tự động rollback khi deployment thất bại hoặc khi CloudWatch Alarm chuyển sang trạng thái ALARM.
  • Lifecycle hooks: chạy script/Lambda kiểm thử ở từng giai đoạn (ví dụ BeforeAllowTraffic, AfterAllowTestTraffic).
  • Chi phí: miễn phí khi deploy lên EC2, Lambda, ECS; chỉ tính phí với máy On-premises.

  • Application: tên logic nhóm các deployment group, gắn với một compute platform.
  • Deployment group: tập target được deploy (nhóm EC2 theo tag/ASG, Lambda function, hoặc ECS service + ALB + Target Group) kèm deployment configuration, rollback, alarm.
  • Deployment configuration: quy tắc chuyển traffic / số lượng instance mỗi đợt, ví dụ CodeDeployDefault.ECSAllAtOnce, ECSCanary10Percent5Minutes, ECSLinear10PercentEvery1Minutes.
  • Revision: phiên bản cần deploy, mô tả bằng file AppSpec (appspec.yml/appspec.yaml).
  • Service role: IAM role để CodeDeploy thao tác ECS, ELB, Auto Scaling... (managed policy AWSCodeDeployRoleForECS cho ECS).

Use Cases

Web app Java trên Elastic Beanstalk

Mỗi commit lên main được build thành .jar và deploy lên environment Elastic Beanstalk, không cần thao tác tay (Lab 5).

Microservice container trên ECS

Pipeline build image, push ECR và cập nhật ECS service. Service quan trọng dùng Blue/Green để kiểm thử trước khi chuyển traffic (Lab 6, Lab 7).

Serverless với Lambda

CodeDeploy dịch chuyển traffic của Lambda alias theo Canary 10% trong 5 phút, tự rollback khi alarm tỷ lệ lỗi kích hoạt (sẽ gặp lại ở section AWS SAM).

Thông tin bổ sung

  • Pipeline V1 vs V2: V1 tính phí theo pipeline active/tháng; V2 tính theo phút chạy action và có nhiều tính năng hơn – nên dùng V2 cho pipeline mới.
  • Execution mode: Superseded (mặc định – execution mới thay thế execution cũ đang chờ), Queued (xử lý lần lượt), Parallel (chạy song song, chỉ V2).
  • Artifact bucket: CodePipeline tự tạo bucket codepipeline-<region>-... nếu bạn không chỉ định. Nhớ dọn file cũ để tiết kiệm chi phí.
  • ECS native Blue/Green: từ 2025, Amazon ECS hỗ trợ Blue/Green, Canary, Linear ngay trong ECS (deployment controller ECS) mà không cần CodeDeploy. Section này dùng CodeDeploy để bạn hiểu rõ cơ chế và phục vụ ôn thi; với dự án mới hãy cân nhắc tính năng native của ECS.
  • Giới hạn: mỗi pipeline tối đa 50 stage, mỗi stage tối đa 50 action; artifact tối đa vài GB (xem trang Quotas của CodePipeline).

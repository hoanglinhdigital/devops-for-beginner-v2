Checklist dọn dẹp resource

Các resource tính phí theo giờ cần xoá ngay: EC2 của Elastic Beanstalk, ALB, task Fargate, Public IPv4, NAT Gateway (nếu bạn tự tạo thêm). Các resource lưu trữ (S3, ECR, CloudWatch Logs) tính phí theo dung lượng.

  1. Elastic Beanstalk: terminate environment java-beanstalk-dev, xoá application java-beanstalk-app (Lab 5).

  2. Pipeline & CodeDeploy: xoá các pipeline còn lại, CodeDeploy application nodejs-ecs-app, deployment configuration ECSCanary25Percent5Minutes, notification rule và SNS topic (Lab 6 → Lab 9).

  3. ECS stack: chạy terraform destroy nếu chưa xoá:

    cd sourcecode/section_9_code_pipeline/terraform_ecs_stack
terraform destroy

  4. Kiểm tra lại trên Console (region Singapore): EC2 instances, Load Balancers, Target Groups, NAT Gateways, Elastic IPs – không còn resource của lab.

  5. ECR: xoá image cũ hoặc xoá repository nodejs-random-color:

    aws ecr delete-repository --repository-name nodejs-random-color --force --region ap-southeast-1

  6. S3: làm rỗng và xoá bucket codebuild-artifact-<your-suffix> và bucket artifact do CodePipeline tự tạo (codepipeline-ap-southeast-1-...):

    aws s3 rb s3://codebuild-artifact-<your-suffix> --force
aws s3 ls | grep codepipeline-ap-southeast-1

  7. CloudWatch Logs: xoá các log group /codebuild/..., /ecs/nodejs-random-color, /aws/elasticbeanstalk/....

  8. Giữ lại để tham khảo (không tính phí khi không chạy): GitHub repository, CodeBuild project, connection github-connection, các IAM role.

Tài liệu tham khảo

  • AWS CodeBuild – Build specification reference và Docker images provided by CodeBuild / Available runtimes.
  • AWS CodePipeline – Image definitions file reference (imagedefinitions.json, imageDetail.json).
  • AWS CodePipeline – Tutorial: Create a pipeline with an Amazon ECR source and ECS-to-CodeDeploy deployment.
  • AWS CodeDeploy – AppSpec file reference và Deployment configurations.
  • Amazon ECS – Deployment types (rolling update, blue/green, canary, linear).

Chủ đề nên tìm hiểu thêm

  • Tự động rollback bằng CloudWatch Alarm gắn với deployment group, lifecycle hooks AfterAllowTestTraffic chạy smoke test bằng Lambda.
  • Pipeline nhiều môi trường: Dev → Staging → (Approval) → Production, cross-account deployment.
  • Định nghĩa pipeline bằng IaC (Terraform aws_codepipeline, CloudFormation, CDK) thay vì thao tác Console.
  • So sánh với các công cụ CI/CD khác trong khoá học: Jenkins và GitHub Actions – cùng khái niệm CI/CD, khác công cụ.

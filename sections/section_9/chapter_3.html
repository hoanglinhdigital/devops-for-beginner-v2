9. CI/CD với AWS CodePipeline / Lab 1: Chuẩn bị source code trên GitHub & tạo kết nối GitHub

Mục tiêu

  • Fork 3 repository mẫu (Java, Node.js Webpack, Node.js Docker) về GitHub account của bạn và clone về máy.
  • Tạo GitHub connection bằng AWS CodeConnections để CodeBuild, CodePipeline đọc được source code và nhận webhook.
  • Tạo S3 bucket dùng chung để lưu artifact cho các lab sau.

Yêu cầu trước khi bắt đầu

  • Tài khoản GitHub đã cấu hình SSH key (Section 7 – Lab 2).
  • Git Bash (Windows) hoặc Terminal (MacOS/Linux), AWS CLI v2 đã cấu hình profile (Section 5 – Lab 1).
  • Tài khoản AWS, đăng nhập Console bằng IAM user có quyền Administrator (khuyến nghị cho môi trường học).
  • Source code: sourcecode/section_9_code_pipeline/lab1_prepare_source/commands.sh.

Các bước thực hành

  1. Bước 1: Fork 3 repository mẫu

    Truy cập từng repository dưới đây trên GitHub và Fork về account của bạn, giữ nguyên tên repository (các lab sau dùng đúng tên này):

    RepositoryBranchỨng dụngDùng cho
    https://github.com/hoanglinhdigital/java-elasticbeanstalk-samplemainSpring Boot (Maven), port 5000Lab 2, Lab 5
    https://github.com/hoanglinhdigital/simple-vue-webpackmasterVue 3 + Webpack, build ra file tĩnhLab 3
    https://github.com/hoanglinhdigital/nodejs-random-colormasterExpress, port 3000, có DockerfileLab 4, Lab 6 → Lab 9
  2. Bước 2: Clone repository về máy

    Thay <your-github-username> bằng username GitHub của bạn:

    mkdir -p ~/codepipeline-labs
cd ~/codepipeline-labs
git clone git@github.com:<your-github-username>/java-elasticbeanstalk-sample.git
git clone git@github.com:<your-github-username>/simple-vue-webpack.git
git clone git@github.com:<your-github-username>/nodejs-random-color.git
ls

    Kiểm tra branch mặc định – các lab sau sẽ push lên đúng branch này:

    git -C java-elasticbeanstalk-sample branch --show-current
main
git -C simple-vue-webpack branch --show-current
master
git -C nodejs-random-color branch --show-current
master
  3. Bước 3: Tạo GitHub connection (AWS CodeConnections)

    Vào Developer Tools → Settings → Connections (region Singapore), tạo connection với các thông số:

    • Provider: GitHub
    • Connection name: github-connection
    • GitHub App: chọn Install a new app → đăng nhập GitHub → cài app AWS Connector for GitHub cho account của bạn, phạm vi Only select repositories → chọn 3 repository vừa fork.

    Sau khi hoàn tất, connection phải ở trạng thái Available. Connection này được dùng chung cho CodeBuild (Lab 2 → Lab 4) và CodePipeline (Lab 5 → Lab 9).

    CodeConnections (tên cũ: CodeStar Connections) dùng GitHub App nên không cần tạo Personal Access Token hay lưu password GitHub trên AWS. Nếu connection ở trạng thái Pending, chọn connection và hoàn tất bước Update pending connection.
  4. Bước 4: Tạo S3 bucket chứa artifact

    Tên bucket là duy nhất toàn cầu, thay <your-suffix> bằng tên/ngày của bạn (ví dụ codebuild-artifact-linh-20261025):

    aws s3 mb s3://codebuild-artifact-<your-suffix> --region ap-southeast-1
aws s3 ls

    Hoặc tạo trên S3 Console với thông số: Region ap-southeast-1, Block all public access: On, các thiết lập khác để mặc định.

Kiểm tra kết quả

✅ Lab thành công khi

  • GitHub account của bạn có 3 repository đã fork, thư mục ~/codepipeline-labs có 3 bản clone.
  • Connection github-connection ở trạng thái Available.
  • Lệnh aws s3 ls hiển thị bucket codebuild-artifact-<your-suffix>.

Troubleshoot

git@github.com: Permission denied (publickey) khi clone
Nguyên nhân: SSH key chưa được thêm vào GitHub hoặc ssh-agent chưa load key.
Giải pháp: Xem lại Section 7 – Lab 2, kiểm tra bằng ssh -T git@github.com; hoặc clone bằng HTTPS.
Không thấy repository khi chọn source ở CodeBuild/CodePipeline
Nguyên nhân: GitHub App chỉ được cấp quyền cho một số repository.
Giải pháp: Trên GitHub vào Settings → Applications → AWS Connector for GitHub → Configure, thêm repository cần dùng.
BucketAlreadyExists khi tạo bucket
Nguyên nhân: Tên bucket đã có người dùng (tên S3 là duy nhất toàn cầu).
Giải pháp: Đổi suffix khác, ví dụ thêm ngày tháng.

Dọn dẹp resource

Giữ lại repository, connection và S3 bucket để dùng cho các lab tiếp theo. Connection và S3 bucket rỗng không phát sinh chi phí đáng kể; hướng dẫn xoá ở chương Tổng kết.

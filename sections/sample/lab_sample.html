22. Container service – ECS, ECR / Lab 5: ECS Cluster – Run Service với ALB

Mục tiêu

  • Tạo Target Group (type IP) và Application Load Balancer (listener 80).
  • Tạo ECS Service chạy nhiều task Fargate, kết nối với ALB.
  • Truy cập ứng dụng qua DNS của ALB.
  • Thử thay đổi số lượng task (scale) và quan sát service tự thay thế task bị dừng.

Yêu cầu trước khi bắt đầu

  • Hoàn thành Lab 3 và Lab 4: có cluster ecs-demo-cluster, task definition my-httpd-task và image trên ECR.
  • Đã hiểu về Application Load Balancer và Target Group (xem section Load Balancer).
  • Region ap-southeast-1, Default VPC có ít nhất 2 public subnet ở 2 AZ khác nhau.

Các bước thực hành

  1. Bước 1: Tạo Security Group cho ALB và cho Service

    Vào EC2 → Security Groups tạo 2 Security Group trong Default VPC:

    • alb-sg: Inbound HTTP (TCP 80) từ 0.0.0.0/0
    • ecs-service-sg: Inbound HTTP (TCP 80) với Source là Security Group alb-sg (chỉ cho phép traffic đi qua ALB)
  2. Bước 2: Tạo Target Group

    Vào EC2 → Target Groups → Create target group với các thông số:

    • Target type: IP addresses (bắt buộc với Fargate vì task dùng network mode awsvpc)
    • Name: ecs-httpd-tg
    • Protocol : Port: HTTP : 80
    • VPC: Default VPC
    • Health check path: /
    • Register targets: không thêm gì, ECS Service sẽ tự đăng ký task vào target group
  3. Bước 3: Tạo Application Load Balancer

    Vào EC2 → Load Balancers → Create Application Load Balancer với các thông số:

    • Name: ecs-demo-alb
    • Scheme: Internet-facing, IP address type: IPv4
    • Network mapping: Default VPC, chọn ít nhất 2 AZ (public subnet)
    • Security group: alb-sg (bỏ Security Group default)
    • Listener: HTTP : 80 → Forward to ecs-httpd-tg
  4. Bước 4: Tạo ECS Service

    Vào cluster ecs-demo-cluster → tab Services → Create với các thông số:

    • Task definition family: my-httpd-task (revision mới nhất)
    • Service name: my-httpd-service
    • Compute options: Launch type = FARGATE
    • Service type: Replica, Desired tasks: 2
    • Networking: Default VPC, các public subnet, Security group: ecs-service-sg (bỏ Security Group default), Public IP: Turned on (vì không dùng NAT Gateway)
    • Load balancing: type Application Load Balancer, chọn Use an existing load balancer = ecs-demo-alb, Container to load balance = httpd 80:80, Listener = 80:HTTP (existing), Target group = ecs-httpd-tg
    • Health check grace period: 30 giây
  5. Bước 5: Chờ service ổn định và test qua ALB

    Đợi các task chuyển sang RUNNING (khoảng 2–3 phút). Vào Target Groups → ecs-httpd-tg → Targets, đợi 2 target có Health status = healthy.

    Vào Load Balancers, copy DNS name của ecs-demo-alb và truy cập http://<alb-dns-name> trên trình duyệt. Bạn sẽ thấy trang Version 1.0.

  6. Bước 6: Scale số lượng task

    Trong Service my-httpd-service chọn Update, đổi Desired tasks từ 2 lên 4 rồi cập nhật. Quan sát danh sách task tăng lên 4 và Target Group có thêm 2 target. Sau đó giảm xuống 1 để quan sát các task bị dừng và được gỡ khỏi Target Group.

  7. Bước 7: Quan sát khả năng tự phục hồi

    Trong tab Tasks, chọn một task đang chạy → Stop. Quan sát service tự tạo task mới để quay về số lượng desired count, trong khi ALB vẫn phục vụ qua các task còn lại.

Kiểm tra kết quả

✅ Lab thành công khi

  • Service my-httpd-service có số task Running bằng Desired count.
  • Target Group ecs-httpd-tg có các target healthy.
  • Truy cập DNS của ALB hiển thị trang Version 1.0.
  • Khi thay đổi Desired tasks hoặc dừng một task, service tự điều chỉnh về số lượng mong muốn.

Troubleshoot

ALB trả về 503 Service Temporarily Unavailable
Nguyên nhân: Chưa có target healthy trong Target Group (task chưa chạy xong hoặc health check thất bại).
Giải pháp: Đợi task RUNNING; kiểm tra tab Targets của Target Group xem lý do unhealthy.
Target unhealthy / health check timeout
Nguyên nhân: Security Group ecs-service-sg chưa cho phép traffic từ alb-sg ở cổng 80, hoặc health check path sai.
Giải pháp: Sửa inbound rule của ecs-service-sg (HTTP 80 từ alb-sg) và đặt health check path là /.
Service liên tục tạo rồi dừng task
Nguyên nhân: ALB health check thất bại trước khi hết health check grace period nên ECS coi task lỗi.
Giải pháp: Tăng health check grace period, kiểm tra container port đúng 80; xem tab Events của Service để biết lý do.
Không chọn được target group khi tạo service
Nguyên nhân: Target group tạo với type Instance thay vì IP.
Giải pháp: Xoá và tạo lại target group với type IP addresses.
CannotPullContainerError
Nguyên nhân: Task không có Public IP và subnet không có NAT Gateway nên không kéo được image từ ECR.
Giải pháp: Cập nhật service bật Public IP (hoặc dùng NAT Gateway/VPC endpoint cho ECR - có phí) rồi force new deployment.

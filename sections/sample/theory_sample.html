7. Computing service – EC2 / Các khái niệm cơ bản & vòng đời EC2

Giới thiệu

Trước khi tạo EC2 đầu tiên, bạn cần nắm một vài khái niệm sẽ gặp liên tục trên AWS Console: AMI, Instance, Instance type, EBS Volume, Snapshot, Key pair. Chương này cũng giới thiệu vòng đời (life cycle) của một instance: các trạng thái và thao tác chuyển trạng thái, cùng với ảnh hưởng của chúng tới dữ liệu và chi phí.

Các khái niệm chính

  • AMI (Amazon Machine Image): giống một file ISO/Ghost chứa toàn bộ hệ điều hành và phần mềm cài sẵn. EC2 được khởi động từ một AMI, tương tự việc cài Windows lần đầu cho PC. Bạn có thể dùng AMI của AWS, của Marketplace, hoặc tự tạo AMI từ instance đang chạy.
  • Instance: một máy chủ ảo được cấp phát tài nguyên CPU, RAM, GPU... Mỗi dòng instance có giới hạn nhất định về tài nguyên và hiệu năng.
  • Instance type: "cấu hình" của instance, ví dụ t3.micro (2 vCPU, 1 GB RAM), m7i.large (2 vCPU, 8 GB RAM).
  • EBS Volume: ổ cứng ảo do AWS cấp phát. Chỉ đọc được dữ liệu khi được gắn (attach) vào một instance.
  • Snapshot: ảnh chụp của một EBS Volume tại một thời điểm, dùng để phục hồi dữ liệu khi có sự cố hoặc tạo volume mới.
  • Key pair: cặp khoá public/private dùng để đăng nhập SSH vào Linux hoặc giải mã mật khẩu Administrator của Windows.

Instance type (Instance class)

Tên instance type có dạng <family><generation><thuộc tính>.<size>. Ví dụ m7g.large: family m (general purpose), thế hệ 7, thuộc tính g (chip Graviton – ARM), kích thước large. Một số ký hiệu thuộc tính hay gặp: g = Graviton, a = AMD, i = Intel, d = có ổ instance store, n = network cao.

T, M
General Purpose
  • Cân bằng CPU/RAM
  • Web server, app server, môi trường dev
  • T là dòng "burstable": rẻ, dùng CPU credit
C
Compute Optimized
  • Tỷ lệ CPU cao
  • Batch processing, encode video, game server
R, X
Memory Optimized
  • Tỷ lệ RAM cao
  • Database, in-memory cache, phân tích dữ liệu lớn
I, D
Storage Optimized
  • Ổ instance store NVMe tốc độ rất cao
  • NoSQL, data warehouse, log processing
P, G, Inf, Trn
Accelerated Computing
  • Có GPU hoặc chip chuyên dụng
  • Train/inference AI, đồ hoạ, render

Danh sách đầy đủ và thông số chi tiết: aws.amazon.com/ec2/instance-types.

Các thao tác cơ bản đối với EC2

Với instance

  • Launch / Reboot / Stop / Start / Terminate instance
  • Thay đổi instance type (cần Stop trước)
  • Create AMI (image) từ instance

Gắn / gỡ tài nguyên

  • Attach / Detach EBS Volume
  • Attach / Detach Elastic IP
  • Attach / Detach Security Group
  • Attach / Detach IAM Role
  • Create Snapshot từ Volume

Vòng đời của EC2 dùng ổ instance store

Ngoài EBS, EC2 hỗ trợ loại ổ instance store: ổ đĩa gắn trực tiếp trên máy host vật lý. Ưu điểm là IOPS rất cao, nhưng dữ liệu sẽ mất khi instance stop, terminate hoặc phần cứng host bị lỗi. Phù hợp cho dữ liệu tạm, cache, buffer cần tốc độ đọc ghi cao.

Use Cases

Nhân bản server bằng AMI

Cài đặt và cấu hình một web server hoàn chỉnh, tạo AMI, rồi launch thêm nhiều instance giống hệt để chạy sau Load Balancer.

Stop instance ngoài giờ làm việc

Môi trường dev/test chỉ cần chạy 8h/ngày. Stop instance buổi tối giúp tiết kiệm tới ~65% chi phí instance.

Backup trước khi nâng cấp

Tạo snapshot ổ root trước khi update OS hoặc ứng dụng. Nếu có lỗi, tạo lại volume từ snapshot để quay về trạng thái cũ.

Thông tin bổ sung

Termination protection: với server quan trọng, hãy bật Termination protection để tránh xoá nhầm instance.
Free Tier: tài khoản mới có thể dùng một số instance type nhỏ (như t3.micro) trong phạm vi Free Tier. Điều kiện Free Tier thay đổi theo thời gian, hãy kiểm tra trang Billing của tài khoản.

15. Elastic Kubernetes Service (EKS) / Lab 1: Tạo một EKS Cluster và kết nối

Mục tiêu

  • Cài đặt sẵn kubectl và eksctl trên máy local.
  • Tạo một EKS Cluster (kèm node group) bằng eksctl.
  • Kết nối tới cluster từ máy local bằng kubectl.

eksctl tạo cluster với control plane (AWS quản lý) và node group (2 EC2 t3.medium). Sau đó bạn cập nhật kubeconfig để kubectl giao tiếp với cluster.

Yêu cầu trước khi bắt đầu

  • Đã cài AWS CLI v2 (chú ý không dùng version quá cũ), kubectl, eksctl, helm.
  • IAM User hiện tại có quyền tạo EKS Cluster (ví dụ AdministratorAccess).
  • Source code: sourcecode/section_14_eks_basic/lab1_create_cluster/.
Mẹo cài đặt: trên Windows nên dùng chocolatey để cài eksctl, kubectl, helm. Link tham khảo: docs.aws.amazon.com/eks/latest/userguide/getting-started-eksctl.html.

Các bước thực hành

  1. Bước 1: Kiểm tra tool và quyền

    Kiểm tra version các tool đã cài:

    aws --version
kubectl version --client
eksctl version
helm version --short

    Xác nhận IAM user hiện tại có quyền:

    aws sts get-caller-identity
  2. Bước 2: Tạo EKS Cluster bằng eksctl

    Tạo file cluster-config.yaml (đã có sẵn trong source code):

    apiVersion: eksctl.io/v1alpha5
kind: ClusterConfig

metadata:
  name: devops-test-cluster
  region: ap-southeast-1

nodeGroups:
  - name: my-nodes
    instanceType: t3.medium
    desiredCapacity: 2
    minSize: 2
    maxSize: 4

    Chạy lệnh tạo cluster (quá trình này mất khoảng 10 phút):

    eksctl create cluster -f cluster-config.yaml

    Disable extended support cho EKS (giúp tiết kiệm chi phí):

    aws eks update-cluster-config --name devops-test-cluster --upgrade-policy supportType=STANDARD
  3. Bước 3: Cập nhật kubeconfig để kết nối cluster

    Cập nhật file ~/.kube/config (trên Windows: C:\Users\<user>\.kube\config):

    aws eks update-kubeconfig --region ap-southeast-1 --name devops-test-cluster

    Kiểm tra context:

    kubectl config get-contexts

    Nếu máy có nhiều cluster, chuyển context về cluster mới tạo:

    kubectl config use-context devops-test-cluster

    Xem thông tin cluster:

    kubectl cluster-info
  4. Bước 4: (Tuỳ chọn) Tạo node group riêng

    Bỏ qua bước này nếu đã tạo cluster có node group ở Bước 2. Nếu cần thêm node group:

    eksctl create nodegroup --cluster=devops-test-cluster --region=ap-southeast-1 --name=my-node-group --node-type=t3.medium --nodes=2 --nodes-min=2 --nodes-max=2 --managed
  5. Bước 5: Kiểm tra node

    Đợi khoảng 5 phút rồi kiểm tra các node của cluster:

    kubectl get nodes
NAME                                               STATUS   ROLES    AGE   VERSION
ip-192-168-13-199.ap-southeast-1.compute.internal  Ready    <none>   5m    v1.29.3-eks
ip-192-168-56-45.ap-southeast-1.compute.internal   Ready    <none>   5m    v1.29.3-eks

    💡 Thấy 2 node với STATUS Ready là thành công.

Kiểm tra kết quả

✅ Lab thành công khi

  • eksctl create cluster hoàn tất không báo lỗi.
  • kubectl cluster-info hiển thị control plane đang chạy tại địa chỉ *.eks.amazonaws.com.
  • kubectl get nodes hiển thị 2 node Ready.

Troubleshoot

kubectl báo lỗi không kết nối được cluster
Nguyên nhân: kubeconfig chưa được cập nhật hoặc context chưa đúng.
Giải pháp: chạy lại aws eks update-kubeconfig --region ap-southeast-1 --name devops-test-cluster và kiểm tra kubectl config get-contexts.
eksctl create cluster báo lỗi thiếu quyền (AccessDenied)
Nguyên nhân: IAM user chưa có quyền tạo EKS/EC2/CloudFormation.
Giải pháp: gán thêm quyền (tạm thời AdministratorAccess hoặc các policy EKS/EC2 tương ứng), kiểm tra lại bằng aws sts get-caller-identity.
Node mãi không Ready
Nguyên nhân: node vẫn đang khởi tạo (join cluster) hoặc thiếu IAM role node.
Giải pháp: đợi thêm 5–10 phút; kiểm tra CloudFormation stack của cluster xem node group đã CREATE_COMPLETE chưa.

Dọn dẹp resource

Chi phí: EKS Cluster tính phí control plane theo giờ, node EC2 t3.medium tính phí theo giờ. Chỉ giữ cluster khi bạn còn làm các lab tiếp theo; xoá khi không dùng.
eksctl delete cluster --name devops-test-cluster --region ap-southeast-1

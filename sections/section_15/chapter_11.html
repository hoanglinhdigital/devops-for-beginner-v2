15. Elastic Kubernetes Service (EKS) / Tổng kết & dọn dẹp resource

Tổng kết section

Qua section này, bạn đã nắm được toàn bộ quy trình làm việc với Amazon EKS:

  • EKS là gì: dịch vụ Kubernetes managed của AWS, AWS lo control plane, bạn lo workload.
  • Tạo cluster: dùng eksctl create cluster và kết nối bằng kubectl.
  • LoadBalancer: dùng AWS Load Balancer Controller để tạo ALB/NLB từ Ingress/Service.
  • Storage: dùng EBS CSI Driver + StorageClass để cấp EBS volume cho Pod.
  • Autoscaling: Cluster Autoscaler (ASG) hoặc Karpenter để scale node.
  • Security: IAM/IRSA, Secret Management, Pod Security, RBAC (Access Entry).

# Storage
kubectl get storageclass / pvc / pv

# Xoá cluster
eksctl delete cluster --name devops-test-cluster --region ap-southeast-1

Dọn dẹp resource

Chi phí: EKS Cluster (control plane), node EC2, ALB/NLB và EBS volume đều tính phí theo giờ. Hãy xoá toàn bộ ngay khi hoàn thành để tránh phát sinh chi phí.
  1. Bước 1: Xoá EKS Cluster 
    eksctl delete cluster --name devops-test-cluster --region ap-southeast-1

    Nếu gặp lỗi "pods are unevictable", xoá các PodDisruptionBudget (PDB) trong kube-system:

    kubectl get pdb -A
kubectl delete pdb coredns -n kube-system
kubectl delete pdb metrics-server -n kube-system

    Nếu vẫn không xoá được:

    eksctl delete cluster --name devops-test-cluster --region ap-southeast-1 --disable-nodegroup-eviction
  2. Bước 2: Kiểm tra và xoá các resource còn sót
    • Load Balancer (ALB/NLB) do Controller tạo (EC2 → Load Balancers).
    • EBS volume còn sót (EC2 → Volumes).
    • IAM user developer01 (nếu đã tạo ở Lab 4).
    • IAM policy AWSLoadBalancerControllerIAMPolicy (nếu không dùng nữa).
    • ECR repository nếu không sử dụng.

Giới thiệu

Amazon Elastic Kubernetes Service (EKS) là dịch vụ quản lý Kubernetes do AWS cung cấp. EKS giúp bạn chạy các ứng dụng container trên AWS mà không cần tự cài đặt, vận hành hay bảo trì phần Control Plane (master node) của Kubernetes. Thay vì phải lo etcd, API Server, Scheduler... như khi dựng cluster bằng kops ở Section 13, với EKS AWS lo toàn bộ phần "bộ não" của cluster cho bạn.

Đặc điểm / tính năng chính

  • Quản lý Kubernetes: EKS tự động xử lý các tác vụ như cài đặt, cập nhật và quản lý các master node (control plane).
  • Tích hợp với các dịch vụ AWS: Load Balancer, Fargate, ECR, S3, VPC, CloudWatch... tạo nền tảng mạnh mẽ cho ứng dụng container.
  • Security & Compliance: hỗ trợ các tính năng bảo mật và tuân thủ của AWS như IAM, VPC và Audit logging.
  • Scalability: hỗ trợ Horizontal Pod Autoscaler và Cluster Autoscaler, giúp mở rộng ứng dụng linh hoạt.
  • Hỗ trợ cộng đồng: hỗ trợ phiên bản Kubernetes mới nhất và tương thích với các công cụ, plugin phổ biến từ cộng đồng.

Mô hình cluster của EKS

Mô hình cluster của EKS
  • Master Node (Control Plane) của cluster do AWS quản lý – bạn không thấy và không phải lo về nó.
  • Worker Node là các EC2 instance, có thể do AWS quản lý (managed node group) hoặc tự quản lý bằng custom AMI (self-managed).
  • EKS có thể kết hợp với Fargate để chạy Pod mà không cần quản lý node.
  • Các instance trong EKS cũng hỗ trợ các purchase options như On-Demand, Reserved, Spot instance...

Chi phí cho EKS

Chi phí của Amazon EKS được tính dựa trên các yếu tố sau:

  • Phí dịch vụ EKS (Master node / control plane): tính phí theo giờ, không phụ thuộc vào kích thước cluster (một cluster dù 1 hay 100 node đều trả phí control plane như nhau).
  • Chi phí cho các resources: EC2 Instance (worker node), EBS/EFS (lưu trữ), Fargate (nếu dùng), Data transfer...
  • Data transfer out: phí dữ liệu truyền từ cluster ra Internet hoặc sang các dịch vụ AWS khác.
  • Dịch vụ bổ sung: các chi phí liên quan đến dịch vụ bổ sung như Monitoring (CloudWatch, Managed Prometheus...).
Tiết kiệm chi phí: bạn có thể disable extended support cho cluster (dùng aws eks update-cluster-config --upgrade-policy supportType=STANDARD) để không bị tính phí hỗ trợ bản Kubernetes quá hạn, và luôn xoá cluster khi không dùng.

Trade-off

✅ Ưu điểm

  • Không phải vận hành control plane: AWS lo cập nhật, backup etcd, đảm bảo HA.
  • Tích hợp sâu với AWS: IAM, VPC, ALB/NLB, EBS/EFS, CloudWatch.
  • Chuẩn Kubernetes upstream: tương thích với công cụ/plugin của cộng đồng.
  • Được AWS hỗ trợ, phù hợp doanh nghiệp cần SLA và compliance.

⚠️ Nhược điểm

  • Phí control plane theo giờ (cao hơn so với tự dựng cluster bằng kops).
  • Vẫn phải quản lý worker node (EC2) nếu không dùng Fargate.
  • Đường cong học tập vẫn cao nếu chưa nắm vững Kubernetes.
  • Với nhu cầu nhỏ, ECS/Fargate có thể đơn giản và rẻ hơn.

Khi nào nên dùng: cần chạy Kubernetes chuẩn, nhiều container cần scale, hoặc muốn tận dụng hệ sinh thái K8s (Helm, ArgoCD, Istio...) mà không muốn tự vận hành control plane. Khi nào không nên: ứng dụng đơn giản chỉ vài container — dùng ECS/Fargate hoặc App Runner nhẹ nhàng hơn.

Use Cases

Nền tảng microservices

Chạy hàng chục service container với service mesh (Istio), GitOps (ArgoCD), Helm chart, scale từng service độc lập.

Ứng dụng cần hybrid / multi-cloud

Dùng cùng manifest Kubernetes chạy trên EKS (AWS), GKE (GCP), AKS (Azure) hoặc on-premise, dễ di chuyển giữa các cloud.

Nền tảng CI/CD & batch/AI workload

Triển khai ArgoCD/Jenkins runner trên EKS, chạy batch job (Spark, ML training) với khả năng scale linh hoạt.

Thông tin bổ sung

  • So với kops (Section 13): kops giúp bạn tự dựng control plane trên EC2 (tự chịu trách nhiệm vận hành), còn EKS là dịch vụ managed — AWS lo control plane, bạn chỉ lo workload.
  • Phiên bản Kubernetes: EKS hỗ trợ nhiều phiên bản; AWS thường xuyên công bố và có lịch trình hỗ trợ (standard/extended) cho từng version.
  • Control plane endpoint: có thể để public (truy cập từ Internet) hoặc private (chỉ trong VPC) tuỳ nhu cầu bảo mật.
  • Tài liệu chính thức: docs.aws.amazon.com/eks.

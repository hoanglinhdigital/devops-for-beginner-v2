6. Thao tác cơ bản với Linux / Tổng kết, lệnh thường dùng khác & dọn dẹp resource

Nội dung đã học

  • Linux là gì, lịch sử, các họ distro (Debian, Red Hat...) và Amazon Linux 2023.
  • Tạo EC2 Linux, kết nối SSH, cấu trúc thư mục và các lệnh làm việc với file/folder.
  • Sử dụng trình soạn thảo Vim và Nano để sửa file cấu hình trên server.
  • Quản lý user, group, quyền sudo; phân quyền file/folder bằng chmod, chown.
  • Quản lý process (ps, top, kill) và service (systemctl, journalctl, tự viết systemd unit).
  • Làm việc với EBS volume: partition, format, mount, /etc/fstab, mở rộng dung lượng.
  • Lập lịch tác vụ với cron job và quản lý SSH key cho thành viên dự án.

Checklist dọn dẹp resource

Trước khi chuyển sang section tiếp theo, hãy xoá toàn bộ resource của section này. EC2 đang chạy, EBS volume (kể cả không gắn vào instance) và Public IPv4/Elastic IP đều tính phí theo giờ.
  1. Bước 1: Terminate EC2 instance

    Vào EC2 → Instances, chọn linux-lab-server → Instance state → Terminate (delete) instance. Root volume sẽ tự xoá theo (mặc định Delete on termination = Yes).

  2. Bước 2: Xoá EBS volume còn sót lại

    Vào EC2 → Volumes, lọc trạng thái Available. Nếu còn linux-lab-data (Lab 7) hoặc volume nào không dùng → Delete volume.

  3. Bước 3: Xoá Elastic IP (nếu có)

    Vào EC2 → Elastic IPs. Nếu đã cấp phát Elastic IP trong quá trình học → Disassociate rồi Release Elastic IP address.

  4. Bước 4: Xoá Security Group và Key pair

    Sau khi instance đã terminated: xoá Security Group linux-lab-sg (EC2 → Security Groups) và key pair linux-lab-key (EC2 → Key Pairs). Hai resource này không tính phí nhưng nên dọn cho gọn. Có thể xoá file linux-lab-key.pem trên PC Local.

  5. Bước 5: Kiểm tra hoá đơn

    Vào Billing and Cost Management → Bills, kiểm tra mục EC2 – Compute và EC2 – Other (EBS, Public IPv4) để chắc chắn không còn chi phí phát sinh.

Thông tin bổ sung

  • Chủ đề nên tìm hiểu thêm: shell script (biến, if/else, vòng lặp, hàm), sed/awk, systemd timer, SELinux, LVM, quản lý log với logrotate, firewall (firewalld/iptables).
  • Trên AWS: Systems Manager (Session Manager, Run Command, Patch Manager) giúp quản lý nhiều server Linux mà không cần SSH thủ công; EC2 User data giúp tự động chạy script cài đặt khi instance khởi động.
  • Tài liệu học thêm: man <lệnh>, linuxjourney.com, explainshell.com (giải thích từng phần của một câu lệnh).
  • Chứng chỉ tham khảo: Linux Foundation Certified System Administrator (LFCS), Red Hat Certified System Administrator (RHCSA).

Các bước thực hành

  1. Bước 1: Tìm hiểu cú pháp cron

    Cron job là công cụ lên lịch thực thi tác vụ tự động vào thời điểm cụ thể (backup database lúc 2h sáng, dọn log mỗi Chủ nhật...). Mỗi dòng cron gồm 5 trường thời gian + lệnh:

    # .---------------- minute (0 - 59)
# |  .------------- hour (0 - 23)
# |  |  .---------- day of month (1 - 31)
# |  |  |  .------- month (1 - 12) OR jan,feb,mar,apr ...
# |  |  |  |  .---- day of week (0 - 6) (Sunday=0 or 7) OR sun,mon,tue,wed,thu,fri,sat
# |  |  |  |  |
# *  *  *  *  * [user-name]  command to be executed
    Biểu thứcÝ nghĩa
    * * * * *Chạy mỗi phút
    */30 * * * *Chạy mỗi 30 phút
    30 1 * * 61:30 sáng mỗi thứ Bảy
    0 2 * * *2:00 sáng hằng ngày (ví dụ backup)
    0 9 1 * *9:00 sáng ngày 1 hằng tháng
    0 8-17 * * 1-5Mỗi giờ đúng từ 8h đến 17h, thứ Hai đến thứ Sáu

    💡 Thời gian cron theo timezone của server (EC2 mặc định là UTC, chậm hơn giờ Việt Nam 7 tiếng). Dùng crontab.guru để kiểm tra biểu thức cron.

  2. Bước 2: Cài đặt cron

    Amazon Linux 2023 không cài sẵn cron (AWS khuyến nghị systemd timer). Cài package cronie và khởi động service crond:

    sudo dnf install -y cronie
sudo systemctl enable --now crond
systemctl status crond
  3. Bước 3: Tạo script

    Tạo file và copy nội dung file script.sh trong source code:

    vim /home/ec2-user/script.sh

    📄 lab8_cronjob/script.sh

    #!/bin/bash
# Script đơn giản ghi log ra file, được cron gọi mỗi phút
LOG_FILE=/home/ec2-user/log.txt

echo "Hello from Cronjob!!! - $(date '+%Y-%m-%d %H:%M:%S') - user: $(whoami)" >> "$LOG_FILE"

    Cấp quyền execute và chạy thử bằng tay trước khi giao cho cron:

    chmod 755 /home/ec2-user/script.sh
/home/ec2-user/script.sh
cat /home/ec2-user/log.txt

    Script dùng đường dẫn tuyệt đối cho file log vì cron không chạy trong thư mục home như khi bạn gõ lệnh.

  4. Bước 4: Cách 1 – crontab của user (crontab -e) 
    crontab -l
no crontab for ec2-user
crontab -e

    Trình soạn thảo Vim mở ra. Nhấn i, thêm dòng sau (crontab của user không có cột user), Esc → :wq:

    * * * * * /home/ec2-user/script.sh
    crontab -l

    Đợi 2–3 phút rồi kiểm tra file log có thêm một dòng mỗi phút. tail -f theo dõi liên tục, nhấn Ctrl + C để thoát:

    cat /home/ec2-user/log.txt
tail -f /home/ec2-user/log.txt

    Xem log của cron daemon (AL2023 ghi log vào journald, không có file /var/log/cron):

    sudo journalctl -u crond --since "10 minutes ago" --no-pager
  5. Bước 5: Cách 2 – crontab hệ thống (/etc/crontab) 
    cat /etc/crontab
sudo vim /etc/crontab

    Thêm dòng sau vào cuối file (crontab hệ thống bắt buộc có cột user), chạy mỗi 2 phút với quyền ec2-user:

    */2 * * * * ec2-user /home/ec2-user/script.sh
    Đặc điểmcrontab -e/etc/crontab, /etc/cron.d/
    Phạm viRiêng từng user (lưu ở /var/spool/cron/<user>)Toàn hệ thống
    Cột userKhông cóBắt buộc có
    Quyền sửaUser tự sửa của mìnhCần sudo
    Xem danh sáchcrontab -l, sudo crontab -l -u <user>cat /etc/crontab, ls /etc/cron.d/

    Không cần restart crond — cron tự phát hiện thay đổi. Sau vài phút, log sẽ có các dòng từ cả 2 cron job.

Troubleshoot

-bash: crontab: command not found
Nguyên nhân: Amazon Linux 2023 chưa cài cron.
Giải pháp: sudo dnf install -y cronie và sudo systemctl enable --now crond.
Cron job không chạy, file log không có dòng mới
Nguyên nhân: Script chưa có quyền execute, service crond chưa chạy, hoặc sai cú pháp (thừa/thiếu cột user).
Giải pháp: Kiểm tra ls -l ~/script.sh, systemctl status crond, sudo journalctl -u crond. Nhớ: crontab -e không có cột user, /etc/crontab phải có.
Script chạy tay được nhưng chạy bằng cron thì lỗi command not found
Nguyên nhân: Cron chạy với biến môi trường tối giản (PATH ngắn, không đọc .bashrc).
Giải pháp: Dùng đường dẫn tuyệt đối cho lệnh và file (ví dụ /usr/bin/aws), hoặc khai báo PATH=... ở đầu crontab/script. Ghi thêm lỗi ra file: * * * * * /home/ec2-user/script.sh >> /home/ec2-user/cron-error.log 2>&1.
Cron job chạy sai giờ so với mong muốn
Nguyên nhân: Server dùng timezone UTC.
Giải pháp: Quy đổi giờ (giờ Việt Nam = UTC + 7), hoặc đổi timezone server bằng sudo timedatectl set-timezone Asia/Ho_Chi_Minh.

Các bước thực hành

  1. Bước 1: Cài đặt Vim và Nano

    Amazon Linux 2023 chỉ có sẵn bản vim-minimal (lệnh vi). Cài bản đầy đủ và Nano bằng trình quản lý gói dnf:

    sudo dnf install -y vim-enhanced nano
vim --version | head -1
nano --version | head -1

    sudo cho phép chạy lệnh với quyền root (cài phần mềm cần quyền quản trị). -y tự động đồng ý, không hỏi lại.

  2. Bước 2: Hiểu các mode của Vim
    flowchart LR N["⌨️ Normal mode
    di chuyển, copy, xoá"] I["✏️ Insert mode
    gõ nội dung"] C["💬 Command mode
    :w :q :wq :q!"] N -->|"i / a / o"| I I -->|"Esc"| N N -->|":"| C C -->|"Enter / Esc"| N

    Vim mở file ở Normal mode: các phím bạn gõ là lệnh chứ không phải nội dung. Muốn gõ nội dung phải chuyển sang Insert mode. Khi bối rối, cứ nhấn Esc để quay về Normal mode.

  3. Bước 3: Tạo file đầu tiên với Vim 
    mkdir -p ~/linux-lab/editor
cd ~/linux-lab/editor
vim sample.txt
    • Nhấn i để vào Insert mode (góc dưới hiện -- INSERT --).
    • Copy nội dung file sample.txt trong source code và dán vào terminal (Git Bash: Shift + Insert hoặc chuột phải → Paste; Mac: Cmd + V).
    • Nhấn Esc, gõ :wq rồi Enter để lưu và thoát.
    cat sample.txt
  4. Bước 4: Thực hành các thao tác trong Vim

    Mở lại file và thử lần lượt các phím trong bảng dưới (ở Normal mode):

    vim sample.txt
    Phím / lệnhChức năng
    i / a / oInsert tại con trỏ / sau con trỏ / mở dòng mới bên dưới
    EscThoát Insert mode, về Normal mode
    :w / :q / :wq / :q!Lưu / thoát / lưu và thoát / thoát không lưu
    dd / yy / pXoá (cut) dòng hiện tại / copy dòng / paste xuống dưới
    5dd / 3yyXoá 5 dòng / copy 3 dòng (số đứng trước lệnh là số lần lặp)
    u / Ctrl + rUndo / Redo
    /từ_khoá, n, NTìm kiếm, tới kết quả tiếp theo / trước đó
    :%s/Linux/LINUX/gThay thế toàn bộ Linux thành LINUX trong file
    :set numberHiển thị số dòng

    Di chuyển con trỏ

    PhímChức năng
    h j k lTrái / xuống / lên / phải (hoặc dùng phím mũi tên)
    w / bĐầu từ tiếp theo / đầu từ trước đó
    0 / $Đầu dòng / cuối dòng
    gg / G / :10Dòng đầu tiên / dòng cuối cùng / tới dòng 10
    Ctrl + f / Ctrl + bXuống / lên một trang
    Ctrl + d / Ctrl + uXuống / lên nửa trang

    Bài tập nhỏ: copy dòng 8 bằng yy rồi paste 2 lần bằng p; xoá dòng 9 bằng dd rồi u để khôi phục; tìm /DevOps; thay thế Linux → LINUX; cuối cùng lưu bằng :wq.

  5. Bước 5: Thực hành với Nano 
    nano notes.txt

    Nano không có mode, mở ra là gõ được ngay. Các phím tắt hiển thị ở cuối màn hình, ký hiệu ^ = Ctrl, M- = Alt.

    Phím tắtChức năng
    Phím mũi tênDi chuyển con trỏ
    Ctrl + O, EnterLưu file (xác nhận tên file)
    Ctrl + XThoát (nếu chưa lưu, Nano hỏi Y/N)
    Ctrl + K / Ctrl + UCắt dòng hiện tại / dán dòng đã cắt
    Ctrl + WTìm kiếm
    Ctrl + \Tìm và thay thế
    Ctrl + _Nhảy tới số dòng
    Alt + U / Alt + EUndo / Redo
    Alt + NBật/tắt hiển thị số dòng

    Gõ vài dòng ghi chú, lưu bằng Ctrl + O → Enter, thoát bằng Ctrl + X, sau đó kiểm tra:

    cat notes.txt
Nên dùng Vim hay Nano? Nano dễ dùng cho người mới. Tuy nhiên vi/vim có mặt trên hầu hết mọi server Linux (kể cả container tối giản), nên DevOps Engineer cần thuộc tối thiểu: i, Esc, :wq, :q!, dd, /tìm_kiếm.

Troubleshoot

Gõ phím trong Vim nhưng không thấy chữ xuất hiện, file bị thay đổi lung tung
Nguyên nhân: Đang ở Normal mode nên các phím bị hiểu là lệnh.
Giải pháp: Nhấn Esc, gõ :q! để thoát không lưu, mở lại file và nhấn i trước khi gõ.
E37: No write since last change (add ! to override)
Nguyên nhân: Gõ :q khi file có thay đổi chưa lưu.
Giải pháp: Dùng :wq để lưu rồi thoát, hoặc :q! để bỏ thay đổi.
E45: 'readonly' option is set / Permission denied khi lưu file
Nguyên nhân: File thuộc quyền root (ví dụ file trong /etc) nhưng mở bằng user thường.
Giải pháp: Thoát bằng :q! và mở lại bằng sudo vim <tên_file>.
Thấy cảnh báo Found a swap file by the name ".sample.txt.swp"
Nguyên nhân: Lần trước Vim bị đóng đột ngột (mất kết nối SSH) nên còn file swap.
Giải pháp: Nhấn R để khôi phục hoặc D để xoá swap file, sau đó tiếp tục làm việc.

6. Thao tác cơ bản với Linux / Giới thiệu Linux & các bản phân phối (Distro)
“Không có việc gì khó, chỉ sợ không biết làm!” — Phần lớn server trên Cloud chạy Linux. Đây là kỹ năng nền tảng mà DevOps Engineer dùng hàng ngày: SSH vào server, cài đặt phần mềm, xem log, phân quyền, quản lý service...

Mục tiêu của section

  • Hiểu Linux là gì, lịch sử phát triển và các phiên bản phân phối (distro) phổ biến.
  • Làm quen với Amazon Linux 2023, biết cách tạo và SSH vào EC2 instance chạy Linux.
  • Thao tác cơ bản với user, group và quyền sudo.
  • Làm việc với file, folder, permission và owner.
  • Quản lý process và service (systemd/systemctl).
  • Làm việc với EBS volume: partition, mount, mở rộng dung lượng.
  • Lập lịch tác vụ tự động với cron job và quản lý SSH key cho thành viên dự án.

Giới thiệu

Linux là một hệ điều hành mã nguồn mở, được Linus Torvalds phát hành phần nhân (kernel) đầu tiên vào năm 1991 và chuyển sang giấy phép mã nguồn mở GPL vào năm 1992. Nhờ tính ổn định, bảo mật, miễn phí và khả năng tuỳ biến cao, Linux trở thành hệ điều hành thống trị trên server, Cloud, container, siêu máy tính và thiết bị nhúng. Trên AWS, phần lớn EC2 instance, container trên ECS/EKS và môi trường chạy Lambda đều dựa trên Linux.

Lịch sử phát triển

Giai đoạnSự kiện chính
1991 – 1992Linus Torvalds (sinh viên Đại học Helsinki) phát hành Linux kernel 0.01, sau đó chuyển sang giấy phép GPL. Kết hợp với bộ công cụ GNU tạo thành hệ điều hành hoàn chỉnh (GNU/Linux).
1990s – 2000sCộng đồng và doanh nghiệp trên toàn thế giới cùng phát triển. Các distro như Slackware, Debian, Red Hat, SUSE ra đời. Linux được dùng rộng rãi trên máy chủ doanh nghiệp nhờ ổn định, an toàn, chi phí thấp.
2000s – 2010sBộ đôi LAMP (Linux, Apache, MySQL, PHP) phổ biến cho web. Ubuntu (2004) giúp Linux thân thiện hơn. Android (2008) dựa trên Linux kernel đưa Linux lên hàng tỷ thiết bị.
2010s – nayCloud Computing, Docker (2013), Kubernetes (2014) đều được xây dựng trên các tính năng của Linux kernel (namespaces, cgroups). 100% top 500 siêu máy tính chạy Linux.

Đặc điểm chính

  • Mã nguồn mở & miễn phí: không mất phí license như Windows Server, ai cũng có thể xem, sửa và phân phối lại mã nguồn.
  • Ổn định & hiệu năng cao: server Linux có thể chạy liên tục nhiều tháng không cần khởi động lại, tiêu tốn ít tài nguyên (không cần giao diện đồ hoạ).
  • Bảo mật: mô hình phân quyền user/group/permission chặt chẽ, cộng đồng lớn phát hiện và vá lỗi nhanh.
  • Đa người dùng, đa nhiệm: nhiều user cùng đăng nhập và chạy nhiều process cùng lúc trên một server.
  • Mạnh mẽ qua dòng lệnh (CLI): mọi thao tác đều thực hiện được bằng lệnh nên dễ tự động hoá bằng script — nền tảng của DevOps.
  • Đa dạng distro: hàng trăm bản phân phối, mỗi bản tối ưu cho một mục đích (server, desktop, nhúng, bảo mật...).

Các bản phân phối (Distro) Linux

Một distro = Linux kernel + bộ công cụ hệ thống + trình quản lý gói (package manager) + cấu hình mặc định. Có hàng trăm distro khác nhau, nhưng phần lớn thuộc vài “họ” chính. Khi đã quen một distro, bạn dễ dàng chuyển sang distro cùng họ vì lệnh và cấu trúc thư mục gần như giống nhau.

Amazon Linux 2023 (AL2023)

Amazon Linux là distro do AWS phát triển và tối ưu riêng cho EC2: khởi động nhanh, tích hợp sẵn AWS CLI, SSM Agent, cloud-init và được AWS hỗ trợ bảo mật. Đây là AMI mặc định khi tạo EC2 và cũng là OS được dùng xuyên suốt section này.

Nên dùng Linux cho web server, API backend (Node.js, Java, Python, Go), container, database mã nguồn mở, CI/CD runner. Chỉ dùng Windows Server khi ứng dụng bắt buộc phụ thuộc vào hệ sinh thái Microsoft.

Use Cases

Web server & API backend

Chạy Nginx/Apache, ứng dụng Node.js, Spring Boot, Django trên EC2 Linux phía sau Load Balancer. Đây là mô hình phổ biến nhất trên AWS.

Container & Kubernetes

Docker image thường dựa trên Alpine, Debian, Amazon Linux. Worker node của ECS/EKS là các EC2 Linux (Amazon Linux, Bottlerocket).

CI/CD & vận hành hệ thống

Jenkins, GitHub Actions self-hosted runner, GitLab runner chạy trên Linux. DevOps Engineer SSH vào server để kiểm tra log, xử lý sự cố, chạy script tự động.

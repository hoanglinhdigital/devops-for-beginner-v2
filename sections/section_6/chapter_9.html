  • Cài đặt web server httpd (Apache) và tạo một trang web đơn giản.
  • Thao tác start, status, stop, restart, reload service.
  • enable service để tự khởi động cùng OS và kiểm chứng bằng cách reboot server.
  • Xem log của service bằng journalctl.

Các bước thực hành

  1. Bước 1: Cài đặt httpd 
    sudo dnf update -y
sudo dnf install -y httpd
systemctl status httpd

    Sau khi cài, service ở trạng thái inactive (dead) và disabled — package chỉ cài phần mềm, không tự chạy service. Nhấn q để thoát màn hình status.

  2. Bước 2: Tạo trang web

    Thư mục chứa web mặc định của httpd là /var/www/html (thuộc quyền root nên cần sudo). Tạo file và copy nội dung file index.html trong source code vào:

    sudo vim /var/www/html/index.html

    📄 lab6_service/index.html

  3. Bước 3: Start service và kiểm tra 
    sudo systemctl start httpd
systemctl status httpd
curl http://localhost

    Status hiển thị Active: active (running), PID chính và vài dòng log gần nhất. Mở trình duyệt truy cập http://<PUBLIC_IP> (lưu ý dùng http, không phải https) sẽ thấy trang Hello from Amazon Linux 2023!.

  4. Bước 4: Stop, start, restart, reload 
    sudo systemctl stop httpd
systemctl status httpd
curl http://localhost
curl: (7) Failed to connect to localhost port 80 after 0 ms: Couldn't connect to server
sudo systemctl start httpd
sudo systemctl restart httpd
sudo systemctl reload httpd
    • restart: dừng hẳn rồi chạy lại (PID thay đổi, các kết nối đang mở bị ngắt).
    • reload: yêu cầu service đọc lại file cấu hình mà không dừng (PID chính giữ nguyên). Không phải service nào cũng hỗ trợ reload.
  5. Bước 5: Enable service khởi động cùng OS 
    systemctl is-enabled httpd
disabled
sudo systemctl enable httpd
Created symlink /etc/systemd/system/multi-user.target.wants/httpd.service → /usr/lib/systemd/system/httpd.service.
systemctl is-enabled httpd
sudo reboot

    Phiên SSH sẽ bị ngắt. Đợi 1–2 phút rồi SSH lại (Public IP không đổi khi reboot), kiểm tra httpd đã tự chạy:

    systemctl is-active httpd
active
curl http://localhost
  6. Bước 6: Xem log của service 
    sudo journalctl -u httpd --no-pager | tail -20
sudo tail -f /var/log/httpd/access_log

    journalctl -u hiển thị log khởi động/dừng của service do systemd ghi lại. Lệnh tail -f theo dõi file access log liên tục: refresh trình duyệt vài lần để thấy request mới xuất hiện, nhấn Ctrl + C để thoát.

  7. Bước 7: Liệt kê các service 
    systemctl list-units --type=service --state=running
systemctl list-unit-files --type=service | grep enabled

    Bạn sẽ thấy các service quen thuộc: sshd, httpd, chronyd (đồng bộ thời gian), amazon-ssm-agent (dùng cho AWS Systems Manager)...

  8. Bước 8: Tự tạo một service

    Tạo script chạy liên tục — copy nội dung file hello.sh trong source code:

    sudo vim /usr/local/bin/hello.sh
sudo chmod 755 /usr/local/bin/hello.sh

    📄 lab6_service/hello.sh

    #!/bin/bash
# Script chạy liên tục, mỗi 5 giây ghi 1 dòng log ra stdout (systemd sẽ đưa vào journal)
while true; do
  echo "Hello from hello.service - $(date '+%Y-%m-%d %H:%M:%S')"
  sleep 5
done

    Tạo file systemd unit — copy nội dung file hello.service trong source code:

    sudo vim /etc/systemd/system/hello.service

    📄 lab6_service/hello.service

    [Unit]
Description=Hello demo service - DevOps on AWS for Beginner
After=network.target

[Service]
Type=simple
User=ec2-user
ExecStart=/usr/local/bin/hello.sh
Restart=always
RestartSec=3

[Install]
WantedBy=multi-user.target
    Thuộc tínhÝ nghĩa
    After=network.targetKhởi động sau khi network sẵn sàng
    User=ec2-userChạy process bằng user thường, không dùng root
    ExecStartLệnh khởi chạy service
    Restart=always, RestartSec=3Tự khởi động lại sau 3 giây nếu process dừng
    WantedBy=multi-user.targetĐược chạy khi OS boot ở chế độ bình thường (khi enable)

    Nạp lại cấu hình systemd, enable và start service, xem log real-time (nhấn Ctrl + C để thoát):

    sudo systemctl daemon-reload
sudo systemctl enable --now hello
systemctl status hello
sudo journalctl -u hello -f
  9. Bước 9: Kiểm chứng cơ chế tự restart

    Buộc kill process chính của service, đợi vài giây và xem systemd tự chạy lại với PID mới:

    systemctl show -p MainPID hello
sudo kill -9 $(systemctl show -p MainPID --value hello)
sleep 6
systemctl show -p MainPID hello
systemctl status hello

    Đây chính là lý do nên chạy ứng dụng production dưới dạng service thay vì chạy tay trong terminal.

Troubleshoot

Trình duyệt báo timeout khi truy cập http://<PUBLIC_IP> nhưng curl localhost chạy được
Nguyên nhân: Security Group chưa mở cổng 80, hoặc trình duyệt tự chuyển sang https://.
Giải pháp: Thêm inbound rule HTTP 80 vào linux-lab-sg; gõ rõ http:// trên thanh địa chỉ.
Hiển thị trang test mặc định của Apache thay vì trang của bạn
Nguyên nhân: File /var/www/html/index.html chưa được lưu hoặc sai tên/đường dẫn.
Giải pháp: Kiểm tra bằng ls -l /var/www/html/ và cat /var/www/html/index.html.
Job for httpd.service failed because the control process exited with error code
Nguyên nhân: Lỗi cấu hình hoặc cổng 80 đang bị process khác chiếm.
Giải pháp: Xem chi tiết bằng sudo journalctl -xeu httpd; kiểm tra cấu hình sudo apachectl configtest; kiểm tra cổng sudo ss -tlnp | grep :80.
hello.service: Failed at step EXEC ... Permission denied / status=203/EXEC
Nguyên nhân: Script chưa có quyền execute hoặc thiếu dòng #!/bin/bash ở đầu file.
Giải pháp: sudo chmod 755 /usr/local/bin/hello.sh, kiểm tra dòng đầu file rồi sudo systemctl restart hello.
Warning: The unit file ... changed on disk. Run 'systemctl daemon-reload'
Nguyên nhân: Sửa file .service nhưng systemd vẫn dùng bản cũ trong bộ nhớ.
Giải pháp: Chạy sudo systemctl daemon-reload rồi restart service.

Dọn dẹp resource

Xoá service hello vừa tạo. httpd có thể giữ lại hoặc gỡ bỏ theo lệnh bên dưới (lưu ý: systemctl không có lệnh remove, muốn gỡ phần mềm phải dùng dnf remove). Giữ lại instance cho Lab 7.
sudo systemctl disable --now hello
sudo rm /etc/systemd/system/hello.service /usr/local/bin/hello.sh
sudo systemctl daemon-reload
sudo systemctl disable --now httpd
sudo dnf remove -y httpd

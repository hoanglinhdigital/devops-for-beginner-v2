Tổng kết kiến thức

Qua section này, bạn đã nắm được nền tảng Kubernetes để sẵn sàng học Amazon EKS ở Section 14:

  • Hiểu container orchestration và vai trò của Kubernetes (kiến trúc Control Plane + Worker Node + kubectl).
  • Nắm các khái niệm cốt lõi: Pod, Namespace, ReplicaSet, Deployment, Service, Ingress, PersistentVolume, ConfigMap, Secret, StatefulSet.
  • Thao tác thành thạo với Minikube và kubectl (apply, get, describe, delete, rollout, scale...).
  • Tạo cluster thật bằng kops trên EC2 và triển khai ứng dụng React + Express + MongoDB.

Cheat sheet lệnh kubectl

# Thông tin cluster & context
kubectl cluster-info
kubectl config get-contexts
kubectl config use-context <tên>

# Pod / ReplicaSet / Deployment
kubectl get pods [-o wide] [-n <namespace>]
kubectl describe pod <tên>
kubectl logs <tên>
kubectl get replicasets
kubectl get deployments

# Tạo / cập nhật / xoá
kubectl apply -f <file.yaml>
kubectl delete -f <file.yaml>
kubectl create namespace <tên>

# Deployment: scale & rollout
kubectl scale --replicas=5 deployment/<tên>
kubectl rollout status deployment/<tên>
kubectl rollout history deployment/<tên>
kubectl rollout undo deployment/<tên>

# Service & Ingress
kubectl get services
kubectl get ingress

# ConfigMap / Secret / PV / PVC
kubectl get configmap <tên> -o yaml
kubectl get secret <tên> -o yaml
kubectl get pv
kubectl get pvc

Dọn dẹp resource

Quan trọng: các lab trên Minikube chạy local không tốn phí, nhưng Lab 4 – 5 dùng EC2/ALB và tốn phí theo giờ. Hãy xoá hết.
  • Minikube: minikube stop (hoặc minikube delete).
  • Cluster kops: kops delete cluster --name <domain> --state=s3://<bucket> --yes.
  • AWS resource: xoá ALB, Target Group, S3 bucket state, và EC2 admin server.
  • Kiểm tra thêm: EBS Volume còn sót, NAT Gateway, Elastic IP.
  • ECR Repository: có thể giữ lại để dùng sau này (tốn phí nhỏ, không đáng kể).

13. Kubernetes (k8s) cơ bản / Lab 4: Tạo Kubernetes cluster bằng kops

Mục tiêu

  • Hiểu kops (Kubernetes Operations) là gì và tại sao dùng để tạo cluster trên AWS.
  • Tạo một Kubernetes cluster thật trên EC2 (1 control-plane + các worker node) bằng kops.
  • Kết nối tới cluster từ EC2 và từ máy cá nhân.

Giới thiệu kops

kops (Kubernetes Operations) là công cụ giúp bạn tạo, xoá, nâng cấp và duy trì cụm Kubernetes trên các nền tảng cloud như AWS, GCE, DigitalOcean. Một số tính năng nổi bật: tự động provisioning cluster High Availability, mô hình state-sync cho phép dry-run và idempotency (chạy nhiều lần vẫn ra cùng kết quả), và khả năng sinh ra Terraform.

kops lưu state vào S3, đọc domain từ Route53, và tạo các EC2 làm control-plane và worker node. Sau đó bạn dùng kubectl để thao tác với cluster.

Yêu cầu trước khi bắt đầu

  • Một EC2 chạy Ubuntu (làm "admin server").
  • EC2 có IAM Role với policy AdministratorAccess.
  • Một domain (có thể mua tại Route53) – thay hoanglinhdigital.com bằng domain của bạn.
  • Source code: sourcecode/section_13_kubernetes_k8s_basic/lab4_kops/commands.sh.
Chi phí: kops tạo EC2 (control-plane + worker), Elastic IP, NAT... tính phí theo giờ. Nhớ xoá cluster ngay sau khi thực hành.

Các bước thực hành

  1. Bước 1: Cài AWS CLI trên EC2 
    sudo apt update
sudo apt install awscli -y
aws --version
  2. Bước 2: Cài kubectl 
    curl -LO "https://dl.k8s.io/release/$(curl -L -s https://dl.k8s.io/release/stable.txt)/bin/linux/amd64/kubectl"
chmod +x ./kubectl
sudo mv ./kubectl /usr/local/bin/kubectl
kubectl help
  3. Bước 3: Cài kops 
    curl -Lo kops https://github.com/kubernetes/kops/releases/download/$(curl -s https://api.github.com/repos/kubernetes/kops/releases/latest | grep tag_name | cut -d '"' -f 4)/kops-linux-amd64
chmod +x kops
sudo mv kops /usr/local/bin/kops
kops version
  4. Bước 4: Chuẩn bị domain & S3 bucket

    Kiểm tra domain (thay hoanglinhdigital.com bằng domain của bạn):

    nslookup -type=ns hoanglinhdigital.com

    Tạo S3 bucket lưu state của kops (thay udemy-devops-kops bằng tên bạn chọn):

    aws s3api create-bucket --bucket udemy-devops-kops --region ap-southeast-1
  5. Bước 5: Tạo cluster bằng kops 
    kops create cluster --name hoanglinhdigital.com --state=s3://udemy-devops-kops \
  --zones=ap-southeast-1a,ap-southeast-1c \
  --node-count=2 --node-size=t3.small \
  --master-size=t3.small \
  --dns-zone hoanglinhdigital.com \
  --node-volume-size=10 --master-volume-size=10

    💡 Lệnh này chỉ "khai báo" cluster (chưa tạo resource thật). --node-count là số worker node; control-plane sẽ được tạo riêng.

  6. Bước 6: Áp dụng thay đổi thực sự và validate 
    kops update cluster --name hoanglinhdigital.com --state=s3://udemy-devops-kops --yes --admin
kops validate cluster --name hoanglinhdigital.com --state=s3://udemy-devops-kops --wait 10m

    Kiểm tra các node:

    kubectl get nodes

    Kết quả mong đợi gồm 1 node control-plane và các node node ở trạng thái Ready.

  7. Bước 7: Kết nối từ máy cá nhân

    Xem file kube config trên EC2:

    cat ~/.kube/config

    Copy nội dung và paste vào file ~/.kube/config trên máy local (Windows: C:\Users\<user>\.kube\config). Sau đó kiểm tra:

    kubectl cluster-info
kubectl get nodes

Kiểm tra kết quả

✅ Lab thành công khi

  • kops validate cluster báo cluster hợp lệ.
  • kubectl get nodes hiển thị control-plane và worker node ở trạng thái Ready.
  • Từ máy cá nhân chạy kubectl cluster-info thấy cluster (sau khi copy config).

Troubleshoot

error: unable to recognize ... no matches for kind
Nguyên nhân: phiên bản kubectl cũ hơn nhiều so với cluster.
Giải pháp: cài kubectl mới theo link chính thức hoặc dùng kops export kubecfg.
Không tạo được cluster, lỗi liên quan IAM/DNS
Nguyên nhân: EC2 thiếu quyền (IAM Role) hoặc domain chưa trỏ đúng Route53.
Giải pháp: gắn IAM Role AdministratorAccess; kiểm tra nslookup -type=ns trả về name server của Route53.

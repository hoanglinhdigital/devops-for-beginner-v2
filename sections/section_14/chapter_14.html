13. Kubernetes (k8s) cơ bản / Secret

Giới thiệu

Secret là một đối tượng API dùng để lưu trữ thông tin nhạy cảm như mật khẩu, token, private key... Nó giúp bảo vệ thông tin quan trọng và ngăn chặn rò rỉ dữ liệu nhạy cảm. Secret được Pod sử dụng để truy cập thông tin nhạy cảm, và có thể được truyền vào Pod qua biến môi trường hoặc volume mount (tương tự ConfigMap).

Đặc điểm chính

  • Lưu dữ liệu nhạy cảm: mật khẩu, token, certificate, private key.
  • Giá trị phải base64: khi khai báo trong YAML, giá trị phải được mã hoá base64.
  • 2 cách sử dụng: biến môi trường và volume mount.
  • Phân biệt với ConfigMap: Secret dành cho dữ liệu nhạy cảm; ConfigMap cho cấu hình thường.

Secret chứa dữ liệu nhạy cảm (đã base64) và được truyền vào Pod qua biến môi trường hoặc mount thành file trong volume.

Ví dụ Secret

Tạo chuỗi base64 bằng lệnh:

echo -n "root" | base64
cm9vdA==
echo -n "VeryStrongPassword123" | base64
VmVyeVN0cm9uZ1Bhc3N3b3JkMTIz

Khai báo Secret trong YAML:

apiVersion: v1
kind: Secret
metadata:
  name: my-secret
type: Opaque
data:
  MYSQL_ROOT_USER: cm9vdA==
  MYSQL_ROOT_PASSWORD: VmVyeVN0cm9uZ1Bhc3N3b3JkMTIz

Đưa Secret vào Pod qua secretKeyRef:

env:
  - name: MYSQL_ROOT_PASSWORD
    valueFrom:
      secretKeyRef:
        name: my-secret
        key: MYSQL_ROOT_PASSWORD

Thực hành: Tạo Secret

Tạo Secret lưu username/password (dạng base64), truyền vào Pod MySQL (NodePort) qua biến môi trường (secretKeyRef), sau đó kết nối MySQL bằng thông tin trong Secret.

Các bước thực hành

  1. Bước 1: Tạo chuỗi base64 
    echo -n "root" | base64
cm9vdA==
echo -n "VeryStrongPassword123" | base64
VmVyeVN0cm9uZ1Bhc3N3b3JkMTIz

    Copy các giá trị base64 và thay thế vào file secret-simple.yaml.

  2. Bước 2: Tạo file cấu hình Secret + MySQL

    Tạo file secret-simple.yaml:

    apiVersion: v1
kind: Secret
metadata:
  name: my-secret
type: Opaque
data:
  MYSQL_ROOT_USER: cm9vdA==
  MYSQL_ROOT_PASSWORD: VmVyeVN0cm9uZ1Bhc3N3b3JkMTIz
  ADDRESS: U2FpR29uLVZpZXROYW0=
---
# ... (PersistentVolume + PVC + Service NodePort giống phần thực hành Persistent Volume)
---
apiVersion: apps/v1
kind: Deployment
metadata:
  name: mysql-deployment
spec:
  replicas: 1
  selector:
    matchLabels:
      app: mysql
  template:
    metadata:
      labels:
        app: mysql
    spec:
      containers:
        - name: mysql
          image: mysql
          env:
            - name: MYSQL_ROOT_PASSWORD
              valueFrom:
                secretKeyRef:
                  name: my-secret
                  key: MYSQL_ROOT_PASSWORD
            - name: MYSQL_ROOT_USER
              valueFrom:
                secretKeyRef:
                  name: my-secret
                  key: MYSQL_ROOT_USER
          ports:
            - containerPort: 3306
          volumeMounts:
            - name: mysql-persistent-storage
              mountPath: /var/lib/mysql
      volumes:
        - name: mysql-persistent-storage
          persistentVolumeClaim:
            claimName: my-pvc

    💡 Khác với phần thực hành ConfigMap (dùng envFrom nạp cả ConfigMap), ở đây ta chọn từng key bằng secretKeyRef.

  3. Bước 3: Apply và kiểm tra Secret 
    kubectl apply -f secret-simple.yaml
kubectl get secret my-secret -o yaml
kubectl get secret my-secret -o jsonpath="{.data.MYSQL_ROOT_USER}" | base64 --decode
kubectl get secret my-secret -o jsonpath="{.data.MYSQL_ROOT_PASSWORD}" | base64 --decode
kubectl get secret my-secret -o jsonpath="{.data.ADDRESS}" | base64 --decode

    Ba lệnh decode sẽ lần lượt in ra root, VeryStrongPassword123, SaiGon-VietNam.

  4. Bước 4: Kết nối MySQL bằng thông tin trong Secret 
    minikube service mysql-service --url
http://127.0.0.1:<port>

    Mở MySQL Workbench, kết nối với username = root, password = VeryStrongPassword123 (giá trị trong Secret).

  5. Bước 5: Xoá resource 
    kubectl delete -f secret-simple.yaml

Kiểm tra kết quả

✅ Thực hành thành công khi

  • kubectl get secret my-secret -o yaml hiển thị các giá trị đã base64.
  • Lệnh base64 --decode khôi phục đúng giá trị gốc.
  • MySQL kết nối được với username/password từ Secret.

Troubleshoot

Decode ra chuỗi có ký tự lạ / không khớp
Nguyên nhân: mã hoá có kèm ký tự xuống dòng (thiếu cờ -n khi echo).
Giải pháp: dùng đúng echo -n "..." | base64.
Pod báo CreateContainerConfigError
Nguyên nhân: secretKeyRef trỏ tới key không tồn tại trong Secret.
Giải pháp: kiểm tra kubectl get secret my-secret -o yaml; đảm bảo tên key khớp chính xác (phân biệt hoa thường).

Thông tin bổ sung

  • Giải mã: kubectl get secret my-secret -o jsonpath="{.data.MYSQL_ROOT_USER}" | base64 --decode.
  • Base64 ≠ mã hoá: base64 chỉ là encoding, ai có quyền đọc Secret vẫn decode được. Hãy dùng RBAC để giới hạn ai đọc được Secret.
  • Best practice: với cloud, cân nhắc dùng giải pháp quản lý secret chuyên dụng (AWS Secrets Manager, Parameter Store, External Secrets Operator) thay vì Secret thô.
  • Không commit Secret vào Git: tương tự quy tắc không hard-code credential đã học xuyên suốt khoá học.

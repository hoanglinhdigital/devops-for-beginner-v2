16. Monitoring for Kubernetes/EKS / Lab 2: Monitoring for Kubernetes – Log

Mục tiêu

  • Làm quen với khái niệm ELK stack (Elasticsearch + Logstash + Kibana) và Filebeat.
  • Cài đặt các công cụ cần thiết để thu thập log từ ứng dụng TODO rồi visualize trên Kibana.

Kiến trúc tổng quan

Concept ELK + Filebeat stack
Sơ đồ thực tế hệ thống của bài Lab 2
  • Filebeat: chạy dạng DaemonSet trên mỗi node, tự động thu thập container log rồi gửi sang Logstash.
  • Logstash: nhận log qua cổng 5044 (Beats), xử lý và chuẩn hoá.
  • Elasticsearch: lưu trữ và đánh index log qua cổng 9200.
  • Kibana: truy vấn Elasticsearch và visualize log qua cổng 5601.

Yêu cầu trước khi bắt đầu

  • Hoàn thành Lab 1: đã có Minikube và ứng dụng TODO (frontend/backend/mongo) đang chạy trong namespace default.
  • Source code bài lab nằm tại sourcecode/section_15_monitoring_for_eks/lab2_log/.

Các bước thực hành

  1. Bước 1: Deploy stack thu thập log (ELK + Filebeat) 
    kubectl apply -f log-collection.yaml -n monitoring
  2. Bước 2: Kiểm tra deploy 
    kubectl get pods -n monitoring

    Bạn sẽ thấy các pod elasticsearch, kibana, logstash, filebeat ở trạng thái Running, cùng với các pod ứng dụng (frontend, backend, mongo).

  3. Bước 3: Truy cập Kibana 
    minikube service kibana -n monitoring

    Hoặc dùng port-forward:

    kubectl port-forward svc/kibana 5601:5601

    rồi truy cập http://localhost:5601.

  4. Bước 4: Tạo Index Pattern và xem log

    Trong Kibana:

    • Vào Stack Management → Index Patterns → Create index pattern.
    • Nhập pattern khớp với cấu hình Logstash: todo-app-logs-*.
    • Chọn @timestamp làm time field rồi hoàn tất.
    • Vào Discover, chọn index pattern todo-app-logs-* vừa tạo.

    Thực hiện vài thao tác trên app TODO (thêm, sửa, xoá todo) rồi tìm log bằng keyword, ví dụ DELETE.

Kiểm tra kết quả

✅ Lab thành công khi

  • Các pod ELK + Filebeat đều Running trong namespace monitoring.
  • Truy cập được Kibana tại cổng 5601.
  • Index pattern todo-app-logs-* được tạo thành công và có dữ liệu log đổ về.
  • Khi thao tác trên app TODO, log của frontend/backend xuất hiện trên Discover.

Troubleshoot

Elasticsearch không lên hoặc bị OOM
Nguyên nhân: Elasticsearch cần nhiều RAM; Minikube thiếu tài nguyên.
Giải pháp: Tăng RAM/CPU cho Minikube khi khởi động (VD minikube start --memory 6144 --cpus 4), hoặc giảm -Xmx trong file YAML.
Kibana không thấy log dù đã tạo index pattern
Nguyên nhân: Pattern sai tên, hoặc Logstash chưa nhận log từ Filebeat.
Giải pháp: Kiểm tra index pattern đúng todo-app-logs-*; xem log pod filebeat và logstash; đảm bảo cổng 5044 thông.

Dọn dẹp resource

Có thể giữ lại để demo/tham khảo. Nếu muốn xoá:
kubectl delete -f log-collection.yaml -n monitoring

17. CICD for Kubernetes/EKS / Lab 4: Implement GitOps với GithubAction + ArgoCD

Mục tiêu

  • Hiểu và thực hành mô hình GitOps: tách build image (GitHub Actions) khỏi deploy (ArgoCD).
  • Cài đặt ArgoCD lên EKS cluster và tạo một ArgoCD Application.
  • Dùng GitHub Actions build & push Docker image lên ECR (theo version), còn ArgoCD tự deploy từ Git repository (manifest repo).

Git là nguồn sự thật duy nhất: GitHub Actions chỉ build & push image; ArgoCD liên tục so sánh manifest repo với EKS và tự đồng bộ.

Yêu cầu trước khi bắt đầu

  • Tái sử dụng resource của Lab 3: EKS cluster, ECR repositories, và GitHub repo chứa code application.
  • Chuẩn bị 2 GitHub repository:
    • Code application repo: chứa code FE/BE + .github/workflows/deploy.yml (tái sử dụng Lab 3, có chỉnh sửa).
    • Manifest repo (tạo mới): chứa file aws-eks.yaml, ví dụ tên todo-app-demo-gitops-manifests.
  • Source code bài lab nằm tại sourcecode/section_16_cicd_for_eks/lab4_gitops_argocd/.

Các bước thực hành

  1. Bước 1: Cài đặt ArgoCD

    Tạo namespace và cài ArgoCD:

    kubectl create namespace argocd
kubectl apply -n argocd -f https://raw.githubusercontent.com/argoproj/argo-cd/stable/manifests/install.yaml

    Truy cập ArgoCD UI bằng port-forward:

    kubectl port-forward svc/argocd-server -n argocd 8080:443

    Lấy mật khẩu admin ban đầu (username: admin):

    kubectl -n argocd get secret argocd-initial-admin-secret -o jsonpath="{.data.password}" | base64 -d
  2. Bước 2: Tạo ArgoCD Application

    Sửa repoURL trong file argocd-app.yaml thành URL của manifest repo của bạn, sau đó apply:

    kubectl apply -f argocd-app.yaml
  3. Bước 3: Cấu hình credential cho ArgoCD truy cập GitHub (dùng GUI)

    Vào ArgoCD UI → Settings (biểu tượng bánh răng) → Repositories → + Connect Repo, chọn phương thức Via HTTPS và điền:

    • Type: git
    • Repository URL: https://github.com/<username>/todo-app-demo-gitops-manifests.git (nên có đuôi .git).
    • Username: tên đăng nhập GitHub.
    • Password: Personal Access Token (PAT) (không phải mật khẩu đăng nhập GitHub).
  4. Bước 4: Chuẩn bị file deploy.yml mới cho code application repo

    Tham khảo file deploy.yml trong thư mục source. Những thay đổi so với Lab 3:

    • Chuyển trigger từ auto (push) sang manual (workflow_dispatch) — không còn push code là tự deploy nữa.
    • Thêm input version để deploy version cụ thể.
    • Dùng tag của Docker image (thay vì sha của commit).
    • Bỏ bước kubectl apply -f aws-eks.yaml (ArgoCD lo việc này).
  5. Bước 5: Test luồng CI/CD — Build & Push image

    Sửa code Backend & Frontend, rồi commit, tag và push code lên Git:

    git add .
git commit -m "Update version v1.0.4 to adapt with ArgoCD"
git tag v1.0.4
git push origin v1.0.4

    Chạy GitHub Actions workflow: GitHub repo → Actions → chọn workflow deploy.yml → Run workflow → nhập version v1.0.4 → Run workflow. Chờ workflow hoàn thành và kiểm tra Docker image đã push lên ECR (backend & frontend).

  6. Bước 6: Cập nhật manifest và sync với ArgoCD

    Trong manifest repo, thực hiện:

    • Tạo thư mục k8s-manifests làm nơi chứa file deploy mà ArgoCD sẽ đọc.
    • Copy file aws-eks.yaml vào thư mục k8s-manifests.
    • Sửa version muốn deploy cho backend và frontend trong aws-eks.yaml (vd v1.0.4).
    • Commit và push manifest repo.

    Vào ArgoCD UI, chọn application và bấm Sync để ArgoCD deploy ứng dụng:

    kubectl port-forward svc/argocd-server -n argocd 8080:443

    Mở https://localhost:8080, chọn application todo-app, nhấn Sync.

Troubleshoot

ArgoCD Application báo Unknown / OutOfSync
Nguyên nhân: repoURL hoặc path trong argocd-app.yaml sai, hoặc ArgoCD chưa có credential để đọc repo.
Giải pháp: kiểm tra lại repoURL/path và kết nối repo đúng PAT ở Bước 3.
Pod lỗi ImagePullBackOff sau khi sync
Nguyên nhân: version trong manifest chưa khớp với tag đã push lên ECR, hoặc node thiếu quyền pull ECR.
Giải pháp: kiểm tra tag image trong manifest khớp với tag đã push; thêm policy ECR read-only cho node role.
Workflow GitHub Actions chạy xong nhưng app chưa deploy
Nguyên nhân: GitOps không deploy từ action — bạn cần commit manifest và bấm Sync trên ArgoCD (hoặc bật automated).
Giải pháp: thực hiện đúng Bước 6, hoặc bật syncPolicy.automated trong argocd-app.yaml.

Dọn dẹp resource

ArgoCD là một thành phần chạy trên cluster nên không tính thêm phí riêng, nhưng EKS cluster và ALB vẫn tính phí. Xoá cluster khi hoàn thành toàn bộ chương.
eksctl delete cluster --name devops-test-cluster --region ap-southeast-1

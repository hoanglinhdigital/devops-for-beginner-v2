13. Serverless Application Model (SAM) / Lab 2: Triển khai ứng dụng URL Shortener bằng SAM

Mục tiêu

  • Đọc hiểu template SAM của ứng dụng URL Shortener: 1 API Gateway, 2 Lambda function, 1 DynamoDB table.
  • Hiểu cách truyền tên table vào Lambda qua biến môi trường và cấp quyền tối thiểu bằng SAM policy templates.
  • Build và deploy toàn bộ ứng dụng bằng 2 lệnh; kiểm tra bằng curl và AWS Console.

Yêu cầu trước khi bắt đầu

  • Hoàn thành Lab 1: đã cài SAM CLI, AWS CLI có credential, Python 3.13 (hoặc dùng --use-container).
  • Source code: sourcecode/section_12_serverless_application_model/lab2_url_shorten_app/.
  • Công cụ gọi API: curl hoặc Postman.
Chi phí: DynamoDB dùng chế độ On-demand (trả theo request), Lambda và API Gateway nằm trong free tier với lượng request nhỏ.

Các bước thực hành

  1. Bước 1: Mở project và đọc hiểu template

    Mở thư mục sourcecode/section_12_serverless_application_model/lab2_url_shorten_app bằng VS Code và đọc file template.yaml. Các điểm quan trọng cần nhận biết:

    Globals:
  Function:
    Runtime: python3.13
    Timeout: 10
    Environment:
      Variables:
        TABLE_NAME: !Ref UrlShortenTable      # tên table thật truyền vào mọi function

Resources:
  MyApi:
    Type: AWS::Serverless::Api
    Properties:
      StageName: dev                          # URL có dạng .../dev/...

  GenerateShortUrlFunction:
    Type: AWS::Serverless::Function
    Properties:
      CodeUri: generate_short_url/
      Handler: app.lambda_handler
      Policies:
        - DynamoDBWritePolicy:                # chỉ được ghi vào đúng table này
            TableName: !Ref UrlShortenTable
      Events:
        GenerateShortUrl:
          Type: Api
          Properties:
            RestApiId: !Ref MyApi
            Path: /generate-short-url
            Method: post

  UrlShortenTable:
    Type: AWS::DynamoDB::Table               # resource CloudFormation thông thường
    Properties:
      AttributeDefinitions:
        - AttributeName: short_url
          AttributeType: S
      KeySchema:
        - AttributeName: short_url
          KeyType: HASH
      BillingMode: PAY_PER_REQUEST
    • Hai function với hai thư mục code riêng (generate_short_url/, get_url/), cùng đọc TABLE_NAME từ biến môi trường.
    • Policies: DynamoDBWritePolicy cho function tạo link, DynamoDBReadPolicy cho function tra cứu – SAM tự sinh IAM Role tương ứng, không cần viết role thủ công.
    • Không đặt TableName: CloudFormation tự sinh tên duy nhất nên có thể deploy lại nhiều lần mà không xung đột.
  2. Bước 2: Đọc hiểu code Lambda

    Mở generate_short_url/app.py và get_url/app.py. Ý chính của generate_short_url: đọc url từ body, sinh mã ngẫu nhiên 15 ký tự và lưu vào DynamoDB.

    # Khởi tạo bên ngoài handler để tái sử dụng kết nối giữa các lần invoke (warm start)
dynamodb = boto3.resource("dynamodb")
table = dynamodb.Table(os.environ["TABLE_NAME"])

def lambda_handler(event, context):
    body = json.loads(event.get("body") or "{}")
    original_url = body.get("url")
    if not original_url:
        return response(400, {"status": "error", "message": "Attribute 'url' is required"})

    short_url = "".join(secrets.choice(alphabet) for _ in range(15))
    table.put_item(Item={"short_url": short_url, "original_url": original_url})
    return response(200, {"short_url_code": short_url})

    get_url đọc pathParameters.short_url, gọi get_item, trả về HTTP 308 kèm header Location hoặc 404 nếu không tìm thấy.

  3. Bước 3: Validate và Build 
    cd sourcecode/section_12_serverless_application_model/lab2_url_shorten_app
sam validate --lint
sam build
  4. Bước 4: Deploy 
    sam deploy --guided

    Trả lời các câu hỏi:

    • Stack Name: url-shorten-app
    • AWS Region: ap-southeast-1
    • Confirm changes before deploy: y
    • Allow SAM CLI IAM role creation: y
    • Disable rollback: n
    • GenerateShortUrlFunction / GetUrlFunction has no authentication. Is this okay: y (cả hai câu hỏi – API công khai phục vụ bài học)
    • Save arguments to configuration file: y

    Xem danh sách thay đổi trong change set (các resource Add), nhập y để deploy. Lấy giá trị Outputs:

    sam list stack-outputs --stack-name url-shorten-app

    Ghi lại giá trị ApiUrl (ví dụ https://abc123xyz.execute-api.ap-southeast-1.amazonaws.com/dev).

  5. Bước 5: Tạo short URL

    Gọi API tạo link rút gọn (thay <ApiUrl>):

    curl -X POST "<ApiUrl>/generate-short-url" -H "Content-Type: application/json" -d '{"url": "https://aws.amazon.com/serverless/sam/"}'
{"short_url_code": "jDdfskaJKJ8f9d1"}

    💡 Dùng Postman: method POST, URL <ApiUrl>/generate-short-url, Body → raw → JSON với nội dung {"url": "https://aws.amazon.com/serverless/sam/"}.

  6. Bước 6: Truy cập link rút gọn

    Dùng mã nhận được ở bước 5 (thay <short_url_code>). Kết quả là HTTP 308 và header location trỏ tới URL gốc:

    curl -i "<ApiUrl>/link/<short_url_code>"
HTTP/2 308
location: https://aws.amazon.com/serverless/sam/

    Dán thẳng link <ApiUrl>/link/<short_url_code> vào trình duyệt – trình duyệt sẽ tự chuyển tới trang gốc. Thử một mã không tồn tại để nhận lỗi 404.

  7. Bước 7: Kiểm tra resource trên AWS Console
    • DynamoDB → Tables → table có tên dạng url-shorten-app-UrlShortenTable-xxxx → Explore table items: thấy item vừa tạo (short_url, original_url).
    • Lambda → function GetUrlFunction → tab Configuration: mục Environment variables có TABLE_NAME; mục Permissions → execution role chỉ có policy đọc đúng table (không phải dynamodb:* trên mọi resource).
    • CloudFormation → stack url-shorten-app → tab Resources và Outputs.

Kiểm tra kết quả

✅ Lab thành công khi

  • Stack url-shorten-app ở trạng thái CREATE_COMPLETE.
  • POST /generate-short-url trả về short_url_code và item xuất hiện trong DynamoDB.
  • GET /link/<short_url_code> redirect tới URL gốc; mã không tồn tại trả 404.
  • Gọi POST với body rỗng hoặc thiếu url trả về 400.

Troubleshoot

{"message": "Missing Authentication Token"}
Nguyên nhân: URL sai – thiếu stage /dev hoặc sai path / method.
Giải pháp: Dùng đúng ApiUrl từ Outputs; generate-short-url là POST, link/{mã} là GET.
{"message": "Internal server error"} khi gọi API
Nguyên nhân: Lambda bị lỗi (ví dụ thiếu quyền, lỗi code).
Giải pháp: Xem log bằng sam logs --stack-name url-shorten-app --name GenerateShortUrlFunction (chi tiết ở Lab 3) hoặc CloudWatch Logs.
AccessDeniedException ... is not authorized to perform: dynamodb:PutItem
Nguyên nhân: Function gọi thao tác không nằm trong policy template (ví dụ GetUrlFunction chỉ có quyền đọc).
Giải pháp: Đổi sang policy phù hợp, ví dụ DynamoDBCrudPolicy, rồi build & deploy lại.
Error: Build Failed ... python3.13
Nguyên nhân: Không có Python 3.13 trên máy.
Giải pháp: Chạy sam build --use-container (cần Docker).

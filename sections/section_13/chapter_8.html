  • SAM = CloudFormation + cú pháp rút gọn cho serverless (Transform: AWS::Serverless-2016-10-31) và SAM CLI cho cả vòng đời phát triển.
  • Cấu trúc template: Globals, Resources (AWS::Serverless::Function / Api / ...), Outputs; quyền dùng policy templates để giữ least privilege.
  • Quy trình chuẩn: sam validate → sam build → test local → sam deploy → sam logs → sam delete.
  • sam sync --watch chỉ dành cho dev; production luôn qua sam deploy (change set).
  • Release an toàn với AutoPublishAlias + DeploymentPreference (Canary / Linear) + CloudWatch Alarm để tự rollback.

Best practice

  • Một template cho nhiều môi trường: dùng Parameters và --config-env; không hard-code tên resource, account ID, region.
  • Cấp quyền bằng policy templates hoặc policy tự viết với Resource cụ thể; tránh dynamodb:* trên "*".
  • Khởi tạo client AWS (boto3...) bên ngoài handler; đặt timeout và memory hợp lý trong Globals.
  • Không commit .aws-sam/, samconfig.toml chứa thông tin cá nhân, env.json hay credential.
  • Production dùng DeploymentPreference kèm alarm; viết unit test và chạy trong pipeline trước sam deploy.
  • Gắn tag, đặt retention cho CloudWatch Log group để kiểm soát chi phí lưu log.

Dọn dẹp resource

Chi phí: các resource của section này chủ yếu tính theo request nên chi phí thấp, nhưng vẫn nên xoá stack khi học xong để tránh lưu dữ liệu và CloudWatch Log không cần thiết.
  1. Bước 1: Xoá stack url-shorten-app 
    sam delete --stack-name url-shorten-app

    Trả lời y khi được hỏi. Kiểm tra trên CloudFormation Console stack đã biến mất (DELETE_COMPLETE).

  2. Bước 2: Xoá stack sam-app (Lab 1) nếu còn 
    sam delete --stack-name sam-app
  3. Bước 3: Kiểm tra các resource còn sót
    • CloudWatch → Log groups: xoá các log group /aws/lambda/url-shorten-app-* và /aws/lambda/sam-app-* (Lambda không tự xoá log group).
    • CodeDeploy → Applications: application ServerlessDeploymentApplication-* đã bị xoá cùng stack.
    • S3: bucket aws-sam-cli-managed-default-* do SAM tạo, chứa package code. Có thể giữ lại để dùng cho các lab sau (dung lượng rất nhỏ) hoặc xoá thủ công sau khi dọn sạch object (stack aws-sam-cli-managed-default trong CloudFormation).
  4. Bước 4: Dọn dẹp trên máy local

    Xoá thư mục .aws-sam/, samconfig.toml, env.json trong project nếu không cần nữa, và dừng container Docker còn chạy bằng docker ps.

13. Serverless Application Model (SAM) / Lab 3: Test ở local, xem log & cập nhật nhanh với sam sync

Mục tiêu

  • Chạy unit test cho Lambda mà không cần AWS.
  • Dùng sam local invoke và sam local start-api để test function ngay trên máy trước khi deploy.
  • Xem log của function đã deploy bằng sam logs --tail.
  • Dùng sam sync --watch để sửa code và thấy thay đổi trên AWS gần như tức thì.

Yêu cầu trước khi bắt đầu

  • Hoàn thành Lab 2: stack url-shorten-app đang chạy (lấy tên DynamoDB table từ Outputs).
  • Docker đang chạy; Python 3.13 và pip trên máy.
  • Source code: sourcecode/section_12_serverless_application_model/lab3_local_test_and_sync/commands.sh; các thao tác thực hiện trong thư mục project của Lab 2.
Lưu ý: test local gọi vào DynamoDB thật của stack, nên dữ liệu bạn tạo ở local sẽ nằm trong table trên AWS.

Các bước thực hành

  1. Bước 1: Chạy unit test

    Thư mục tests/unit chứa test kiểm tra các trường hợp đầu vào sai (body rỗng, JSON lỗi, thiếu url) – không cần kết nối AWS.

    cd sourcecode/section_12_serverless_application_model/lab2_url_shorten_app
pip install -r tests/requirements.txt
python -m pytest tests/unit -v
3 passed
  2. Bước 2: Chuẩn bị file biến môi trường cho local

    Ở local, biến TABLE_NAME trong template chỉ là tham chiếu logic, nên cần ghi đè bằng tên table thật. Lấy tên table:

    sam list stack-outputs --stack-name url-shorten-app

    Copy file mẫu thành env.json (đã được gitignore) rồi sửa giá trị TABLE_NAME bằng tên table thật:

    cp env.json.example env.json
    {
  "Parameters": {
    "TABLE_NAME": "url-shorten-app-UrlShortenTable-XXXXXXXXXXXX"
  }
}
  3. Bước 3: Invoke function ở local

    Build rồi invoke GenerateShortUrlFunction với event mẫu events/generate.json (giả lập request từ API Gateway):

    sam build
sam local invoke GenerateShortUrlFunction --event events/generate.json --env-vars env.json

    Kết quả hiển thị log của function và response statusCode: 200 cùng short_url_code. Sửa file events/get.json thay THAY_BANG_MA_RUT_GON bằng mã vừa nhận rồi thử với function còn lại:

    sam local invoke GetUrlFunction --event events/get.json --env-vars env.json
  4. Bước 4: Chạy API ở local

    SAM đọc Events trong template để dựng các route:

    sam local start-api --env-vars env.json

    Mở terminal thứ hai và gọi API local:

    curl -X POST http://127.0.0.1:3000/generate-short-url -H "Content-Type: application/json" -d '{"url": "https://docs.aws.amazon.com/"}'
curl -i http://127.0.0.1:3000/link/<short_url_code>

    Mỗi request SAM khởi động một container (hoặc dùng lại container nếu đang warm). Nhấn Ctrl + C để dừng khi xong. Sửa code trong app.py rồi sam build lại để thấy thay đổi.

  5. Bước 5: Xem thông tin endpoint và log của stack đã deploy 
    sam list endpoints --stack-name url-shorten-app

    Mở log của function theo thời gian thực (giữ terminal này mở), sau đó gọi API từ terminal khác để thấy log xuất hiện:

    sam logs --stack-name url-shorten-app --name GenerateShortUrlFunction --tail

    Có thể lọc log: --filter "ERROR" hoặc xem trong khoảng thời gian: --start-time '10min ago'.

  6. Bước 6: Cập nhật nhanh với sam sync

    Chạy sam sync ở chế độ watch. Lần đầu SAM đồng bộ toàn bộ stack (mất vài phút), sau đó theo dõi file thay đổi:

    sam sync --stack-name url-shorten-app --watch

    Giữ terminal này chạy. Mở generate_short_url/app.py, sửa dòng cuối thành trả thêm URL gốc rồi lưu file:

        return response(200, {"short_url_code": short_url, "original_url": original_url})

    SAM phát hiện thay đổi và cập nhật code Lambda trong vài giây (không qua change set). Gọi lại API POST /generate-short-url trên AWS và thấy field mới. Nhấn Ctrl + C để dừng watch.

  7. Bước 7: Đưa trạng thái về đúng với template bằng sam deploy

    sam sync có thể làm code trên AWS khác với bản đã đóng gói. Trước khi tiếp tục, hoàn tác thay đổi ở bước 6 (hoặc giữ lại nếu muốn) và deploy chính thức để đồng bộ:

    sam build
sam deploy

Kiểm tra kết quả

✅ Lab thành công khi

  • 3 unit test pass.
  • sam local invoke và sam local start-api trả về kết quả đúng, item mới xuất hiện trong DynamoDB.
  • sam logs --tail hiển thị log khi bạn gọi API.
  • Sửa code khi sam sync --watch đang chạy, response của API trên AWS thay đổi theo sau vài giây.

Troubleshoot

KeyError: 'TABLE_NAME' hoặc ResourceNotFoundException: Requested resource not found khi chạy local
Nguyên nhân: Quên truyền --env-vars env.json hoặc TABLE_NAME chưa phải tên table thật.
Giải pháp: Kiểm tra lại env.json và region của AWS CLI (phải là ap-southeast-1, cùng region với table).
botocore.exceptions.NoCredentialsError / Unable to locate credentials trong container
Nguyên nhân: SAM không tìm thấy credential để truyền vào container.
Giải pháp: Cấu hình lại AWS CLI; nếu dùng profile khác default, thêm --profile <tên> cho lệnh sam local.
ModuleNotFoundError: No module named 'pytest'
Nguyên nhân: Chưa cài dependency test.
Giải pháp: Chạy pip install -r tests/requirements.txt (nên dùng virtual environment).
sam sync báo lỗi "Stack ... does not exist" hoặc dùng sai region
Nguyên nhân: Stack chưa deploy hoặc region mặc định khác.
Giải pháp: Thêm --region ap-southeast-1 hoặc kiểm tra samconfig.toml.

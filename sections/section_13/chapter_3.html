13. Serverless Application Model (SAM) / Lab 1: Cài đặt SAM CLI & ứng dụng Hello World

Mục tiêu

  • Cài đặt và kiểm tra AWS SAM CLI trên máy local.
  • Tạo project mẫu bằng sam init, đọc hiểu template.yaml.
  • Build, chạy thử ở local, rồi deploy ứng dụng Hello World lên AWS bằng sam deploy --guided.
  • Quan sát stack CloudFormation, Lambda, API Gateway được SAM tạo ra; sửa code và deploy lại; xoá stack.

Yêu cầu trước khi bắt đầu

  • AWS CLI v2 đã cấu hình profile có quyền tạo CloudFormation, Lambda, API Gateway, IAM, S3 (Section 5 – Lab cài AWS CLI).
  • Python 3.13 cài trên máy (nếu không có Python này, thêm --use-container khi sam build).
  • Docker đang chạy (Section 8) – cần cho sam local và --use-container.
  • Source code tham khảo: sourcecode/section_12_serverless_application_model/lab1_hello_world/commands.sh.
Chi phí: Hello World nằm trong free tier của Lambda / API Gateway. Vẫn nên xoá stack ở cuối lab.

Các bước thực hành

  1. Bước 1: Cài đặt AWS SAM CLI

    Cài SAM CLI theo hướng dẫn chính thức cho hệ điều hành của bạn (Windows – file MSI, macOS – Homebrew brew install aws-sam-cli, Linux – file zip): Install the AWS SAM CLI. Mở terminal mới và kiểm tra các công cụ:

    python --version
aws --version
sam --version
docker --version
  2. Bước 2: Kiểm tra credential của AWS CLI

    SAM CLI dùng chung credential với AWS CLI. Kết quả phải hiển thị Account ID và ARN của user bạn:

    aws sts get-caller-identity
  3. Bước 3: Khởi tạo project bằng sam init

    Tạo project sam-app từ template Hello World Example:

    sam init --name sam-app --runtime python3.13 --app-template hello-world --package-type Zip --dependency-manager pip

    Nếu SAM CLI hỏi thêm, chọn các giá trị sau:

    • Enable X-Ray tracing: N
    • Enable CloudWatch Application Insights: N
    • Set Structured Logging in JSON format: N

    Xem cấu trúc project vừa tạo (hello_world/app.py là code Lambda, events/event.json là event mẫu, template.yaml là định nghĩa resource):

    cd sam-app
ls
  4. Bước 4: Đọc hiểu template.yaml

    Mở template.yaml bằng VS Code. Nội dung chính (đã lược bỏ chú thích):

    AWSTemplateFormatVersion: '2010-09-09'
Transform: AWS::Serverless-2016-10-31
Description: sam-app

Globals:
  Function:
    Timeout: 3

Resources:
  HelloWorldFunction:
    Type: AWS::Serverless::Function
    Properties:
      CodeUri: hello_world/
      Handler: app.lambda_handler
      Runtime: python3.13
      Architectures:
        - x86_64
      Events:
        HelloWorld:
          Type: Api
          Properties:
            Path: /hello
            Method: get

Outputs:
  HelloWorldApi:
    Description: API Gateway endpoint URL for Prod stage
    Value: !Sub "https://${ServerlessRestApi}.execute-api.${AWS::Region}.amazonaws.com/Prod/hello/"

    Chỉ ~20 dòng nhưng khi deploy SAM sẽ tạo: Lambda function, IAM Role, API Gateway REST API (ServerlessRestApi), stage Prod và permission cho API Gateway gọi Lambda.

  5. Bước 5: Validate và Build 
    sam validate --lint
sam build

    Kết quả build nằm trong thư mục .aws-sam/build/. Nếu máy không có Python 3.13, dùng sam build --use-container.

  6. Bước 6: Chạy thử ở local

    Invoke trực tiếp function với event mẫu (lần đầu SAM tải container image nên hơi lâu):

    sam local invoke HelloWorldFunction --event events/event.json
{"statusCode": 200, "body": "{\"message\": \"hello world\"}"}

    Giả lập API Gateway ở local, mở terminal thứ hai để gọi API (dừng bằng Ctrl + C):

    sam local start-api
    curl http://127.0.0.1:3000/hello
  7. Bước 7: Deploy lên AWS 
    sam deploy --guided

    Trả lời các câu hỏi như sau:

    • Stack Name: sam-app
    • AWS Region: ap-southeast-1
    • Confirm changes before deploy: y (để xem change set trước khi áp dụng)
    • Allow SAM CLI IAM role creation: y
    • Disable rollback: n
    • HelloWorldFunction has no authentication. Is this okay: y
    • Save arguments to configuration file: y (file samconfig.toml, config file environment default)

    SAM upload code lên S3, tạo change set và hiển thị danh sách resource sắp tạo. Nhập y để triển khai. Khi xong, phần Outputs hiển thị URL của API.

  8. Bước 8: Kiểm tra trên AWS và gọi API

    Gọi API bằng URL ở mục Outputs (thay <ApiUrl> bằng giá trị thật):

    curl <ApiUrl>
{"message": "hello world"}

    Trên AWS Console, kiểm tra các nơi sau:

    • CloudFormation: stack sam-app – tab Resources liệt kê Lambda, IAM Role, API Gateway, Permission... do SAM sinh ra. Tab Template có thể chọn View processed template để xem template sau khi Transform.
    • Lambda: function có tên dạng sam-app-HelloWorldFunction-xxxx, trigger là API Gateway.
    • API Gateway: API sam-app, stage Prod, resource /hello method GET.
  9. Bước 9: Sửa code và deploy lại

    Mở hello_world/app.py, đổi nội dung "message": "hello world" thành "message": "hello SAM", sau đó build và deploy lại (lần này không cần --guided vì đã có samconfig.toml):

    sam build
sam deploy

    Chỉ Lambda thay đổi nên change set chỉ có 1 dòng Modify cho function. Gọi lại API để thấy kết quả mới.

Kiểm tra kết quả

✅ Lab thành công khi

  • sam --version hiển thị phiên bản SAM CLI.
  • sam local invoke trả về statusCode 200 và message.

Troubleshoot

Error: Docker is not reachable. Is Docker installed? Running Lambda functions locally requires Docker.
Nguyên nhân: Docker chưa chạy.
Giải pháp: Mở Docker Desktop (hoặc khởi động dịch vụ docker) và chạy lại lệnh.
Error: PythonPipBuilder:Validation - Binary validation failed for python, searched for python in following locations ... which did not satisfy constraints for runtime: python3.13
Nguyên nhân: Máy không có Python 3.13 trong PATH.
Giải pháp: Cài Python 3.13 hoặc chạy sam build --use-container.
Unable to locate credentials / ExpiredToken
Nguyên nhân: Chưa cấu hình hoặc credential hết hạn.
Giải pháp: Chạy aws configure hoặc đăng nhập lại; kiểm tra bằng aws sts get-caller-identity. Nếu dùng nhiều profile, thêm --profile <tên> cho lệnh sam.
Error: Failed to create/update the stack ... is in ROLLBACK_COMPLETE state and can not be updated
Nguyên nhân: Lần deploy đầu bị lỗi và rollback, stack không thể cập nhật.
Giải pháp: Xoá stack bằng sam delete --stack-name sam-app (hoặc trên CloudFormation Console) rồi deploy lại.

Dọn dẹp resource

Có thể giữ stack sam-app để thử nghiệm thêm; nếu không cần nữa hãy xoá để tránh phát sinh chi phí.
sam delete --stack-name sam-app

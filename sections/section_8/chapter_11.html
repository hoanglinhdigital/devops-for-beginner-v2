8. Thao tác cơ bản với Docker / Lab 7: Docker Compose – Multi container (Node.js, Redis, MySQL)

Mục tiêu

  • Viết file docker-compose.yaml start 3 service: web (Node.js), cache (Redis), db (MySQL).
  • Tạo named volume riêng cho MySQL để dữ liệu không mất khi xoá container.
  • Dùng healthcheck + depends_on để web chỉ start khi MySQL đã sẵn sàng; quản lý password bằng file .env.
  • Truy cập website Node.js (đọc dữ liệu từ MySQL, đếm lượt truy cập bằng Redis) và kết nối MySQL qua host port bằng MySQL Workbench.

Các bước thực hành

  1. Bước 1: Tìm hiểu cấu trúc project 
    lab7_compose_multi/
├── docker-compose.yaml
├── .env.example        # mẫu biến môi trường (password)
├── commands.sh
├── db/
│   └── init.sql        # tạo bảng employee + 10 dòng dữ liệu mẫu
└── web/
    ├── Dockerfile
    ├── index.js        # API /api/info (Redis) và /api/employees (MySQL)
    ├── package.json    # express, mysql2, redis
    └── public/
        └── index.html

    Trong index.js, ứng dụng kết nối tới MySQL bằng host db và Redis bằng host cache – chính là tên service trong file compose. Docker cung cấp DNS nội bộ để phân giải các tên này thành IP của container.

  2. Bước 2: Tạo file .env chứa password

    Không hard-code password trong file compose. Copy file mẫu thành .env, sau đó mở .env và đổi password theo ý bạn:

    cd lab7_compose_multi
cp .env.example .env
    MYSQL_ROOT_PASSWORD=ChangeMeRoot123
MYSQL_PASSWORD=ChangeMeApp123

    💡 File .env đã có trong .gitignore của repository – không commit password lên Git.

  3. Bước 3: Viết file docker-compose.yaml 
    services:
  web:
    build:
      context: ./web
      dockerfile: Dockerfile
    image: compose-multi-web:1.0
    ports:
      - "8080:3000"
    environment:
      - NODE_ENV=development
      - DB_HOST=db
      - DB_USER=appuser
      - DB_PASSWORD=${MYSQL_PASSWORD}
      - DB_NAME=testdb
      - REDIS_HOST=cache
    depends_on:
      db:
        condition: service_healthy
      cache:
        condition: service_started
    restart: unless-stopped

  cache:
    image: redis:7-alpine
    restart: unless-stopped

  db:
    image: mysql:8.4
    environment:
      - MYSQL_ROOT_PASSWORD=${MYSQL_ROOT_PASSWORD}
      - MYSQL_DATABASE=testdb
      - MYSQL_USER=appuser
      - MYSQL_PASSWORD=${MYSQL_PASSWORD}
    ports:
      - "3306:3306"
    volumes:
      # Named volume: dữ liệu MySQL được giữ lại kể cả khi container bị xoá
      - db-data:/var/lib/mysql
      # Script khởi tạo bảng & dữ liệu mẫu (chỉ chạy lần đầu khi volume rỗng)
      - ./db/init.sql:/docker-entrypoint-initdb.d/init.sql:ro
    healthcheck:
      test: ["CMD-SHELL", "mysqladmin ping -h 127.0.0.1 -uroot -p$${MYSQL_ROOT_PASSWORD} --silent"]
      interval: 10s
      timeout: 5s
      retries: 10
      start_period: 30s
    restart: unless-stopped

volumes:
  db-data:
    • ${MYSQL_PASSWORD}: Compose thay bằng giá trị trong .env. $${...} (2 dấu $) giữ nguyên biến để shell bên trong container tự đọc.
    • Image mysql tự tạo database testdb và user appuser từ các biến MYSQL_*, rồi chạy các file trong /docker-entrypoint-initdb.d/.
    • condition: service_healthy: web chỉ start khi healthcheck của db trả về thành công.
  4. Bước 4: Start toàn bộ service 
    docker compose config
docker compose up -d --build

    MySQL cần khoảng 20–40 giây để khởi tạo lần đầu. Theo dõi trạng thái tới khi db là (healthy) và web là Up:

    docker compose ps
NAME                         IMAGE                   SERVICE   STATUS                    PORTS
lab7_compose_multi-cache-1   redis:7-alpine          cache     Up 40 seconds             6379/tcp
lab7_compose_multi-db-1      mysql:8.4               db        Up 40 seconds (healthy)   0.0.0.0:3306->3306/tcp, 33060/tcp
lab7_compose_multi-web-1     compose-multi-web:1.0   web       Up 8 seconds              0.0.0.0:8080->3000/tcp
    docker compose logs -f db
  5. Bước 5: Truy cập website Node.js

    Mở http://localhost:8080 (hoặc http://<EC2_PUBLIC_IP>:8080): trang hiển thị hostname của container, số lượt truy cập (tăng mỗi lần refresh) và bảng 10 nhân viên đọc từ MySQL.

    curl http://localhost:8080/api/info
{"hostname":"e7ce29911252","visits":1}
curl http://localhost:8080/api/employees
[{"id":1,"name":"John Doe","age":30,"department":"IT","salary":"5000.00"},...]
  6. Bước 6: Kiểm tra Redis & MySQL từ bên trong 
    docker compose exec cache redis-cli GET visits
"3"

    Nhập giá trị MYSQL_PASSWORD trong .env khi được hỏi password:

    docker compose exec db mysql -uappuser -p testdb -e "SELECT COUNT(*) FROM employee;"

    Kiểm tra network, volume do Compose tạo và DNS nội bộ:

    docker network ls
docker volume ls
docker compose exec web ping -c 2 db
  7. Bước 7: Kết nối MySQL bằng MySQL Workbench

    Tạo connection mới trong MySQL Workbench với các thông số:

    • Hostname: 127.0.0.1 (hoặc <EC2_PUBLIC_IP>), Port: 3306
    • Username: appuser, Password: giá trị MYSQL_PASSWORD trong .env
    • Default Schema: testdb

    Chạy câu lệnh SELECT * FROM employee;, sau đó thử thêm 1 nhân viên mới và refresh website để thấy dữ liệu mới:

    INSERT INTO employee (id, name, age, department, salary) VALUES (11, 'Your Name', 25, 'DevOps', 8000.00);
  8. Bước 8: Kiểm chứng dữ liệu được giữ lại nhờ volume

    down xoá toàn bộ container và network, nhưng named volume db-data vẫn còn:

    docker compose down
docker volume ls
docker compose up -d
curl http://localhost:8080/api/employees

    Nhân viên số 11 vẫn còn. Ngược lại, bộ đếm visits của Redis bắt đầu lại từ đầu vì service cache không dùng volume.

Kiểm tra kết quả

✅ Lab thành công khi

  • 3 service ở trạng thái Up, db có trạng thái (healthy).
  • Website hiển thị số lượt truy cập tăng dần và danh sách nhân viên từ MySQL.
  • Kết nối được MySQL bằng MySQL Workbench qua port 3306.
  • Sau down → up, dữ liệu MySQL vẫn còn.

Troubleshoot

Bind for 0.0.0.0:3306 failed: port is already allocated
Nguyên nhân: Máy bạn đã có MySQL (cài trực tiếp hoặc container khác) dùng port 3306.
Giải pháp: Đổi mapping thành "3307:3306" trong file compose và dùng port 3307 khi kết nối từ MySQL Workbench. Kết nối giữa web và db không bị ảnh hưởng vì dùng port nội bộ 3306.
dependency failed to start: container lab7_compose_multi-db-1 is unhealthy
Nguyên nhân: MySQL khởi tạo lỗi (thường do thiếu file .env nên password rỗng) hoặc máy yếu khởi tạo quá lâu.
Giải pháp: Kiểm tra docker compose config có giá trị password; xem docker compose logs db; chạy lại docker compose up -d.
/api/employees trả về Table 'testdb.employee' doesn't exist hoặc Access denied for user 'appuser'
Nguyên nhân: Script init và các biến MYSQL_* chỉ có tác dụng khi volume rỗng. Nếu volume đã được tạo từ lần chạy lỗi trước đó (hoặc bạn đổi password sau lần chạy đầu), MySQL bỏ qua bước khởi tạo.
Giải pháp: docker compose down -v để xoá volume rồi docker compose up -d lại (dữ liệu cũ sẽ mất).
WARN The "MYSQL_PASSWORD" variable is not set. Defaulting to a blank string.
Nguyên nhân: Chưa tạo file .env, hoặc file nằm sai thư mục.
Giải pháp: Tạo .env cùng thư mục với docker-compose.yaml (Bước 2).

Dọn dẹp resource

docker compose down -v --rmi local

-v xoá named volume db-data (toàn bộ dữ liệu MySQL), --rmi local xoá image do Compose build (compose-multi-web:1.0).

Nếu dùng EC2, hãy xoá inbound rule port 3306 trong Security Group khi không còn cần kết nối MySQL Workbench.

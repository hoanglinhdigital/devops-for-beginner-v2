8. Thao tác cơ bản với Docker / Lab 6: Docker Compose – ứng dụng Node.js đơn giản

Mục tiêu

  • Viết file docker-compose.yaml để build và start một service Node.js (Express).
  • Truy cập website Node.js qua port 8080 của host.
  • Dùng bind mount để sửa code trên máy host và thấy thay đổi ngay trong container.
  • Làm quen với các lệnh docker compose up / ps / logs / exec / restart / down.

Các bước thực hành

  1. Bước 1: Tìm hiểu cấu trúc project 
    lab6_compose_simple/
├── docker-compose.yaml
├── commands.sh
└── web/
    ├── Dockerfile
    ├── .dockerignore
    ├── index.js          # Express server, port 3000
    ├── package.json      # dependency: express
    ├── package-lock.json
    └── public/
        ├── index.html    # trang chủ
        └── learning.html # trang /learning

    index.js phục vụ file tĩnh trong public/, redirect /learning tới learning.html và có API /api/info trả về hostname của container và các biến môi trường.

  2. Bước 2: Xem Dockerfile của service web 
    # Base image Node.js 20
FROM node:20-alpine

# Thư mục làm việc trong container
WORKDIR /app

# Copy package.json & package-lock.json trước để tận dụng layer cache
COPY package*.json ./

# Cài dependencies
RUN npm install

# Copy toàn bộ source code
COPY . .

# Port ứng dụng lắng nghe
EXPOSE 3000

# Lệnh chạy ứng dụng
CMD ["npm", "start"]
  3. Bước 3: Viết file docker-compose.yaml

    Tạo file docker-compose.yaml trong thư mục lab6_compose_simple:

    services:
  web:
    build:
      context: ./web
      dockerfile: Dockerfile
    image: compose-web:1.0
    ports:
      - "8080:3000"
    volumes:
      # Bind mount source code từ máy host vào container: sửa file trên host => container thấy ngay
      - ./web:/app
      # Anonymous volume giữ lại node_modules đã cài trong image (không bị bind mount ghi đè)
      - /app/node_modules
    environment:
      - NODE_ENV=development
      - APP_VERSION=1.0
    restart: unless-stopped

    💡 Bind mount ./web:/app “che” toàn bộ thư mục /app trong image bằng thư mục trên host – vốn không có node_modules. Dòng /app/node_modules tạo một volume riêng để giữ lại thư viện đã cài lúc build.

  4. Bước 4: Kiểm tra cấu hình & start service 
    cd lab6_compose_simple
docker compose config
docker compose up -d --build
    docker compose ps
NAME                        IMAGE             COMMAND                  SERVICE   CREATED          STATUS          PORTS
lab6_compose_simple-web-1   compose-web:1.0   "docker-entrypoint.s…"   web       10 seconds ago   Up 9 seconds    0.0.0.0:8080->3000/tcp
    docker compose logs web
web-1  | Server is running on port 3000
  5. Bước 5: Truy cập website

    Mở browser truy cập http://localhost:8080 (hoặc http://<EC2_PUBLIC_IP>:8080): trang Welcome to Docker Compose v1.0. Bấm Login để chuyển tới trang /learning. Kiểm tra API:

    curl http://localhost:8080/api/info
{"hostname":"ba728b565cd1","nodeEnv":"development","appVersion":"1.0"}

    hostname chính là Container ID; nodeEnv, appVersion lấy từ mục environment trong file compose.

  6. Bước 6: Sửa code và thấy thay đổi ngay (bind mount)

    Mở file web/public/index.html trên máy host, đổi v1.0 thành v1.1, lưu file và refresh browser – trang web đổi ngay mà không cần build lại image.

    File index.js chỉ được Node.js đọc lúc khởi động, nên khi sửa file này cần restart service:

    docker compose restart web
  7. Bước 7: Thao tác với container của service 
    docker compose exec web sh
    ls /app
env | grep APP_VERSION
exit
    docker compose stop
docker compose ps -a
docker compose start

Troubleshoot

Error: Cannot find module 'express', container liên tục restart
Nguyên nhân: Thiếu dòng - /app/node_modules nên bind mount ghi đè mất node_modules đã cài trong image.
Giải pháp: Bổ sung anonymous volume như Bước 3, chạy docker compose down rồi docker compose up -d --build.
the attribute `version` is obsolete, it will be ignored
Nguyên nhân: File compose cũ có dòng version: '3'.
Giải pháp: Đây chỉ là cảnh báo; xoá dòng version để hết cảnh báo.
Sửa code nhưng browser không thay đổi
Nguyên nhân: Sửa nhầm file (ví dụ sửa index.js mà chưa restart), hoặc browser cache.
Giải pháp: docker compose restart web khi sửa index.js; nhấn Ctrl + F5; kiểm tra docker compose exec web cat /app/public/index.html.
no configuration file provided: not found
Nguyên nhân: Chạy lệnh ở thư mục không có file docker-compose.yaml / compose.yaml.
Giải pháp: cd vào đúng thư mục, hoặc chỉ định file bằng docker compose -f <đường dẫn> up -d.

Dọn dẹp resource

docker compose down --rmi all

down xoá container và network do Compose tạo; --rmi all xoá luôn image compose-web:1.0 của service. Bỏ --rmi all nếu muốn giữ image cho lần chạy sau.

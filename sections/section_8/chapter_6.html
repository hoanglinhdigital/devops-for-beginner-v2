8. Thao tác cơ bản với Docker / Lab 3: Build & Run container đơn giản với Dockerfile

Mục tiêu

  • Viết Dockerfile sử dụng base image httpd (Apache HTTP Server), dùng COPY để đưa code HTML từ workspace vào image và expose port 80.
  • Build image, chạy container từ image và mapping với port 8080 của host.
  • Kiểm tra truy cập qua browser, build version mới của image với tag khác.
  • Stop, xoá container và image đã tạo.

Yêu cầu trước khi bắt đầu

  • Hoàn thành Lab 1, Lab 2. Đã đọc chương Dockerfile & các chỉ thị cơ bản.
  • Port 8080 trên host đang trống (đã xoá container my-nginx ở Lab 2).
  • Source code: sourcecode/section_8_docker_basic_operation/lab3_dockerfile/ (Dockerfile, web/index.html, commands.sh).

Các bước thực hành

  1. Bước 1: Chuẩn bị thư mục làm việc

    Tạo thư mục lab3_dockerfile với cấu trúc như sau (hoặc dùng thư mục có sẵn trong source code):

    lab3_dockerfile/
├── Dockerfile       # mô tả cách build image
├── commands.sh      # các lệnh tham khảo
└── web/
    └── index.html   # trang web mẫu

    Tạo file web/index.html, copy nội dung từ file sourcecode/section_8_docker_basic_operation/lab3_dockerfile/web/index.html.

  2. Bước 2: Viết Dockerfile

    Tạo file tên Dockerfile (không có phần mở rộng) với nội dung:

    # Base image: Apache HTTP Server
FROM httpd:2.4

# Biến môi trường (có thể đọc trong container bằng lệnh env)
ENV APP_VERSION=1.0

# Copy code HTML từ workspace vào thư mục web root của httpd
COPY ./web/ /usr/local/apache2/htdocs/

# Ghi version vào file để kiểm tra (chạy lúc build image)
RUN echo "version=${APP_VERSION}" > /usr/local/apache2/htdocs/version.txt

# Khai báo port ứng dụng lắng nghe
EXPOSE 80

# Lệnh chạy khi container start (chạy httpd ở foreground)
CMD ["httpd-foreground"]

    💡 Thư mục web root /usr/local/apache2/htdocs/ và lệnh httpd-foreground được mô tả trong trang hướng dẫn của image httpd trên Docker Hub. Khi dùng một image mới, hãy luôn đọc trang này trước.

  3. Bước 3: Build image

    Di chuyển vào thư mục lab3_dockerfile rồi build. -t đặt tên và tag cho image, dấu . cuối lệnh là build context (thư mục hiện tại):

    cd lab3_dockerfile
docker build -t my-httpd-image:1.0 .
[+] Building 5.2s (8/8) FINISHED
 => [internal] load build definition from Dockerfile
 => [1/3] FROM docker.io/library/httpd:2.4
 => [2/3] COPY ./web/ /usr/local/apache2/htdocs/
 => [3/3] RUN echo "version=1.0" > /usr/local/apache2/htdocs/version.txt
 => exporting to image
 => => naming to docker.io/library/my-httpd-image:1.0

    Kiểm tra image vừa build và các layer của nó:

    docker images my-httpd-image
docker image history my-httpd-image:1.0
  4. Bước 4: Run container, mapping port 8080 
    docker run -d -p 8080:80 --name my-httpd-container my-httpd-image:1.0
docker ps
  5. Bước 5: Kiểm tra qua browser

    Truy cập http://localhost:8080 (hoặc http://<EC2_PUBLIC_IP>:8080), bạn sẽ thấy trang Welcome to DevOps on AWS – Docker Lab v1.0 với form đăng nhập. Kiểm tra thêm file được tạo bởi RUN và biến môi trường từ ENV:

    curl http://localhost:8080/version.txt
version=1.0
docker exec my-httpd-container env
docker logs my-httpd-container
  6. Bước 6: Build version mới

    Sửa web/index.html, đổi v1.0 thành v2.0. Build image với tag 2.0, xoá container cũ và chạy container từ image mới:

    docker build -t my-httpd-image:2.0 .
docker rm -f my-httpd-container
docker run -d -p 8080:80 --name my-httpd-container my-httpd-image:2.0

    Refresh browser để thấy v2.0. Quan sát log build: bước FROM dùng lại cache, chỉ bước COPY và các bước sau được chạy lại.

    💡 Đây chính là cách deploy version mới với container: không sửa container đang chạy, mà build image mới rồi thay container. Image 1.0 vẫn còn – muốn rollback chỉ cần chạy lại image cũ.

Troubleshoot

failed to read dockerfile: open Dockerfile: no such file or directory
Nguyên nhân: Không đứng đúng thư mục chứa Dockerfile, hoặc file bị lưu thành Dockerfile.txt (Windows ẩn phần mở rộng).
Giải pháp: ls kiểm tra tên file; dùng -f <đường dẫn> để chỉ định Dockerfile khác tên mặc định.
COPY failed: file not found in build context / "/web": not found
Nguyên nhân: Đường dẫn trong COPY là tương đối với build context (dấu .), không phải với vị trí Dockerfile; hoặc quên dấu . cuối lệnh build.
Giải pháp: Chạy docker build tại thư mục lab3_dockerfile, kiểm tra thư mục web/ tồn tại.
Browser vẫn hiển thị nội dung cũ sau khi build version mới
Nguyên nhân: Container cũ vẫn chạy image 1.0, hoặc browser cache.
Giải pháp: docker ps kiểm tra cột IMAGE của container; nhấn Ctrl + F5 để tải lại trang không dùng cache.

Dọn dẹp resource

docker stop my-httpd-container
docker rm my-httpd-container
docker rmi my-httpd-image:1.0 my-httpd-image:2.0

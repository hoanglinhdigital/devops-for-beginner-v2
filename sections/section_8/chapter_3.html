8. Thao tác cơ bản với Docker / Lab 1: Cài đặt Docker & Docker Compose, đăng ký Docker Hub

Mục tiêu

  • Cài đặt Docker và Docker Compose theo 1 trong 2 cách: Docker Desktop trên máy local (Windows/MacOS) hoặc Docker Engine trên EC2 Amazon Linux 2023.
  • Kiểm tra version và chạy container đầu tiên hello-world.
  • Đăng ký tài khoản Docker Hub và đăng nhập bằng Personal Access Token.

Yêu cầu trước khi bắt đầu

  • Cách 1 – Windows: Windows 10/11 64-bit, bật Virtualization trong BIOS, RAM tối thiểu 8 GB (khuyến nghị 16 GB).
  • Cách 1 – MacOS: MacOS phiên bản được Docker hỗ trợ (3 bản mới nhất), biết máy dùng chip Apple Silicon hay Intel.
  • Cách 2 – EC2: AWS account, đã biết tạo EC2 và SSH (Section 6 – Lab 1).
  • Source code: sourcecode/section_8_docker_basic_operation/lab1_install_docker/commands.sh.
Vì sao không dùng AWS Cloud9 như phiên bản cũ? Từ 07/2024, AWS ngừng cho khách hàng mới sử dụng Cloud9. EC2 Amazon Linux 2023 mang lại các ưu điểm tương tự: tương thích native với Linux, không bị chặn bởi rule mạng công ty khi pull package/image, cấu hình linh hoạt và có thể Stop khi không dùng để tiết kiệm chi phí.

Các bước thực hành

Cách 1: Docker Desktop trên Windows / MacOS

  1. Bước 1 (chỉ Windows): Cài đặt WSL 2

    Docker Desktop trên Windows chạy Linux container thông qua WSL 2. Mở PowerShell (Run as Administrator) và chạy lệnh sau, sau đó khởi động lại máy:

    wsl --install

    Kiểm tra sau khi khởi động lại:

    wsl --status
  2. Bước 2: Tải và cài đặt Docker Desktop
    • Windows: docs.docker.com/desktop/setup/install/windows-install – khi cài, chọn Use WSL 2 instead of Hyper-V.
    • MacOS: docs.docker.com/desktop/setup/install/mac-install – chọn đúng bản Apple Silicon hoặc Intel chip.

    Mở Docker Desktop, chấp nhận điều khoản sử dụng và đợi tới khi góc dưới trái hiển thị trạng thái Engine running.

  3. Bước 3: Kiểm tra version

    Mở Terminal (MacOS) hoặc PowerShell / Git Bash (Windows):

    docker --version
Docker version 28.x.x, build xxxxxxx
docker compose version
Docker Compose version v2.x.x-desktop.1

    💡 Docker Desktop đã bao gồm Docker Engine, Docker CLI, Docker Compose và Buildx. Version cụ thể trên máy bạn có thể mới hơn.

Cách 2: Docker Engine trên EC2 Amazon Linux 2023

  1. Bước 1: Tạo Security Group

    Tạo Security Group docker-lab-sg trong Default VPC với các inbound rule:

    • SSH (TCP 22) – Source: My IP
    • Custom TCP 8080 – Source: My IP (truy cập web từ các bài lab)
    • MySQL/Aurora (TCP 3306) – Source: My IP (dùng ở Lab 7 để kết nối MySQL Workbench)
  2. Bước 2: Tạo EC2 instance

    Tạo EC2 instance với các thông số:

    • Name: docker-lab-server
    • AMI: Amazon Linux 2023 (64-bit x86)
    • Instance type: t3.small (2 vCPU, 2 GB RAM – đủ để build Node.js và chạy MySQL ở các lab sau)
    • Key pair: tạo mới docker-lab-key (định dạng .pem), lưu vào ~/.ssh/
    • Network: Default VPC, public subnet, Auto-assign public IP: Enable
    • Security Group: docker-lab-sg
    • EBS Volume: 20 GB gp3 (image Docker chiếm khá nhiều dung lượng)
  3. Bước 3: SSH vào EC2 và cài Docker Engine

    Thay <EC2_PUBLIC_IP> bằng Public IPv4 của instance:

    ssh -i ~/.ssh/docker-lab-key.pem ec2-user@<EC2_PUBLIC_IP>
    sudo dnf update -y
sudo dnf install -y docker
sudo systemctl enable --now docker
sudo systemctl status docker

    Trạng thái active (running) nghĩa là Docker daemon đã chạy. Nhấn q để thoát màn hình status.

  4. Bước 4: Cho phép ec2-user chạy docker không cần sudo

    Thêm ec2-user vào group docker (xem lại Section 6 – User & Group), sau đó thoát SSH và đăng nhập lại để group mới có hiệu lực:

    sudo usermod -aG docker ec2-user
exit
    ssh -i ~/.ssh/docker-lab-key.pem ec2-user@<EC2_PUBLIC_IP>
groups
ec2-user adm wheel systemd-journal docker
  5. Bước 5: Cài Docker Compose plugin & Buildx plugin

    Package docker của Amazon Linux 2023 chưa kèm Compose. Cài Compose V2 dạng CLI plugin (dùng lệnh docker compose):

    sudo mkdir -p /usr/local/lib/docker/cli-plugins
sudo curl -SL "https://github.com/docker/compose/releases/latest/download/docker-compose-linux-$(uname -m)" -o /usr/local/lib/docker/cli-plugins/docker-compose
sudo chmod +x /usr/local/lib/docker/cli-plugins/docker-compose
docker compose version

    Cài thêm Buildx để tránh cảnh báo “legacy builder is deprecated” khi chạy docker build:

    BUILDX_VERSION=$(curl -s https://api.github.com/repos/docker/buildx/releases/latest | grep '"tag_name"' | cut -d '"' -f 4)
ARCH=$(uname -m | sed 's/x86_64/amd64/; s/aarch64/arm64/')
sudo curl -SL "https://github.com/docker/buildx/releases/download/${BUILDX_VERSION}/buildx-${BUILDX_VERSION}.linux-${ARCH}" -o /usr/local/lib/docker/cli-plugins/docker-buildx
sudo chmod +x /usr/local/lib/docker/cli-plugins/docker-buildx
docker buildx version
  6. Bước 6: Cài Git & lấy source code của khoá học

    Cài Git để clone source code về EC2 (hoặc copy thư mục section_8_docker_basic_operation lên EC2 bằng scp):

    sudo dnf install -y git

Chạy container đầu tiên & đăng ký Docker Hub (áp dụng cho cả 2 cách)

  1. Bước 1: Chạy container hello-world 
    docker run hello-world
Unable to find image 'hello-world:latest' locally
latest: Pulling from library/hello-world
...
Hello from Docker!
This message shows that your installation appears to be working correctly.

To generate this message, Docker took the following steps:
 1. The Docker client contacted the Docker daemon.

    Đọc kỹ 4 bước Docker in ra: Client → Daemon → pull image từ Docker Hub → tạo container và in kết quả. Đây chính là kiến trúc đã học ở chương trước.

  2. Bước 2: Đăng ký tài khoản Docker Hub

    Truy cập hub.docker.com/signup và đăng ký tài khoản miễn phí (Personal). Sau khi đăng nhập, bạn có thể tìm kiếm image (ví dụ nginx, httpd) và xem các tag, hướng dẫn sử dụng của image đó.

  3. Bước 3: Tạo Personal Access Token & đăng nhập

    Trong Docker Hub, vào Account settings → Personal access tokens, tạo token với thông số:

    • Description: docker-lab
    • Expiration: 30 days
    • Access permissions: Read-only (đủ để pull image)

    Copy token (chỉ hiển thị 1 lần), sau đó đăng nhập. Khi được hỏi Password, dán token vào:

    docker login -u <DOCKERHUB_USERNAME>
Password:
Login Succeeded

    💡 Docker Hub giới hạn số lần pull image với người dùng chưa đăng nhập. Đăng nhập giúp tăng giới hạn này, tránh lỗi toomanyrequests khi làm lab.

Troubleshoot

Docker Desktop báo WSL 2 installation is incomplete / Virtualization support not detected
Nguyên nhân: WSL 2 chưa cài hoặc Virtualization (Intel VT-x / AMD-V) bị tắt trong BIOS.
Giải pháp: Chạy wsl --install, wsl --update trong PowerShell (Administrator); bật Virtualization trong BIOS rồi khởi động lại máy.
permission denied while trying to connect to the Docker daemon socket at unix:///var/run/docker.sock
Nguyên nhân: User hiện tại chưa thuộc group docker, hoặc đã thêm nhưng chưa đăng nhập lại.
Giải pháp: Chạy sudo usermod -aG docker ec2-user, thoát SSH và đăng nhập lại, kiểm tra bằng lệnh groups.
Cannot connect to the Docker daemon. Is the docker daemon running?
Nguyên nhân: Docker Desktop chưa mở, hoặc service docker trên EC2 chưa chạy.
Giải pháp: Mở Docker Desktop và đợi Engine running; trên EC2 chạy sudo systemctl start docker.
docker: 'compose' is not a docker command
Nguyên nhân: Chưa cài Compose plugin, hoặc tải sai kiến trúc CPU.
Giải pháp: Thực hiện lại Bước 5, kiểm tra file /usr/local/lib/docker/cli-plugins/docker-compose có quyền thực thi (ls -l).
toomanyrequests: You have reached your unauthenticated pull rate limit
Nguyên nhân: Vượt giới hạn pull của Docker Hub cho người dùng ẩn danh (hay gặp khi nhiều người dùng chung 1 IP public).
Giải pháp: docker login bằng tài khoản Docker Hub rồi pull lại.

Dọn dẹp resource

EC2 tính phí theo giờ khi đang chạy. Nếu dùng Cách 2, hãy Stop instance docker-lab-server mỗi khi nghỉ học và Start lại khi làm lab tiếp theo (Public IP sẽ thay đổi). Instance sẽ được dùng xuyên suốt Lab 2 → Lab 9 và xoá ở chương cuối của section. EBS volume vẫn tính phí kể cả khi instance đã Stop.

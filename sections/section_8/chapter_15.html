Docker cheat sheet

Các lệnh thường dùng nhất, đầy đủ hơn trong file sourcecode/section_8_docker_basic_operation/docker_cheatsheet/commands.sh.

Image

LệnhÝ nghĩa
docker pull <image>:<tag>Tải image từ registry
docker imagesLiệt kê image
docker build -t <image>:<tag> .Build image từ Dockerfile trong thư mục hiện tại
docker tag <image>:<tag> <registry>/<repo>:<tag>Đánh tag mới cho image
docker push <registry>/<repo>:<tag>Đẩy image lên registry
docker image history / inspectXem layer / metadata của image
docker rmi <image>:<tag>Xoá image

Container

LệnhÝ nghĩa
docker run -d -p 8080:80 --name web nginxChạy container nền, mapping port, đặt tên
docker run -it ubuntu bash / --rmChạy interactive / tự xoá khi kết thúc
docker run -e KEY=value -v vol:/data ...Truyền biến môi trường, gắn volume
docker ps / docker ps -aContainer đang chạy / tất cả container
docker logs -f <container>Theo dõi log
docker exec -it <container> shMở shell trong container đang chạy
docker stop | start | restart <container>Dừng / chạy / khởi động lại
docker rm [-f] <container>Xoá container (-f: xoá cả khi đang chạy)
docker stats / docker inspectTheo dõi tài nguyên / xem chi tiết

Docker Compose & dọn dẹp

LệnhÝ nghĩa
docker compose up -d --buildBuild & start toàn bộ service
docker compose up -d --scale web=3Chạy 3 replica của service web
docker compose ps / logs -f / execTrạng thái / log / chạy lệnh trong service
docker compose down [-v] [--rmi local]Xoá container, network (và volume, image đã build)
docker system dfXem dung lượng Docker đang dùng
docker system prune [-a] [--volumes]Xoá tài nguyên không dùng (cẩn thận với -a --volumes)

Dọn dẹp resource

Hãy rà soát và xoá toàn bộ resource của section để tránh phát sinh chi phí. EC2, task Fargate, Public IPv4, EBS volume và Load Balancer đều tính phí theo giờ kể cả khi không có traffic.

Trên AWS

  • Stop toàn bộ task và xoá ECS cluster docker-lab-cluster; xoá ECS Service (nếu đã tự tạo thêm).
  • Deregister & delete task definition my-httpd-task.
  • Xoá ECR repository my-httpd (kèm toàn bộ image).
  • Xoá Application Load Balancer, Target Group (nếu đã tự thử nghiệm thêm).
  • Terminate EC2 docker-lab-server; kiểm tra EBS Volume, Snapshot, Elastic IP không còn sót lại.
  • Xoá Security Group docker-lab-sg, ecs-task-sg, key pair docker-lab-key, CloudWatch log group /ecs/my-httpd-task.
  • Môi trường Cloud9 cũ (nếu có từ phiên bản trước của khoá học): xoá environment để dừng EC2 đi kèm.
  • Kiểm tra lại trang Billing and Cost Management sau 1 ngày.

Trên máy local

Kiểm tra dung lượng và xoá các container, image, volume, build cache không còn dùng:

docker ps -a
docker system df
docker system prune -a --volumes
docker system prune -a --volumes xoá tất cả image và volume không được container nào sử dụng – bao gồm cả dữ liệu của các dự án khác trên máy bạn. Chỉ chạy khi chắc chắn, hoặc xoá từng resource của lab bằng docker rm, docker rmi, docker volume rm.

Section tiếp theo

Bạn đã biết đóng gói ứng dụng thành image, chạy hệ thống nhiều container bằng Docker Compose và đưa image lên AWS. Ở các section tiếp theo, chúng ta sẽ tự động hoá toàn bộ quy trình build → push lên ECR → deploy lên ECS bằng pipeline CI/CD với CodePipeline, CodeBuild, CodeDeploy, Jenkins và GitHub Actions; sau đó là Kubernetes & EKS.

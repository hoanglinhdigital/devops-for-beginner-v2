8. Thao tác cơ bản với Docker / Lab 2: Thao tác cơ bản với Image & Container

Mục tiêu

  • Pull image từ Docker Hub, liệt kê và xem thông tin image.
  • Chạy container ở chế độ nền (-d), mapping port (-p) và truy cập ứng dụng qua browser.
  • Liệt kê container theo trạng thái, xem log, Start/Stop/Restart container.
  • Truy cập vào bên trong container đang chạy bằng docker exec, chạy container ở chế độ interactive (-it).
  • Xoá container, xoá image và dọn dẹp tài nguyên Docker.

Các bước thực hành

  1. Bước 1: Pull image từ Docker Hub

    Cú pháp: docker pull <image>:<tag>. Không chỉ định tag thì Docker dùng tag latest.

    docker pull nginx:latest
docker pull ubuntu:24.04
  2. Bước 2: Liệt kê & xem thông tin image 
    docker images
REPOSITORY   TAG       IMAGE ID       CREATED       SIZE
nginx        latest    a830707172e8   2 weeks ago   192MB
ubuntu       24.04     59ab366372d5   3 weeks ago   78.1MB

    Xem metadata (port, biến môi trường, lệnh khởi động...) và các layer của image:

    docker image inspect nginx:latest
docker image history nginx:latest
  3. Bước 3: Chạy container nginx

    Chạy container ở chế độ nền và map port 8080 (host) → 80 (container):

    docker run -d -p 8080:80 --name my-nginx nginx:latest
    Tham sốÝ nghĩa
    -dDetached – chạy nền, trả lại terminal cho bạn
    -p 8080:80Mapping <host port>:<container port>
    --name my-nginxĐặt tên container (nếu không, Docker tự sinh tên ngẫu nhiên)
    nginx:latestImage dùng để chạy container (tự động pull nếu chưa có)

    Mở browser truy cập http://localhost:8080 (hoặc http://<EC2_PUBLIC_IP>:8080), bạn sẽ thấy trang Welcome to nginx!

    curl http://localhost:8080
  4. Bước 4: Liệt kê container & xem log

    docker ps chỉ hiển thị container đang chạy, thêm -a để hiển thị container ở mọi trạng thái:

    docker ps
CONTAINER ID   IMAGE          COMMAND                  CREATED         STATUS         PORTS                  NAMES
3c1f0e8a9b2d   nginx:latest   "/docker-entrypoint.…"   1 minute ago    Up 1 minute    0.0.0.0:8080->80/tcp   my-nginx
    docker ps -a
docker logs my-nginx
docker logs -f my-nginx

    -f (follow) theo dõi log liên tục: refresh browser vài lần để thấy access log mới, nhấn Ctrl + C để thoát.

  5. Bước 5: Stop / Start / Restart container 
    docker stop my-nginx
docker ps -a
docker start my-nginx
docker restart my-nginx

    Sau khi stop, STATUS chuyển thành Exited (0) và browser không truy cập được nữa. Có thể dùng tên hoặc Container ID (chỉ cần vài ký tự đầu, ví dụ docker stop 3c1f).

  6. Bước 6: Truy cập vào container đang chạy

    docker exec -it mở một shell bên trong container (tương tự SSH vào server):

    docker exec -it my-nginx /bin/bash

    Bên trong container, xem hệ điều hành và sửa trang chủ của nginx:

    cat /etc/os-release
ls /usr/share/nginx/html
echo "<h1>Hello from container</h1>" > /usr/share/nginx/html/index.html
exit

    Refresh browser để thấy trang chủ đã thay đổi. Lưu ý thay đổi này chỉ nằm trong container layer – sẽ mất khi container bị xoá.

    💡 Một số image tối giản (alpine) không có bash, hãy dùng /bin/sh thay thế.

  7. Bước 7: Chạy container ở chế độ interactive

    -it = -i (giữ STDIN) + -t (cấp terminal). Container chạy Ubuntu và mở shell cho bạn thao tác:

    docker run -it --name my-ubuntu ubuntu:24.04
    cat /etc/os-release
exit

    Khi bạn exit, process chính (bash) kết thúc nên container chuyển sang Exited. Container chỉ sống khi process chính còn chạy.

    Chạy nền nhưng vẫn giữ terminal (-dit) để container không bị exit, sau đó exec vào:

    docker run -dit --name my-ubuntu-bg ubuntu:24.04
docker exec -it my-ubuntu-bg bash

    Container tự xoá sau khi chạy xong với --rm (hữu ích khi chỉ cần chạy 1 lệnh):

    docker run --rm ubuntu:24.04 echo "Hello Docker"
Hello Docker
  8. Bước 8: Theo dõi tài nguyên container 
    docker stats --no-stream
docker inspect my-nginx

    docker stats hiển thị CPU, RAM, network I/O của từng container; docker inspect hiển thị IP, mount, biến môi trường... dạng JSON.

  9. Bước 9: Xoá container & image

    Container phải ở trạng thái dừng mới xoá được, hoặc dùng -f để xoá cưỡng bức (cẩn thận khi dùng):

    docker stop my-nginx
docker rm my-nginx
docker rm -f my-ubuntu-bg
docker rm my-ubuntu

    Xoá image theo <image>:<tag> hoặc Image ID. Image đang được container sử dụng sẽ không xoá được:

    docker rmi nginx:latest
docker rmi ubuntu:24.04
docker images

Troubleshoot

Bind for 0.0.0.0:8080 failed: port is already allocated
Nguyên nhân: Port 8080 trên host đang được một container hoặc ứng dụng khác sử dụng.
Giải pháp: Xoá container cũ (docker ps để tìm) hoặc dùng port khác, ví dụ -p 8081:80.
Conflict. The container name "/my-nginx" is already in use
Nguyên nhân: Đã tồn tại container cùng tên (kể cả đang ở trạng thái Exited).
Giải pháp: docker rm -f my-nginx rồi chạy lại, hoặc đặt tên khác.
conflict: unable to remove repository reference "nginx:latest" (must force) - container ... is using its referenced image
Nguyên nhân: Vẫn còn container (kể cả đã dừng) được tạo từ image này.
Giải pháp: Xoá container trước (docker ps -a, docker rm), sau đó xoá image.
EC2: browser không truy cập được http://<EC2_PUBLIC_IP>:8080
Nguyên nhân: Security Group chưa mở port 8080, hoặc IP của bạn đã thay đổi so với rule My IP.
Giải pháp: Kiểm tra inbound rule của docker-lab-sg; thử curl http://localhost:8080 ngay trên EC2 để xác định lỗi nằm ở container hay ở network.

Dọn dẹp resource

Kiểm tra dung lượng Docker đang dùng và xoá toàn bộ container đã dừng, network không dùng, image không có tag (dangling) và build cache:

docker system df
docker system prune
Nếu làm lab trên EC2, hãy Stop instance docker-lab-server khi nghỉ học để tiết kiệm chi phí.

5. Infra as Code sử dụng Terraform / Lab 4: Terraform Output

Mục tiêu

  • Hiểu Terraform Output là gì và dùng để làm gì.
  • Gắn Elastic IP cho EC2 và xuất ra các giá trị: public IP, private IP, Security Group ID, lệnh SSH.
  • Sử dụng lệnh terraform output để đọc giá trị output, kết hợp output với lệnh shell.

Kiến thức cần nắm

Output là "giá trị trả về" của một Terraform project/module. Sau khi apply, Terraform in ra các output trên màn hình và lưu chúng trong state. Output được dùng để: (1) hiển thị thông tin cần thiết cho người dùng (IP, DNS của Load Balancer...), (2) truyền dữ liệu giữa các module (sẽ học ở Lab 5), (3) cung cấp dữ liệu cho script hoặc CI/CD pipeline. 

output "instance_public_ip" {
  description = "Elastic IP gắn vào EC2"   # mô tả (không bắt buộc)
  value       = aws_eip.demo_eip.public_ip  # biểu thức bất kỳ: thuộc tính resource, chuỗi, list...
  sensitive   = false                       # true: ẩn giá trị khi in ra màn hình
}

Yêu cầu trước khi bắt đầu

  • Hoàn thành Lab 3 (đã destroy resource). Lab này phát triển tiếp từ code của Lab 3.
  • Keypair tại ~/terraform-labs/keypair/.

Các bước thực hành

  1. Bước 1: Copy code từ Lab 3

    Copy các file .tf và terraform.tfvars (không copy thư mục .terraform và file state):

    mkdir -p ~/terraform-labs/lab4_outputs
cd ~/terraform-labs/lab4_outputs
cp ../lab3_variables/main.tf ../lab3_variables/variable.tf ../lab3_variables/terraform.tfvars .
code .
  2. Bước 2: Thêm Elastic IP vào main.tf

    Thêm đoạn sau vào cuối file main.tf. Elastic IP là IP public cố định, không thay đổi khi stop/start EC2:

    # Elastic IP: IP public cố định, không đổi khi stop/start EC2
resource "aws_eip" "demo_eip" {
  instance = aws_instance.demo_instance.id
  domain   = "vpc"
}
  3. Bước 3: Tạo file output.tf

    Theo quy ước, output được đặt trong file riêng output.tf. Output ssh_command dùng string interpolation để tạo sẵn lệnh SSH:

    📄 lab4_outputs/output.tf

    output "instance_id" {
  description = "ID của EC2 instance"
  value       = aws_instance.demo_instance.id
}

output "instance_public_ip" {
  description = "Elastic IP gắn vào EC2"
  value       = aws_eip.demo_eip.public_ip
}

output "instance_private_ip" {
  description = "Private IP của EC2"
  value       = aws_instance.demo_instance.private_ip
}

output "security_group_id" {
  description = "ID của Security Group"
  value       = aws_security_group.demo_sg.id
}

output "ssh_command" {
  description = "Lệnh SSH vào EC2"
  value       = "ssh -i ../keypair/udemy-key ec2-user@${aws_eip.demo_eip.public_ip}"
}
  4. Bước 4: Deploy và xem output 
    terraform init
terraform apply -auto-approve

    Cuối quá trình apply, Terraform in ra các output:

    Outputs:

instance_id = "i-0abc123def4567890"
instance_private_ip = "172.31.20.15"
instance_public_ip = "13.250.xx.xx"
security_group_id = "sg-0abc123def4567890"
  5. Bước 5: Đọc output bằng lệnh terraform output

    Xem lại toàn bộ output bất kỳ lúc nào (đọc từ state, không gọi lên AWS):

    terraform output

    Lấy một giá trị cụ thể dạng text thuần (không có dấu ngoặc kép) với -raw, hoặc toàn bộ dạng JSON với -json (thường dùng trong script/CI):

    terraform output -raw instance_public_ip
terraform output -json
  6. Bước 6: SSH vào EC2 bằng output

    Kết hợp output với shell để SSH mà không cần copy IP thủ công (Mac/Linux nhớ chmod 400 ../keypair/udemy-key nếu chưa làm):

    ssh -i ../keypair/udemy-key ec2-user@$(terraform output -raw instance_public_ip)

    Gõ exit để thoát.

  7. Bước 7: Kiểm chứng Elastic IP không đổi khi stop/start

    Trên Console vào EC2 → Instances, chọn instance udemy-demo-dev, thực hiện Stop rồi Start. Sau khi instance Running trở lại, public IP vẫn bằng giá trị terraform output -raw instance_public_ip.

Kiểm tra kết quả

✅ Lab thành công khi

  • terraform apply tạo 4 resource (key pair, SG, EC2, EIP) và in ra 5 output.
  • terraform output -raw instance_public_ip trả về đúng Elastic IP hiển thị trên Console.
  • SSH thành công bằng lệnh kết hợp với output.

Troubleshoot

Warning: No outputs found
Nguyên nhân: Chưa apply sau khi thêm output.tf, hoặc đang đứng sai thư mục.
Giải pháp: Chạy terraform apply (Terraform chỉ cập nhật output vào state, không tạo thêm resource) và kiểm tra pwd.
Reference to undeclared resource trong output.tf
Nguyên nhân: Tên resource trong output không khớp với main.tf (ví dụ aws_eip.demo_eip chưa được thêm).
Giải pháp: Kiểm tra Bước 2 đã thêm resource aws_eip chưa.
AddressLimitExceeded
Nguyên nhân: Mỗi region mặc định giới hạn 5 Elastic IP.
Giải pháp: Giải phóng (Release) các Elastic IP không dùng tại EC2 → Elastic IPs.

Dọn dẹp resource

Elastic IP tính phí (khoảng 0.005 USD/giờ cho mỗi IPv4 public) kể cả khi gắn vào instance đang chạy, và vẫn tính phí khi instance đã stop. Hãy destroy ngay sau khi học xong.
terraform destroy -auto-approve

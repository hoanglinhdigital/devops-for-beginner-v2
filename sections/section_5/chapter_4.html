5. Infra as Code sử dụng Terraform / Lab 1: Cài đặt môi trường làm việc với Terraform

Mục tiêu

  • Cài đặt và kiểm tra version của AWS CLI v2.
  • Cấu hình credential để AWS CLI và Terraform có quyền truy cập tài khoản AWS.
  • Cài đặt và kiểm tra version của Terraform.
  • Cài đặt extension Terraform cho VS Code.
  • Làm quen với tài liệu chính thức của Terraform và cách tra cứu.

Yêu cầu trước khi bắt đầu

  • Tài khoản AWS và một IAM User có quyền AdministratorAccess (dùng cho lab, không dùng root user).
  • Đã cài VS Code và Git. Người dùng Windows nên dùng Git Bash làm terminal cho toàn bộ section này; người dùng Mac dùng Terminal.

Các bước thực hành

  1. Bước 1: Cài đặt AWS CLI v2

    Tải bộ cài từ trang chính thức: Install AWS CLI v2 (Windows: file .msi, Mac: file .pkg). Sau khi cài xong, mở terminal mới và kiểm tra version:

    aws --version
aws-cli/2.x.x Python/3.x.x Windows/10 exe/AMD64
  2. Bước 2: Tạo Access Key và cấu hình AWS CLI

    Trên AWS Console, vào IAM → Users → (user của bạn) → Security credentials và tạo Access key với use case Command Line Interface (CLI). Lưu lại Access key ID và Secret access key.

    Chạy lệnh sau và nhập thông tin khi được hỏi:

    aws configure
    • AWS Access Key ID: access key vừa tạo
    • AWS Secret Access Key: secret key vừa tạo
    • Default region name: ap-southeast-1
    • Default output format: json

    Kiểm tra credential hoạt động:

    aws sts get-caller-identity
    Bảo mật: Không chia sẻ, không commit Access Key lên Git. Terraform sẽ tự đọc credential từ file ~/.aws/credentials, bạn không cần ghi access key vào file .tf.
  3. Bước 3: Cài đặt Terraform

    Hướng dẫn chính thức: developer.hashicorp.com/terraform/install. Khoá học yêu cầu Terraform >= 1.10.

    Windows (PowerShell hoặc Git Bash):

    winget install --id Hashicorp.Terraform -e

    MacOS (Homebrew):

    brew tap hashicorp/tap
brew install hashicorp/tap/terraform

    Hoặc tải file zip, giải nén và thêm thư mục chứa terraform vào biến môi trường PATH. Mở terminal mới và kiểm tra:

    terraform -version
Terraform v1.13.x
on windows_amd64
  4. Bước 4: Cài đặt Terraform extension cho VS Code

    Trong VS Code, mở tab Extensions, tìm và cài extension HashiCorp Terraform (publisher: HashiCorp). Extension hỗ trợ tô màu cú pháp, gợi ý thuộc tính (auto-complete), format code khi lưu và nhảy tới định nghĩa variable/module.

  5. Bước 5: Tạo thư mục làm việc cho các bài lab

    Tạo một thư mục chứa toàn bộ lab của section này. Mỗi bài lab sẽ là một thư mục con, keypair dùng chung đặt trong thư mục keypair:

    mkdir -p ~/terraform-labs/keypair
cd ~/terraform-labs
    terraform-labs/
├── keypair/          # keypair dùng chung (tạo ở Lab 2)
├── lab2_ec2_basic/
├── lab3_variables/
└── ...

    Source code đầy đủ của các lab nằm trong repository khoá học tại sourcecode/section_5_IaC_using_Terraform/ với cùng cấu trúc thư mục.

  6. Bước 6: Làm quen với tài liệu Terraform

    Hai trang bạn sẽ dùng nhiều nhất:

    • Terraform Language: cú pháp variable, output, module, function, backend...
    • AWS Provider docs: tìm resource theo tên, ví dụ gõ aws_instance vào ô tìm kiếm. Mỗi trang có Example Usage (code mẫu), Argument Reference (tham số đầu vào) và Attribute Reference (giá trị có thể lấy ra để dùng cho resource khác hoặc output).

Kiểm tra kết quả

✅ Lab thành công khi

  • aws --version hiển thị aws-cli/2.x.
  • aws sts get-caller-identity trả về Account ID và ARN của IAM user.
  • terraform -version hiển thị version >= 1.10.
  • Mở một file .tf bất kỳ trong VS Code có tô màu cú pháp.

Troubleshoot

terraform: command not found / 'terraform' is not recognized
Nguyên nhân: Thư mục chứa terraform chưa nằm trong PATH, hoặc terminal được mở trước khi cài.
Giải pháp: Đóng và mở lại terminal/VS Code; nếu cài bằng file zip, thêm thư mục chứa terraform.exe vào biến môi trường PATH.
Unable to locate credentials hoặc InvalidClientTokenId
Nguyên nhân: Chưa chạy aws configure hoặc nhập sai/copy thừa khoảng trắng ở access key.
Giải pháp: Chạy lại aws configure; kiểm tra access key còn trạng thái Active trong IAM.
Version Terraform cũ hơn 1.10
Nguyên nhân: Máy đã cài sẵn bản cũ (ví dụ qua Chocolatey).
Giải pháp: Nâng cấp (winget upgrade Hashicorp.Terraform, brew upgrade hashicorp/tap/terraform hoặc choco upgrade terraform), kiểm tra which terraform để chắc chắn terminal đang dùng đúng bản mới.

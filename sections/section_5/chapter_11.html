5. Infra as Code sử dụng Terraform / Lab 8: Bài tập cuối chương – ALB, Auto Scaling & MongoDB

Mục tiêu

  • Phân tích một sơ đồ hệ thống và thiết kế cấu trúc Terraform có phân chia module.
  • Implement Terraform template theo thiết kế có sẵn gồm 5 module: network, security, bastion, storage, application.
  • Deploy một stack hoàn chỉnh: VPC, Subnet, Security Group, Bastion EC2, Application Load Balancer, Target Group, Auto Scaling Group và MongoDB database.
  • Sử dụng user_data và hàm templatefile() để tự động cài đặt ứng dụng khi EC2 khởi động.

Kiến trúc tổng quan

Ứng dụng mẫu là Vote App (mã nguồn mở của CloudAcademy): Frontend React chạy trên nginx (port 80) và API viết bằng Go (port 8080), dữ liệu lưu trong MongoDB.

Yêu cầu trước khi bắt đầu

  • Ôn lại kiến thức ALB, Target Group, Listener Rule, Auto Scaling ở Section 4.

  6. Bước 6: Module application

    Script cài đặt cần biết DNS của ALB và IP của MongoDB — đây là các giá trị chỉ có sau khi resource được tạo. Hàm templatefile() đọc file template và thay các biến ${alb_dns}, ${mongodb_ip} bằng giá trị thật trước khi gán vào Launch Template.

    📄 lab8_final_assignment/modules/application/userdata.sh.tftpl

    #!/bin/bash
# File template: Terraform thay ${alb_dns} và ${mongodb_ip} bằng giá trị thật thông qua hàm templatefile()
apt-get -y update
apt-get -y install nginx jq

ALB_DNS=${alb_dns}
MONGODB_PRIVATEIP=${mongodb_ip}

mkdir -p /tmp/cloudacademy-app
cd /tmp/cloudacademy-app

echo ===========================
echo FRONTEND - download latest release and install...
mkdir -p ./voteapp-frontend-react-2023
pushd ./voteapp-frontend-react-2023
curl -sL https://api.github.com/repos/cloudacademy/voteapp-frontend-react-2023/releases/latest | jq -r '.assets[0].browser_download_url' | xargs curl -OL
INSTALL_FILENAME=$(curl -sL https://api.github.com/repos/cloudacademy/voteapp-frontend-react-2023/releases/latest | jq -r '.assets[0].name')
tar -xvzf $INSTALL_FILENAME
rm -rf /var/www/html
cp -R build /var/www/html
cat > /var/www/html/env-config.js << EOFF
window._env_ = {REACT_APP_APIHOSTPORT: "$ALB_DNS"}
EOFF
popd

echo ===========================
echo API - download latest release, install, and start...
mkdir -p ./voteapp-api-go
pushd ./voteapp-api-go
curl -sL https://api.github.com/repos/cloudacademy/voteapp-api-go/releases/latest | jq -r '.assets[] | select(.name | contains("linux-amd64")) | .browser_download_url' | xargs curl -OL
INSTALL_FILENAME=$(curl -sL https://api.github.com/repos/cloudacademy/voteapp-api-go/releases/latest | jq -r '.assets[] | select(.name | contains("linux-amd64")) | .name')
tar -xvzf $INSTALL_FILENAME
# Start the API (port 8080) ở background
MONGO_CONN_STR=mongodb://$MONGODB_PRIVATEIP:27017/langdb nohup ./api > /var/log/voteapp-api.log 2>&1 &
popd

systemctl restart nginx
echo fin v1.00!

    #==========Launch Template===========
resource "aws_launch_template" "apptemplate" {
  name = "application"

  image_id               = var.ami
  instance_type          = var.instance_type
  key_name               = var.key_name
  vpc_security_group_ids = [var.webserver_sg_id]

  # templatefile(): đọc file template và truyền giá trị biến vào
  user_data = base64encode(templatefile("${path.module}/userdata.sh.tftpl", {
    alb_dns    = aws_lb.alb1.dns_name
    mongodb_ip = var.mongodb_ip
  }))

  tag_specifications {
    resource_type = "instance"

    tags = {
      Name  = "FrontendApp"
      Owner = "Udemy"
    }
  }
}

    type             = "forward"

  listener_arn = aws_lb_listener.front_end.arn
  priority     = 100

      values = ["/"]

  action {
    type             = "forward"
    target_group_arn = aws_lb_target_group.webserver.arn
  }
}

# Request tới API được chuyển tới target group port 8080
resource "aws_lb_listener_rule" "api_rule1" {
  listener_arn = aws_lb_listener.front_end.arn
  priority     = 10

  condition {
    path_pattern {
      values = [
        "/languages",
        "/languages/*",
        "/languages/*/*",
        "/ok"
      ]
    }
  }

  action {
    type             = "forward"
    target_group_arn = aws_lb_target_group.api.arn
  }
}

Troubleshoot

Invalid value for variable: workstation_ip phải là CIDR hợp lệ
Nguyên nhân: Nhập IP thiếu /32 hoặc sai định dạng.
Giải pháp: Sửa thành dạng x.x.x.x/32 trong terraform.tfvars.
ALB trả về 502 Bad Gateway / 503, target unhealthy
Nguyên nhân: user_data chưa chạy xong (mất vài phút), hoặc app chưa tải được từ GitHub.
Giải pháp: Đợi thêm 3–5 phút. Nếu vẫn lỗi, SSH qua Bastion vào app instance và xem log: sudo tail -n 50 /var/log/cloud-init-output.log và cat /var/log/voteapp-api.log.
Trang web hiển thị nhưng không có dữ liệu / API lỗi kết nối DB
Nguyên nhân: MongoDB chưa cài xong khi API khởi động, hoặc SG mongodb chưa cho phép 27017 từ SG application.
Giải pháp: Kiểm tra trên MongoDB: sudo systemctl status mongod, sudo tail /var/log/cloud-init-output.log; sau đó terminate các app instance để ASG tạo lại instance mới.
SSH vào Bastion bị timeout
Nguyên nhân: Public IP của bạn đã thay đổi (mạng di động, đổi Wi-Fi) so với workstation_ip.
Giải pháp: Cập nhật workstation_ip trong tfvars rồi chạy terraform apply — chỉ Security Group bastion được cập nhật.
Permission denied (publickey) khi SSH từ Bastion vào private instance
Nguyên nhân: Không bật agent forwarding hoặc chưa ssh-add private key.
Giải pháp: Chạy lại ssh-add -l để kiểm tra key đã được thêm, SSH vào Bastion với tham số -A.

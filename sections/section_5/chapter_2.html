5. Infra as Code sử dụng Terraform / Các công cụ Infra as Code thường dùng

Giới thiệu

Có rất nhiều công cụ IaC, mỗi công cụ được thiết kế cho một mục đích riêng. Có thể chia thành 2 nhóm chính: Provisioning (tạo hạ tầng: VPC, EC2, RDS... — ví dụ CloudFormation, CDK, Terraform) và Configuration Management (cấu hình phần mềm bên trong server đã có — ví dụ Ansible, Puppet, Chef). Chương này giới thiệu các công cụ phổ biến để bạn hiểu vì sao khoá học chọn Terraform.

Đặc điểm chính của các công cụ Provisioning

  • AWS CloudFormation (AWS): định nghĩa resource dưới dạng template YAML hoặc JSON, deploy thành các CloudFormation stack. Là service native của AWS nên chỉ hỗ trợ AWS.
  • AWS Cloud Development Kit – CDK (AWS): định nghĩa hạ tầng bằng ngôn ngữ lập trình quen thuộc (TypeScript, JavaScript, Python, C#, Java). Code CDK được compile (synth) thành CloudFormation template, nên phía sau vẫn là CloudFormation stack. Chỉ hỗ trợ AWS.
  • Terraform (HashiCorp): mã nguồn mở, dùng ngôn ngữ HCL, hỗ trợ rất nhiều nhà cung cấp (AWS, Azure, GCP, Kubernetes, Github, Cloudflare...). Terraform gọi thẳng API của Cloud, không tạo CloudFormation stack.
  • Azure Resource Manager (ARM) Templates / Bicep (Microsoft): định nghĩa hạ tầng Azure qua template JSON (hoặc Bicep).
  • Google Cloud Deployment Manager / Infrastructure Manager (Google): tự động hoá tạo resource trên GCP qua file cấu hình YAML.
  • OpenTofu, Pulumi: OpenTofu là bản fork mã nguồn mở của Terraform (cú pháp gần như giống hệt); Pulumi cho phép viết IaC đa cloud bằng ngôn ngữ lập trình.

❓ Trong các công cụ IaC, công cụ nào là tốt nhất?
Không có công cụ "tốt nhất". Các công cụ được thiết kế đa dạng mục đích và có ưu nhược điểm riêng. Tuỳ vào nhu cầu dự án và khả năng của thành viên mà chọn công nghệ phù hợp để mang lại hiệu quả cao nhất. Ví dụ: những người đi lên từ developer thường thích dùng CDK, những người đi lên từ system admin thường thích dùng Terraform.

Use Cases

🏢 Doanh nghiệp đa cloud

Công ty chạy hệ thống chính trên AWS, dùng Cloudflare cho DNS/CDN và Github cho source code → Terraform quản lý tất cả bằng một ngôn ngữ duy nhất.

👨‍💻 Team Developer thuần AWS

Team backend TypeScript muốn định nghĩa Lambda, API Gateway, DynamoDB ngay trong repo ứng dụng → AWS CDK (hoặc AWS SAM sẽ học ở section sau).

⚙️ Cấu hình hàng trăm server

Cần cài đặt agent monitoring, cập nhật cấu hình nginx trên nhiều EC2 cùng lúc → Ansible playbook chạy qua SSH.

Thông tin bổ sung

  • Khoá học sử dụng Terraform vì phổ biến nhất trên thị trường tuyển dụng DevOps, hỗ trợ đa cloud và kiến thức có thể dùng lại với OpenTofu.
  • Từ năm 2023 Terraform chuyển sang license BSL (vẫn miễn phí cho người dùng cuối); cộng đồng tạo ra OpenTofu (license MPL, thuộc Linux Foundation) tương thích với Terraform.
  • Kỳ thi AWS (SAA, DVA, DOP) chủ yếu hỏi về CloudFormation, CDK, SAM — nên nắm khái niệm stack, change set, drift detection của CloudFormation.

5. Infra as Code sử dụng Terraform / Tổng kết section & dọn dẹp resource

Nội dung đã học

  • IaC là gì và công dụng của IaC: tự động hoá, nhất quán, tái sử dụng, kiểm soát phiên bản.
  • Các công cụ IaC phổ biến (CloudFormation, CDK, Terraform, Ansible...) và cách lựa chọn.
  • Cách setup môi trường làm việc Terraform: AWS CLI, Terraform CLI, VS Code extension.
  • Cơ chế hoạt động và các thành phần cơ bản của Terraform: provider, resource, data source, variable, output, module, state.
  • Các bước triển khai hạ tầng lên AWS với Terraform: init → plan → apply → destroy.
  • Vận dụng Terraform để triển khai hạ tầng theo System Design (VPC, ALB, Auto Scaling, Database).
  • Quy hoạch Terraform theo module để tái sử dụng, quản lý state trên S3 và triển khai multi-environment, multi-region.

Checklist dọn dẹp resource

Trước khi chuyển sang section tiếp theo, hãy chắc chắn không còn resource nào của section này đang chạy để tránh phát sinh chi phí ngoài ý muốn.
  1. Bước 1: Chạy destroy ở mọi thư mục lab đã apply

    Trong mỗi thư mục lab, kiểm tra state còn resource không. Nếu lệnh dưới đây trả về danh sách resource thì chạy terraform destroy -auto-approve ở thư mục đó:

    terraform state list
  2. Bước 2: Kiểm tra trên AWS Console ở cả 2 region Singapore và Tokyo
    • VPC → NAT gateways: không còn NAT Gateway trạng thái Available.
    • EC2 → Elastic IPs: không còn IP nào.
    • EC2 → Load Balancers, Auto Scaling Groups, Instances: không còn resource của lab.
    • VPC → Your VPCs: chỉ còn Default VPC.
    • EC2 → Key Pairs: xoá các key udemy-keypair* còn sót lại (không tính phí nhưng nên dọn).
  3. Bước 3: Xoá S3 bucket chứa state

    Nếu chưa xoá ở Lab 10: chọn bucket udemy-terraform-state-... → Empty → Delete.

  4. Bước 4: Kiểm tra hoá đơn

    Vào Billing and Cost Management → Bills, xem chi phí theo dịch vụ (EC2-Other là nơi tính phí NAT Gateway và Elastic IP) để chắc chắn không còn chi phí phát sinh thêm.

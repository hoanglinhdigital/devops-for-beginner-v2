4. Giới thiệu & ôn lại kiến thức AWS / Tổng quan các dịch vụ chính trên AWS

Giới thiệu

AWS có hơn 200 dịch vụ, được chia thành nhiều nhóm theo chức năng: Compute, Storage, Networking, Database, Security, Monitoring, Integration, DevOps... Chương này giúp bạn có bản đồ tổng quan để biết mỗi dịch vụ nằm ở đâu và dùng để làm gì — không cần nhớ hết tên hay biểu tượng (vì Google có!).

Đặc điểm của danh sách dưới đây

  • Được sắp xếp theo mức độ phổ biến trong dự án thực tế — service hay dùng được đưa lên đầu.
  • Sắp xếp theo độ khó tăng dần — service dễ tiếp cận được đưa lên trước.
  • Chỉ là một phần nhỏ, không phải tất cả dịch vụ của AWS.
  • Những dịch vụ có nhãn Hay dùng và nền màu cam là dịch vụ thường xuyên xuất hiện trong dự án.
  • Khoá DevOps này tập trung vào các nhóm: Compute, Container, Database, Network, Security, Deployment & Monitoring.

🖥️ Compute & Container

Amazon EC2Hay dùngMáy chủ ảo — nền tảng của hầu hết các hệ thống.
EC2 Auto ScalingHay dùngTự động tăng/giảm số lượng EC2 theo tải.
AWS LambdaHay dùngChạy code dạng function, không cần quản lý server.
Amazon ECS / FargateHay dùngChạy container được quản lý bởi AWS.
Amazon ECRHay dùngRegistry lưu trữ Docker image.
Amazon EKSHay dùngKubernetes được quản lý (managed control plane).
AWS Elastic BeanstalkPaaS — upload code, AWS lo phần hạ tầng.
AWS OutpostsHạ tầng AWS đặt tại data center của doanh nghiệp.
VMware Cloud on AWSChạy môi trường VMware trên hạ tầng AWS.

💾 Storage

Amazon S3Hay dùngObject storage gần như không giới hạn dung lượng.
Amazon EBSHay dùngỔ đĩa (block storage) gắn vào EC2.
Amazon EFSHay dùngFile system NFS dùng chung cho nhiều EC2/container.
AWS BackupHay dùngQuản lý backup tập trung cho nhiều dịch vụ.
Amazon FSxFile system được quản lý: Windows File Server, Lustre, NetApp ONTAP...
AWS Storage GatewayKết nối storage on-premise với AWS.
AWS Snow FamilyThiết bị vật lý để chuyển dữ liệu lớn (TB–PB) lên AWS.
Elastic Disaster RecoveryGiải pháp DR cho server on-premise/cloud.

Trade-off: Managed service vs tự quản lý trên EC2

Tiêu chíManaged service (RDS, ECS Fargate, Lambda...)Tự cài trên EC2
Công sức vận hànhThấp — AWS lo patch, backup, HACao — tự cài đặt, update, backup
Chi phí trực tiếpThường cao hơn một chútThấp hơn về giá instance
Mức độ tuỳ biếnBị giới hạn bởi tính năng serviceToàn quyền (root access)
Vendor lock-inCao hơnThấp hơn, dễ di chuyển
Khuyến nghịƯu tiên managed service cho team nhỏ, muốn tập trung vào sản phẩm; tự quản lý khi có yêu cầu đặc thù mà service không đáp ứng.

Use Cases

Web application truyền thống

Route 53 → CloudFront → ALB → EC2/ECS → RDS + ElastiCache, file upload lưu trên S3, monitoring bằng CloudWatch.

Ứng dụng Serverless

S3 + CloudFront host frontend, API Gateway + Lambda làm backend, DynamoDB lưu dữ liệu, Cognito xác thực người dùng.

CICD pipeline trên AWS

Source trên GitHub → CodePipeline → CodeBuild build Docker image, push lên ECR → CodeDeploy/ECS triển khai — sẽ được thực hành ở section CodePipeline phía sau.

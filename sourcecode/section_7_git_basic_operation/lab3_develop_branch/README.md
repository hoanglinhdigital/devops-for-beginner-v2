# demo-git

Repository thực hành Section 7 – Thao tác cơ bản với Git (khoá học DevOps on AWS for Beginner).

## Branch
| Branch | Mục đích |
|---|---|
| `main` | Code đã release, gắn tag theo version |
| `develop` | Nhánh tích hợp các feature/bugfix |
| `feature/*` | Phát triển chức năng mới, tạo từ `develop` |
| `release/*` | Chuẩn bị release, tạo từ `develop`, merge vào `main` |
